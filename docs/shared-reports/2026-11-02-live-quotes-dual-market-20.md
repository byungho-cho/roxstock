# 실시간 시세 20종목 · 이중 시장 수신 (로컬 검증)

## 정책

- 사용자별 표시 목록 신규 등록 상한을 20종목으로 변경한다. 이미 초과한 목록은 자동 삭제하지 않고 경고하며 기존 항목의 순서 변경·제거만 허용한다. 20개 이하로 정리한 뒤 새 종목을 추가할 수 있다.
- 통합은 논리 화면이다. 장중에는 한투 통합+KRX, 장전·장후 NXT 운영 시간에는 통합+NXT를 구독한다. 같은 종목에 세 시장을 동시에 추가하지 않는다.
- KRX 정규장 09:00~15:30에는 정상 통합 우선, 없거나 30초 이상 오래된 경우 정상 KRX로 대체한다. NXT 운영 구간 08:00~08:50 및 15:40~20:00에는 정상 NXT 우선, 정상 통합이 있으면 차선으로 사용한다. 휴일 및 시장 종료에는 마지막 실제 체결의 전체 튜플을 유지한다.
- NXT 미수신 종목은 마지막 KRX 등 실제 체결을 참고값으로 유지한다. 실제 시세를 받지 못한 것을 정상 NXT 수신으로 표시하지 않는다.
- 가격·등락률·등락액·시각은 한 시장의 값을 함께 선택한다. 시간 재작성 없이 실제 원천 시장(sourceMarket)을 전달하고, 통합 화면에서 KRX/NXT 대체 중이면 시각 앞에 표시한다. 출처 전환 자체는 가격 변동 강조를 발생시키지 않는다.
- 직접 KRX/NXT 선택은 해당 시장만 표시한다. 기존 인증·사용자별 목록·수동 정렬·드래그·1초 묶음 반영을 유지한다.
- 알림의 TOTAL 조건도 화면과 같은 선택 원천을 사용한다. KRX/NXT 조건은 해당 시장만 사용한다. 정상 신규 실제 체결만 기존 알림 판정기로 전달하며 캐시·단순 시간 경과·출처 선택만으로 알림을 발생시키지 않는다. 서로 다른 시장의 거래량 순번은 직접 비교하지 않는다. 물리 시장 내부의 동일 시각 역순·중복 순번은 수신 단계에서 차단한다.

## 구독 예산

- 한투 공식 FAQ: 앱키당 1세션, 모든 상품·항목 합산 41건.
- 20종목의 통합 화면은 최대 40건. 같은 종목·시장의 화면/접속/알림 요청은 서버에서 공유한다.
- 다른 사용자·명시적 시장 선택·별도 알림이 추가 시장을 요구하면 전역 41건을 공유한다. 20종목 모두의 동시 수신을 사용자마다 별도 보장하는 구조가 아니다.
- 예산은 논리 요청 묶음 전체를 수용하거나 한도 상태로 반환한다. 대체 경로 한쪽만 몰래 누락하지 않는다. 시장 전환은 이전 불필요 구독을 해제한 뒤 새 구독을 등록한다.
