## 수행·검증

저장된 원본·공시 목록·참고자료·계산 근거를 우선 재사용했다. 기존 근거만 재계산한 2,487종목에서는 추가 값이 0개였고, 이후 필요한 동일 공시 주식수·손익·자본·실제 회계기간과 해당 결산기의 과거 종가만 추가 조회했다. 출처·공시·기간·연결/별도·통화·주식 기준을 기존 검증기와 계산기로 대조하고, 저장 직전 최신 행과 사본의 일치·기존 정상 값 보존·저장 결과·재실행 결과를 확인했다.

기간 손익에 의존하는 초기 보완 169종목은 실제 회계기간을 재대조해 2025-01-01~2025-12-31 및 동일 공시 자본·손익 일치를 확인하고 근거를 보존했다. 이후 배치는 실제 기간 근거를 저장 전에 확인한다.

초기 실행의 적자 종목 2개에서 기존 계산 함수가 음수 PER를 생성한 것을 발견했다. 두 기간 행 전체를 변경 후 사본과 일치할 때만 변경 전 상태로 복원했고, 해당 2개 기간의 지표 저장을 순성과에서 제외했다. 이후 같은 후보는 저장 전에 개발 대기로 분리한다. 기존 정상 EPS를 바꾸려는 계산 후보도 저장하지 않는다. 운영 프로그램 수정·검증 우회·배포는 하지 않았다.

## 재무자료 확인과 남은 원인

필수 재무 항목이 남은 5종목은 금융업 매출 계정 대응 대상이다. 보험수익·보험영업수익·투자수익·이자수익·순이자손익을 일반기업 매출 하나로 임의 합치지 않는다. 종목·2025년 연간·원문/응답·현재/기대 동작 및 정확한 재처리 목록을 최종 개발 인계에 남긴다.

서한·한국전자인증·제이씨케미칼은 API의 반환 접수번호와 최신 첨부정정 사이 관계가 기존 검증에서 보류됐다. 첨부정정 원문에 재무 본문이 없는 점을 확인했다. 폴레드는 공식 원문의 당기 열 선택이 기존 파서에서 보류됐다. 기존 검증 참고자료는 보존하고 DART 정기공시로 재표시하지 않는다.

엠에스바이오·엘리스의 공식 2025년 감사보고서를 추가 확인했다. 엠에스바이오의 기존 참고자료와 원문 6개 금액·기간·별도/KIFRS·원 단위·당기 열·대차 합계·내용 해시가 일치했다. 저장 직전 기존 행이 확인돼 신규 저장은 차단했다. 이 자료는 2026-10-25에 이미 확보된 자료이며 이번 신규 보완 실적으로 가산하지 않는다.

초기 중간 안내의 재무 미확보 1종목은 버전 필드가 없는 기존 DART_PUBLIC_REFERENCE 메타데이터를 집계기가 놓친 오류였다. 메타데이터의 실제 기간·출처·내용 해시를 확인해 집계를 수정했다. 정확한 보완 전후 재무자료 미확보는 0→0이다. 기존 행을 중복 생성하거나 덮어쓰지 않았다.

## 보존과 계속할 작업

변경 전 전체 운영 DB 백업은 `/opt/roxstock/backups/roxstock-v0.2-20261026T060306Z/`에 비공개 보존했다. SHA-256 재계산·gzip 전체 CRC·덤프 머리말/완료 표시를 검증했다. **이번 백업의 별도 DB 복원 검증은 미실시**다. 대상 행의 변경 전후 사본·출처 응답·계산 근거·체크포인트·선별 복구 자료는 비공개 보존한다. 개인 계좌·거래·예수금·자산 스냅샷·알림 설정을 변경하지 않는다.

기존 재무 공유 잠금과 일일 10,000회 예산을 사용한다. 잠금이 다른 수집에 있으면 양보한다. 초기 회계기간 재검증은 클라이언트를 종목별로 새로 만들어 요청 간 2초 간격이 유지되지 않은 구간이 있었다. 이후 배치는 단일 DART 클라이언트로 간격을 공유하고 종목 사이 2초간 잠금을 양보하도록 바꿨다. 이 일회성 실행기의 조정은 운영 제품 코드 수정이 아니다. 예산 한도를 늘리거나 자동 수집을 중단하지 않았다.

원인별 조회·응답 재사용·실제 호출·저장 결과를 비공개 체크포인트에 남긴다. 아직 확인하지 않은 대상과 원문·계산 근거가 부족한 대상을 보완 불가로 합치지 않는다. 한도 도달 시 정확한 진행 위치와 남은 대상을 기록한다. 2025년 연간이 끝나기 전 다른 연도·분기를 재처리하지 않는다. 오류 카드·원본 사건·발생 시각·검토 메모·반복 이력은 보존하며 실제 원인 해소를 확인하지 않은 사건을 해결 처리하지 않았다.

최종 보고에는 고정 대상의 최신 전후 표, 지표별 실제 저장 수, 정상 계산 불가·보완 불가·개발 대기·조사 미완료 수, API·캐시 재대조 결과와 재개 대상을 갱신한다. 현재 문서는 진행 중 기준점이다.
