# 운영 DB 로컬 최신화 및 오류 검토 — 2026-10-22

## 범위와 복구

운영 DB를 읽기 전용 single-transaction 스냅샷으로 내려받아 loopback/roxstock_dev에 복원했다. 교체 전 로컬 전체 DB를 gzip 백업하고 무결성과 SHA-256을 기록했다. 운영 DB 쓰기, 스키마 변경, 운영 배포는 하지 않았다. APK 단일 다운로드 변경 사항을 보존했다.

스냅샷 69개 테이블의 행 수를 덤프의 실제 INSERT 수와 모두 대조했다. 백업·운영 원본 스냅샷·검토 전 보고서/발생 이력·변경 전 재무지표와 상세 근거는 저장소 밖 비공개 work 경로에 보관한다. 개인 데이터와 비밀값은 이 보고서에 포함하지 않는다. 복구 시 로컬 서버를 중지한 뒤 비공개 백업 또는 원본 운영 스냅샷을 roxstock_dev에만 복원한다.

## 검토와 보완

- 초기 미해결 26개 원인 그룹, 358개 발생 이력을 원 실행 항목 SHA-256 키와 대조했다.
- 동일 기간 저장 원천 128개 기간을 재계산해 ROE 6개 기간을 보완했다. 기존 정상 지표가 바뀌지 않았음을 확인했고 관련 캐시 revision을 증가시켰다. 이 기간의 남은 BPS 누락은 해결 처리하지 않았다.
- DART 목록 조회 P1017 오류 중 동일 종목·동일 작업의 이후 SUCCESS 목록 확인이 있는 4개 발생 이력만 해결했다. 실행 전체 오류나 다른 기간 누락을 함께 해결하지 않았다.
- 한투 미제공 4개 종목은 현재 시장 구분으로 한투·KRX를 재조회했으나 종목/스키마 불일치 또는 자료 부재가 계속돼 보류했다. 현재 참고값을 과거 지표로 대체하거나, 자료 없는 종목을 임의로 수집 제외하지 않았다.
- 뉴스 원천 조회 범위·회사 매핑·DART 작업 양보·링크 제약, 공시 원문 해석 보류, 실시간 연결 및 스냅샷 예수금 부재는 근거 부족으로 보류했다. 개인 예수금은 임의 생성하지 않았다.

## 최종 상태

로컬 서버 재시작 후 자동 오류 점검이 갱신한 동일 기간 BPS 부족 재관측 6개도 기존 검토 대상과 대조했다. 따라서 358 - 해결 4 + 재관측 6 = 미해결 발생 이력 360개이며, 중복을 제거한 대상은 195개다.

원인별 26개 그룹을 REVIEWING으로 보존하여 화면에서는 기존 기능인 ‘검토한 미해결 항목’ 하나로 표시한다. OPEN 0개이며 최초 358개 발생 이력이 모두 남아 있음을 검증했다. 실제 미해결을 해결 완료로 표시하거나 삭제하지 않았다.

로컬 웹 HTTP 200, 백엔드 버전 v1.2.5 정상 응답을 확인했다. 운영 반영은 후속 작업이다.

## 승인 후 운영 DB 반영 (v1.2.6)

운영 직전 전체 백업·gzip·SHA-256 검증 및 변경 행 사전 이미지를 비공개 보관했다. 현재 운영 원천의 해시·공시 접수번호·기간·종목과 후속 목록 조회 성공을 재검증했고 충돌 0건으로 ROE 6개 기간 보완, 목록 조회 오류 4건 해결, 검토한 원인 그룹 26개 통합을 적용했다. 운영 기존 정상 지표 6개를 보존했고 로컬에서만 생성된 6개 발생 이력은 복사하지 않았다. 새로운 운영 사건이 있으면 보류하지 않고 별도로 유지한다. 개인 계좌·거래·예수금·인증 데이터와 스키마 변경 없음.

프론트엔드 production 빌드, 커버·태블릿 모니터링 회귀 26개, APK 구성 2개 및 검증 4개 테스트, YAML 파싱과 Bash 문법 검사 통과. 운영 이미지는 PR 병합 후 자동 배포한다. 전체 백업의 격리 복원 검증은 이번 스냅샷에서 재수행하지 않았으며 무결성 검사와 변경 전 행 백업을 완료했다.
