# 거래 보유일 및 연결 매수 선택 개선

기준 main: e2905a3ead7e7dac377f18351f8df3442a1bcbff (웹 1.2.15). 별도 feat/holding-days-lot-selector-20261023 브랜치. PR #313·#314의 제세금 원 단위 올림·대시보드·로그인 유지 수정은 보존한다.

## 변경

- 종목 상세 거래내역의 각 매도 카드에 연결된 매수일부터 매도일까지 한국 날짜 차이를 `보유 N일`로 표시한다. 당일 0, 분할매도는 각 매도일 기준. 불명확한 날짜·역전 날짜는 표시하지 않는다. 날짜와 같은 9px/400 흰색이며 손익률 뒤, 수정·삭제 앞에 배치한다. 긴 금액은 줄바꿈하여 아이콘 공간을 보존한다.
- 연결 매수 선택은 기존 HistoryDialog 및 stockDialogPaper 공통 폭/중앙 정렬을 재사용한다. 최대 354px, 양옆 8px, 높이는 화면에서 32px를 남기며 목록만 내부 스크롤한다. 사용자 폭 확대 지시를 Figma의 기존 338px보다 우선 적용했다.
- Figma 5092:629 및 후보 5135:48~67의 칩·두 줄·색·간격을 적용한다. 매수 칩 28×18, 날짜 흰색, 예상 손익은 첫 줄 오른쪽. 둘째 줄은 잔여수량×매수단가 및 잔여 매입합계다. 상하 8px, 줄 간격 4px, 수익 빨강/손실 파랑/0 중립. 다크 블루 선택 배경과 노란 테두리, 라디오 없음. 팝업 안에 새 이미지 자산은 없다.
- 수익률 `(매도단가-매수단가)/매수단가`를 정수 스케일 교차곱으로 비교하고, 동률이면 한국 매수 날짜·고유 ID 순으로 고정한다. 표시 반올림은 정렬에 사용하지 않는다. 잔여 합계와 이번 매도 손익은 서로 다른 수량으로 정확 계산한다. DB 수량 6자리/가격 4자리 정밀도를 보존한다.
- 최초 첫 후보 기본 선택. 유효한 사용자 선택은 재렌더·후보 갱신에 유지하고, 무효화 시 첫 유효 후보로 재평가한다. 사용자·계좌·종목·알림 scope 변경 시 초기화한다. 조회 중/오류/후보 없음은 다음 버튼을 차단한다.
- 후보의 계좌 조회 범위·정확한 종목 ID·수량·매수일 필터를 유지한다. 단일 Lot만 기존 매도 등록 화면에 전달한다. 기본 선택만으로 저장하지 않으며 기존 최종 저장·실패/취소·알림 처리·서버 소유권/잔여량 검증 로직은 변경하지 않는다.

## 검증 및 배포 상태

프론트 타입 검사/빌드와 날짜·정렬·분할매도 금액 및 기존 알림 파싱 정책 단위 검증 11건 통과. 커버 370×465 / 태블릿 725×396 브라우저 검증과 최종 CI 결과는 완료 후 기록한다. 실제 휴대전화 터치·키보드 및 실제 사용자 거래 저장은 미검증이다.

웹 패치 1.2.16. 네이티브 변경·새 APK 빌드·DB 스키마 변경·데이터 보정 없음. 배포 대상은 변경 서비스 선택 결과에 따른 frontend이며 공통 runtime 버전 메타데이터를 함께 갱신한다. CI 시작·병합·운영 반영 완료를 구분하여 후속 결과를 기록한다.

복구 시 이전 frontend 불변 이미지와 runtime 버전 메타데이터를 함께 복구하고, DB·거래 원본·Android 로컬 알림은 유지한다. 운영 사용자 거래를 생성하거나 원문 개인정보를 보고서에 포함하지 않는다.
