- 릴리스: 1.2.62

## 변경 동작

- 실시간 주가 카드 본문을 누르면 해당 종목의 상승 VI·하락 VI·시가·고가·저가를 작은 팝업으로 표시한다. 수치는 오른쪽 정렬하고 상승은 빨강, 하락은 파랑, 확인할 수 없는 값은 회색 `—`로 표시한다.
- 팝업 바깥 클릭·터치, 닫기 버튼, Esc로 닫힌다. 팝업 내부 클릭은 유지하고, 다른 카드 본문을 누르면 해당 종목으로 교체한다. 같은 카드 본문을 다시 누르면 닫힌다.
- 카드 본문의 기존 알림 확인 처리를 유지한다. 종목명은 기존 상세 이동, 종 아이콘은 알림 설정, 길게 누르기는 순서 편집 동작을 유지한다.
- 이미 구독 중인 KIS 체결 프레임의 시가·고가·저가와 정적 VI 기준가를 전달한다. 팝업을 열기 위한 별도 구독이나 REST 요청은 추가하지 않는다.
- 정적 VI 기준가는 상승·하락 발동가 자체가 아니다. KOSPI/KOSDAQ 일반 주식이며 실제 KRX/NXT 시장의 유효한 기준가가 있을 때만 ±10%에 일반 주식 호가 단위를 바깥 방향으로 적용한다. 상품 유형·시장·기준가가 확인되지 않으면 VI를 추정하지 않는다. 통합 시세도 기준 시장을 함께 표시한다.
- 주가 변동 테두리의 내부 여백은 좌우 최대 16px·상하 2px로 둔다. 절대 위치 테두리를 사용하여 현재가·등락률·등락금액·시간 및 카드 높이·행 간격은 유지한다. 좁은 카드에서 테두리가 등락률이나 카드 경계를 침범하지 않도록 좌우 여백을 제한한다.
- 당일 실제 체결을 아직 수신하지 않았다면 현재가·등락률·등락금액·시간을 회색으로 표시한다. 기존 유효 값과 원래 체결 시간은 유지하며, 미확인 값은 `—`로 표시한다. REST 응답 시간이나 연결 성공만으로 수신 완료 상태로 바꾸지 않는다.
- 태블릿 즐겨찾기의 노란 테두리는 행의 아이콘·버튼을 포함하도록 높이와 내부 정렬을 맞춘다.
- 태블릿 관심종목의 W 0.7/0.8/0.9/1.0 가격을 축소하여 같은 테이블 행에 배치한다. 기존 가치지표·영업이익·현재가·등락금액·등락률은 유지하고, 커버 화면의 가격 카드 배치는 유지한다.
