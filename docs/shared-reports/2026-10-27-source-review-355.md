검증한 핵심 항목은 매출액·영업이익·순이익·자산·부채·자본이다. 이 6항목의 누락은 1,788필드에서 1,380필드로 감소했다. EPS·BPS·ROE·PER·PBR, 현금흐름 등 다른 항목까지 모두 보완했다는 뜻은 아니다.

## 원천과 계산 검증

- 68종목의 공식 회사 정보·해당 연도 정기공시 선택 결과와 한투 재무상태표/손익계산서 218개 응답을 비공개 보관했다. 355대상 기간에 해당하는 DART 정기보고서는 이번 조회에서 선택되지 않았다.
- 누적 손익의 의미를 추가 확인할 11종목에 대해 다른 실제 공시 기간을 읽기 전용 대조했다. 10종목은 한투의 손익 3항목이 DART 누적값과 반올림 오차 범위 내에서 일치하는 근거를 확보했다. 이 추가 공시 기간의 값을 운영 DB에 저장하거나 작업 범위를 확장하지 않았다.
- 당해 연도의 유효한 연간 기간 근거를 요구했다. 오래된 저장 행의 검증 정보가 없는 경우에는 이번 공식 공시 선택의 동일 회사·접수번호·연말 종료일로 기간을 재검증했다. 현재 결산월을 과거에 일괄 적용하지 않았다.
- `mode=1`의 누적 손익을 분기 손익으로 그대로 저장하지 않았다. Q1은 누적과 단독 분기가 같고, Q2/Q3는 검증한 누적값에서 같은 연도의 직전 누적값을 뺐다. 직전 자료가 없거나 누적 기준이 입증되지 않으면 해당 손익을 보류했다.
- 억원 값을 부동소수점 없이 원 단위 정수로 환산했다. 누적값 차감에 따른 반올림 불확실성도 메타데이터에 기록했다. 실제 음수 손익은 유지했다.
- 한투의 전부 0인 대차 응답을 실제 0원 자산으로 저장하지 않았다. 중복 기간, 잘못된 숫자, 대차 불일치도 보류했다. 독립적으로 검증된 대차 또는 손익 3항목만 부분 저장할 수 있게 했다.
- 저장 출처는 `KIS_API_REFERENCE`, 연결/별도는 `UNVERIFIED`, 반올림·참고용 플래그를 유지했다. 모든 신규 필드의 원천·계산 근거를 기록하고 DART 자료와 별도 보관했다.

## 운영 반영과 보존 검증

기본은 읽기 전용 계획이며 실제 저장은 명시적 apply로 실행했다. 355기간 allowlist, 최신 종목코드·수집 revision·공시 매핑·작업 수정 시각·기존 값 hash를 전부 재확인했다. 고정 계획 SHA-256은 `4d96438710baedbfb244e566adff8dcd5d8ff2cae0620ccedb7353db02854bf4`다. 공용 financial lease·수집 제외 검사·DART 공용 예산·기존 한투 토큰 경로를 재사용했다.

- 원래 재무자료 302행의 전체 값·출처가 동일하고, 신규 참고자료만 106행 추가됐다.
- DART 원본·기간 지표·계좌·매수 Lot·분할매도 5개 테이블의 checksum이 모두 동일했다. 기존 지표나 개인 데이터를 변경하지 않았다.
- financial revision은 963157 → 963618로 정상 갱신됐다. 신규 106기간·408필드를 실제 상세 API에서 모두 대조했고, 빈 필드는 그대로 비어 있음을 확인했다.
- 2026 목록 캐시 `REFRESHED`, 새 인스턴스 `PERSISTED_HIT` 및 동일 revision을 확인했다. 동일 계획 재실행은 신규 저장 0건이었다.
- 저장·보존 확인 후 해당 원인이 해소된 87개 오류 사건만 해결했다. 기존 연간 57개도 포함하므로 이 87개를 새 데이터 저장 실적으로 사용하지 않는다. 원래 사건·시각·작업 관계와 결정 이력은 유지했다.
- 전체/부분 참고 보완 및 원천 부족은 `DATA_UNAVAILABLE` 안에서 구분하고, 핵심 6항목 전체가 있을 때만 `needsSupplement=false`로 기록했다. `SUCCESS`인 DART API 원본을 만들어 내지 않았다. 나머지 268기간은 미완료로 유지한다.

독립 정책 테스트 9개와 기존 과거 수집·원 단위 환산·실행 경로 테스트를 포함해 총 22개 통과했다. 중복 원천, 음수 손익, 과거 결산 근거, 공통 출처/기간 불일치, 부분 보완, 누적값 오인 방지를 검증했다.

## 실행 조율과 복구

작업 전 전체 운영 DB 추가 백업의 gzip 무결성과 비공개 별도 복제 SHA-256 일치를 확인했다. 원천 응답·확정 계획·행별 사전 사본·결정 이력·적용 결과를 비공개 압축 사본으로 이중 보관했다. 비밀 설정과 운영 원본은 Git에 게시하지 않았다.

기존 일시 과거 보완 예약을 잠시 멈추고 실행했다. 완료 후 그 예약을 복원했으며, 기존 고정 계획의 남은 위치에는 이번 355개 작업이 없음을 확인했다. 따라서 같은 작업이 곧바로 재실행돼 검토 결과를 덮어쓰지 않는다. 2단계와 우선종목 보류, 전용 DART 컨테이너 `false/restart=no`는 유지했다.

복구는 전체 DB 덮어쓰기가 아닌 **이번 plan hash의 신규 참고 행과 355개 작업 상태만** 대상으로 한다. 공용 실행권을 확보하고 이후 변경 여부를 대조한 뒤 사전 사본으로 선별 복원한다. 이후 새 공시·수동 보완이 있으면 덮어쓰지 않고 충돌 대상으로 분리한다. 오류 사건 복구도 이 작업의 해결 사유와 시각이 일치하는 것만 대상으로 한다. 원본 공시·기존 재무·개인 자산은 복구/삭제 대상이 아니다.

이번 반영은 운영 데이터의 선별 보완과 수동 실행 정책 도구다. 웹/Android 실행 코드는 변경하지 않았고 운영 버전 1.2.29와 APK를 유지한다.
