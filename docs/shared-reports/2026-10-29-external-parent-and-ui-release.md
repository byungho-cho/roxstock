# 지배주주 항목 선별 보완 및 종목 관리 UI · v1.2.44

## 변경 범위

- 종목 관리와 연결 상세의 로딩 텍스트를 화면 중앙 원형 애니메이션으로 통일. 자동 polling·focus·reconnect 갱신 제거. 최초 조회, 페이지 선조회, 명시적 재시도 및 저장 후 무효화는 유지.
- 같은 연간 공시에서 보통주·우선주·합계 주식수와 자본/BPS가 검증된 경우에만 합산 주식수 참고 W를 허용. 투자 주의 표시, 원본 BPS 보존. 연말 지배주주 자본 ROE 사용 및 기존 값과 1%p 이상 차이 안내 유지.
- 원본 상세의 지배주주 순손익 표시가 검증된 보완 계정도 사용하도록 수정. 다른 종목·기간·통화·공시 및 수기 우선순위 보존.
- NAVER 연간 지배주주 항목은 별도 외부 출처와 응답 근거를 저장. DART 제공 계정으로 가장하지 않는다. 같은 종목·2025 ANNUAL·12월 결산·CFS·KRW와 당기순손익·자산·부채·자본 네 합계를 대조한다. 제공처 0.01억원 표시 정밀도의 반올림 허용범위는 항목별 최대 500,000원이다. 일부 원천 합계가 없거나 서로 다르면 저장하지 않는다.
- 한투 조회 응답의 전체 당기순이익을 지배주주 순손익으로 대체하지 않는다. 네이버 평균 자본 ROE를 그대로 W에 사용하지 않고 검증된 순손익/기말 지배주주 자본으로 계산한다.
- 기존 DART 계정·수기 값·다른 지표·최신 공시·이력은 보존한다. 과거 자동 수집과 대기열을 재개하지 않는다.

## 저장 전 전체 대상 검증

최신 운영 자료에 미배포 로컬 정책을 적용했을 때 2025 연간 W 미충족은 370종목이었다. 그중 지배주주 순손익 또는 자본이 부족한 **203종목**을 지정해 네이버를 한 번씩 조회했다. API 키·개인 거래 원본·응답 원본은 저장소에 포함하지 않는다.

- 네이버 해당 연간 지배주주 항목 제공: 201종목. 제공 여부와 저장 적합성은 별개다.
- 저장 적합 계획: **179종목, 199개 계정 필드**.
- 이 중 W 충족 전환 예상: **137종목**. 보완 계정을 저장해도 다른 근거가 부족한 42종목은 W 미충족 유지.
- 연말 지배주주 자본 기준 ROE 저장 예상: 174종목. 1%p 이상 차이 주의 예상 71종목.
- 나머지 24종목은 원천/통화/결산/기존 컨텍스트 불일치 또는 제공처 파싱·자료 미제공으로 보류. 검증 강도를 낮추지 않았다.
- 코리안리(003690): 네이버 지배주주 순이익 322,041,000,000원. DART 기말 지배주주 자본 3,683,421,777,221원. ROE 8.743%, 계획상 W 충족. 한투의 전체 순이익 322,000,000,000원은 귀속 구분이 없어 대신 저장하지 않는다.

위 숫자는 배포 전 계획 결과다. 실제 저장·운영 응답·배포 확인 결과는 아래 후속 기록으로 구분한다. 새로운 자료나 주가가 반영되면 집계가 달라질 수 있다.

## 선별 실행·복구

`scripts/reprocess-external-parent.mjs`는 기본 계획만 출력한다. 필수 인수는 `--symbols-file <비공개 JSON allowlist> --evidence-dir <비공개 응답 디렉터리> --output-dir <비공개 계획·before·after 디렉터리>`이며 실제 반영에만 `--apply --production`을 추가한다. 컨테이너에서는 `ROXSTOCK_RUNTIME_ROOT=/app`로 기존 shared/collector 모듈을 사용한다.

2025 ANNUAL의 명시한 종목과 parentNetIncome/parentEquity만 보완한다. 기존 금융 lease·종목 수집 정책, 실행 직전 원천·행 hash/updatedAt 재대조, 행별 체크포인트, 사본, 다른 계정·지표 불변 검증을 사용한다. 외부 API 호출·전체 종목 수집·오류 초기화 기능은 없다. 완료된 계정은 재실행 시 건너뛴다.

복구는 `scripts/rollback-external-parent.mjs --symbol <지정 종목> --output-dir <같은 사본 위치>`로 먼저 읽기 전용 확인한다. `--apply --production`이 있을 때만 이전 values/provenance/reasons/supplemental을 선별 복구한다. after 전체 행과 원공시 hash가 현재와 일치해야 하며, 이후 변경이 있으면 자동 복구하지 않는다. 전체 운영 DB를 과거 사본으로 덮어쓰지 않는다. 운영 최신 DB 전체 추가 백업 및 이전 이미지 식별자는 비공개 보관한다.

Android 네이티브 변경·DB 스키마 변경 없음. APK 유지. 코드 배포와 실제 데이터 보완 완료는 분리해 보고한다.
