# v1.2.5 수집 검토 반영

모니터링 순서를 실시간 주가, 일별 계좌 스냅샷, 전체 종목 주가, 투자동향, DART 재무제표, 종목 마스터, 종목소식, 오류 리포트로 정렬한다.

추가 재무지표 수집에서 재무 저장 잠금 대기를 원천 실패로 집계하던 문제를 수정한다. 잠금 대기는 별도 `annualDeferred`로 기록하며, 실제 API 오류는 실패로 유지한다. 사용자가 제외한 연간 보완 기간은 해당 연도에만 적용하고 현재 참고지표와 다른 연도의 수집은 유지한다.

## 검토 데이터

- 네 종목의 전체 외부 수집 제외 및 관련 미해결 기록 정리.
- 제출기한 검토 190개 기간 제외.
- 결산월 검토 179개 기간 중 56개는 시기 미도래로 정정하고 123개는 기간 수집 제외.
- 연간 보완 잠금 대기 158개 배치의 실제 대상 546종목·883기간 대조. 로컬에서 EPS 56개를 보완하고, 남은 누락을 포함한 883개 기간은 연간 추가지표 보완 경로에서 제외했다. 일부 보완 기간과 제외 기간은 겹친다. DART 원천 재무제표 수집은 유지한다.

운영 반영은 전체 DB 복원이 아니라 검토한 행의 필드만 병합한다. 운영에서 새로 채워진 값과 새 오류는 보존한다. 종목·연도·접수번호가 변경된 행은 충돌로 처리한다. 실제 운영 반영 수치는 충돌 대조 및 사후 검증 결과로 확정한다.

## 검증 및 복구

수집기 관련 테스트 31개, 화면 타입 검사 통과. 연도별 제외 범위, 비동기 저장 잠금 경합, 기존 값 보존을 검증했다. 로컬 사후 검증에서 기존 비어 있지 않은 지표 1,504개가 보존됐다.

운영 변경 전 `/opt/roxstock/backups/roxstock-v0.2-UTC시각/`에 DB 백업과 체크섬·검증 결과를 보관한다. 대상 행의 별도 비공개 변경 전 사본도 보관한다. 데이터 복구는 해당 사본과 변경 후 상태를 대조해 대상 필드만 복원한다. 반영 이후의 신규 사용자 데이터에 전체 DB 백업을 덮어쓰지 않는다.

코드 복구는 배포 전 보관한 웹 이미지 및 전용 투자동향 수집기 이미지로 되돌린다. 인증·사용자 소유권 검사는 유지한다. DB 스키마와 Android 네이티브 변경은 없다. 비공개 데이터 묶음과 원본 백업은 저장소에 포함하지 않는다.
