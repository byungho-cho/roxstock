# v1.2.1 화면 및 수집 모니터링 수정

## 변경

- 종목 상세 카드와 탭 간격을 8px로 통일하고 예수금·복리계획 빈 안내를 가운데 배치했다. 자료가 없는 예수금의 이전 월·추이 상세 버튼을 비활성화했다.
- 일반 사용자에게 모니터링 메뉴를 숨기고 직접 접근도 차단했다. 계좌 관리의 상단 여백을 없애고 목록 아래에 추가 버튼과 안내를 배치했다.
- 종목소식 빈 안내에서 일부 수집 실패 문구를 제거했다. 운영 모니터링 진단은 유지한다.
- 모니터링 카드에 결과와 시도 시간을 제목 옆에 배치했다. 성공은 파랑, 대기는 녹색이며 결과 시간도 같은 색이다. 하단 결과 건수와 다음 일정은 좌우 정렬했다.
- DART 집계를 실제 수집 범위와 제외 정책에 맞췄다. 검토 보류는 실패 이력에 남기되 자동 단계 전환을 막지 않으며 현행 수집에서 같은 보류 공시를 재시도하지 않는다. 최근 실행 기록으로 지연을 판단한다.
- 투자동향의 검증된 수량·금액 저장을 수집 성공으로 표시한다. 원문만 저장, 미제공 대기, 실패는 성공에 포함하지 않는다. API 미제공 항목 안내는 별도 유지하며 원래 실행 상태는 originalStatus에 보존한다. 요약·이력·대상 API에 같은 기준을 적용했다.

## 검증

- 백엔드 146개 중 145개 통과, 실제 DB 인증 테스트 1개는 기본 설정에 따라 건너뜀. 로컬 실제 인증 세션으로 요약·이력·오류 리포트 API를 별도 검증했다.
- 수집기 및 DART 범위 회귀 테스트 232개 통과. 타입 검사와 운영용 프런트엔드 빌드 통과.
- 투자동향 커버·펼침 화면 2개 테스트 통과. 모니터링 운영 빌드 회귀 검증과 권한별 메뉴·계좌 배치, 예수금 빈 화면 검증을 수행했다.
- 로컬 실제 데이터: 투자동향 성공 76/76, 미완료 0. 오류 리포트는 원본 이력 보존 후 10월 21일 검토 그룹 하나로 통합했다. 저장 공시로 추가 계산 가능한 누락 지표는 없었다.
- 실제 Android 기기 재검증은 이번 화면 수정에서 수행하지 않았다. 네이티브 소스 변경은 없다.

## 운영 반영 및 복구

- 운영 최신 데이터 전체를 로컬 DB로 덮어쓰지 않는다. 운영에서 현재 근거를 다시 검증하고 오류 리포트 검토 상태와 메모만 반영한다. 새 사건은 기존 검토 목록으로 자동 숨기지 않는다.
- DB 스키마 변경 없음. 운영 일관성 백업과 SHA-256·gzip 검증, 서버 밖 비공개 복제를 완료했다. 백업·개인 데이터는 Git에 포함하지 않는다.
- 코드 복구는 백업에 기록한 직전 v1.2.0 서비스 이미지를 복원한다. 인증·소유권 접근 통제를 유지하며 인증 도입 이전 이미지로 되돌리지 않는다.
- 리포트 복구는 작업 직전 비공개 JSON의 상태·메모만 조건부 복원한다. 원천 자료와 개인 자산 데이터는 수정하지 않는다. DART 단계 전환을 되돌려야 하면 수집기를 정지한 후 백업된 state 행을 비교·복원한다.
- 이번 백업의 전체 복원 리허설은 실행하지 않았다. 기존 인증 배포 때의 복원 검증 기록은 별도 유지한다.
