# v1.2.22 과거 자료 오류 사유 및 22건 재검토

## 문제와 변경

운영 실행 21440의 실패 22건에서 긴 표준 오류 코드가 비밀 문자열로 오인되어 가려졌고, 임시 보완 작업이 실제 검증 진단을 실행 항목에 전달하지 않았다. 알려진 코드만 한국어로 변환하고 임의의 긴 문자열·키·토큰·URL·SQL 숨김은 유지한다. 기존 이력도 알려진 코드와 대상 연도를 안전하게 복원해 표시한다. 누락된 핵심 필드와 후속 보완/제외 여부를 표시하며, 과거 실패 이력과 집계는 지우지 않는다.

신영증권의 IFRS 표준 영업이익 계정 `ifrs-full_ProfitLossFromOperatingActivities`를 인식하지 못한 문제를 수정한다. 영업외수익을 대체하지 않고 같은 공시의 당기 및 누적 값을 구분해 저장한다. 접수번호가 달라졌다는 이유만으로 차단하던 임시 조건을 제거하고, 기존의 실제 반환 접수번호·정정 관계 검증을 그대로 적용한다.

운영 선별 반영은 2026-10-25 09:32 KST 실행 **21441**에서 완료했다. 저장 11·제외 9·자료 미제공 1·연간 실패 1건을 재검증했고, 신규 저장 금액과 출처·접수번호·기간을 대조했다. 이전 실행 21440의 실패 22건 집계와 개별 실패 이력은 보존하고 상세 진단에 후속 조치만 기록했다. 기존 정상 원본·지표·우선종목·개인 계좌 자료를 덮어쓰지 않았다. `/opt/roxstock/backups/roxstock-v0.2-20261025T002425Z/`의 새 전체 백업과 대상 preimages 체크섬을 확인했다. 이 새 전체 백업의 별도 DB 복원 검증은 수행하지 않았다.

## 임시 캠페인 정책

- 2023년 이전은 **2022년까지**로 해석한다. 남은 고정 계획에서 해당 연간을 우선 처리한다.
- 연간은 실패 시 실패를 유지한다. 연간 실패를 자동 제외하지 않는다.
- 분기는 CFS/OFS 모두 미제공이거나, 공시와 KIS 과거 자료가 모두 미제공임이 확인된 경우에만 제외한다. 2022년까지는 사용자 과거 분기 정책, 이후에는 같은 해 출처와 핵심 금액이 검증된 연간이 있는 경우만 자동 제외한다.
- 통신·인증·한도 오류와 미해석 계정은 자료 미제공 근거가 아니므로 자동 제외하지 않는다. KIS 값만으로 공시 정체성을 가정하지 않는다.
- 2단계 및 우선종목 보류는 유지한다. `backfillCompletedAt`을 보존한 채 BACKFILL로 명시 전환한 임시 운영 상태에서는 일반 DART worker가 실행하지 않도록 하여 배포로 재시작돼도 2단계를 시작하지 않는다.
- 요약 API도 완료일만으로 2단계라고 추정하지 않고 명시적 BACKFILL 단계를 반영한다. 예상된 5분 배치 간격은 실행 대기로 표시하되 실제 PARTIAL/FAILED 결과는 숨기지 않는다. 제외 확정 항목은 ‘수집 제외 여부 검토’와 구분한다.
- 전체 보완이 끝나면 예약은 종료하며 2단계는 별도 설계 후 재개한다.

## 검증과 복구

임시 작업 격리 실행 및 정책 테스트 10개, 표준 계정/표시/기존 DART 검증 테스트 67개, 임시 단계·배치 대기 상태 테스트 2개 통과. 호출 예산·일시적 요청 제한·의도적 종료는 작업 위치를 보존한 PAUSED/SKIPPED로 기록하고 실제 자료 실패로 바꾸지 않는 경우도 검증한다. shared/backend/collector/frontend TypeScript 검사 통과. 로컬 `npm run typecheck:backend`의 사전 Prisma 복사는 실행 중 Windows 파일 잠금으로 실패했으며 타입 검사 자체는 별도로 통과했다. CI에서 전체 검사를 다시 수행한다.

운영 수정 전 새 전체 DB 백업과 대상 22건의 변경 전 상태를 비공개 보관한다. 공유 문서에는 재무 금액·키·메일·개인 자산 원본을 싣지 않는다. 복구는 해당 작업 원본/작업 상태/실행 항목의 현재 값과 변경 후 값을 비교해 선별 수행한다. 운영 전체 DB 덮어쓰기를 기본 복구로 사용하지 않는다. 구버전 복구 시에도 2단계 자동 컨테이너는 보류한 상태를 유지한다.
