# CJ 및 동일 사례의 참고 W 검증

2026-10-29 로컬 코드·데이터 보완. 운영에는 아직 반영하지 않았다. 운영 데이터 최신 사본의 2025년 연간 관리 대상 2,556종목을 이전 계산 코드와 대조했다.

## 확인 결과

| 종목 | 코드 | 결과 | ROE | 주의 표시 |
|---|---|---|---|---|
| CJ | 001040 | 우선주 합산 참고 W 약 0.64 | 0.8206% → 2.7516% | 변경 차이 1.93%p 기록 |
| 코오롱 | 002020 | 우선주 합산 참고 W 약 -4.15 | 기존 -8.5081% 유지 | 기존 3.93%p 주의 이력 보존 |

가격 시점에 따라 W는 달라진다. 음수 W를 성공률 향상을 위해 0으로 치환하지 않았다. 두 종목이 추가로 계산 가능해져 W 미충족은 233 → 231, W 충족은 2,323 → 2,325종목이다. 기존 계산 가능 종목이 미충족으로 바뀌는 회귀는 없었다.

## 원인과 변경

CJ는 같은 연간·연결 공시에 지배주주 자본 5,208,897,884,000원과 지배주주 순손익 143,329,782,000원, 전체 유통주식수 33,530,936주가 있었다. 제공처 BPS 155,346.03원은 이 나눗셈 결과의 소수 둘째 자리 반올림값이다. 빈 2·3우선주 행은 기존 코드가 미확보 주식수로 취급했다.

- 제공처 BPS는 종목코드·원공시·회계기간·연결/별도·원화·12개월 기간·기존 6개 재무 앵커 대조·출처 URL/해시가 모두 확인된 경우만 허용한다. 기존 수기 BPS는 우회하지 않는다.
- 빈 우선주 행은 발행·자기·유통 세 수량이 모두 비어 있고, 확인된 종류별 합계가 세 공시 총합과 각각 일치하며 발행−자기=유통도 맞는 경우에만 잔여 수량 0으로 입증한다. 일부 수량이 남았거나 총합 불일치이면 계속 보류한다. 원본 빈 값을 0으로 덮어쓰지 않는다.
- 제공처 BPS는 그대로 표시·저장한다. W 계산기에는 검증된 지배주주 자본÷전체 유통주식수의 반올림 전 값을 별도 입력해 반올림 오차를 전파하지 않는다.
- 연말 지배주주 자본 기준 ROE를 적용하고, 1%p 이상 차이는 기존 공통 주의 정책으로 보존한다. 원본 상세·편집 화면에서도 ROE 주의 문구를 표시한다.
- 우선주 권리 차이를 반영하지 않은 **참고 W**라는 기존 투자 주의를 유지한다. 보수적 가치임을 보장하지 않는다.
- 조회 캐시 버전 12와 연간 집계 기준 V4로 이전 계산 결과를 재사용하지 않게 한다. 과거 수집기·대기열은 재개하지 않는다.

## 데이터 보호 및 검증

재무 잠금과 기존 수기 보호·revision 갱신 경로를 사용했다. CJ ROE 1필드와 두 종목의 계산 검증 메타데이터만 로컬에서 갱신했다. BPS·EPS·PER·PBR·공시 원본·주식수 원본·개인 자료는 보존했다. 전체 및 행별 변경 전 사본과 변경 후 사본은 작업 비공개 위치에 보존했다.

공통 계산·기간·참고 W·주의·캐시 회귀 61개, 상세 API 9개, 커버/태블릿 주의 표시 2개 테스트 및 타입 검사·프런트 빌드를 통과했다. 실제 로컬 API에서도 두 종목의 W, ROE, 원본 BPS, 주의 문구와 집계 231을 대조했다. 다른 출처·기간·통화·주식수 불일치, 확인 안 된 제공처, 수기 값, 비어 있는 일부 수량은 계속 차단한다.

운영 적용 시 최신 상태를 다시 계획·대조하고 두 종목만 선별 반영해야 한다. 로컬 DB 전체를 운영에 덮어쓰면 안 된다. 복구는 현재 값이 변경 후 사본과 동일한지 확인한 뒤 해당 두 기간의 변경 필드만 변경 전으로 복원하고 계산 캐시를 무효화한다. 이번 보완으로 남은 231종목을 수집 제외하거나 오류를 삭제하지 않았다.
