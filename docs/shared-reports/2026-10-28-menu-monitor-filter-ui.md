# 메뉴·모니터링·종목 관리 필터 UI 반영

- 더보기 메뉴는 4열을 유지하고 각 버튼을 가로 폭에 맞는 정사각형으로 표시한다. 행은 내용 높이로 배치하며 스크롤을 유지한다.
- 수집 모니터링에서 종목 데이터 수집을 전체 상태 바로 아래 첫 카드로 표시한다. 나머지 순서는 유지한다.
- 종목 관리의 분기별 미수집 목록에서 전체·재무제표·가치지표 필터를 안내 문구 위에 배치한다. 동일한 3열 버튼이 전체 폭을 채우며 선택 상태를 색상과 `aria-pressed`로 표시한다.
- 재무자료·지표·개인 데이터, 공시 시작일 및 수집기 설정 변경은 없다. 신규 수집기는 기존 2026-10-28 공시 시작 경계를 유지한다.

표시 버전은 1.2.33이다. 프런트엔드 타입 검사와 370×465·725×396 화면 회귀 검증을 진행한다. 운영 배포는 기존 변경 범위 판정에 따라 프런트엔드만 교체하며 Android APK는 변경하지 않는다. 복구는 이전 프런트엔드 이미지로 되돌리고 DB를 복원하지 않는다. 실제 검사·병합·배포 결과는 연결 PR에 기록한다.
