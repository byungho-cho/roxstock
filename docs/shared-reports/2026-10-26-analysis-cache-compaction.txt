재무제표·가치분석 목록 캐시 경량화
작성일: 2026-10-26 (KST)
브랜치: codex/compact-analysis-cache-20261026
배포 대상 버전: 1.2.25

문제
운영 DB max_allowed_packet은 16,777,216바이트(16MiB).
운영 스냅샷에서 계산한 새 2026년 목록 캐시는 22,264,488바이트(약21.2MiB)로 제한 초과.
상세 provenance가 valuation과 metricBasis에 중복되고 perMetric 안에 다시 중첩되어 크기가 증가했다.

변경
- 캐시는 지표 숫자·가격 기준·출처·연도/접수번호·참고 BPS 표시와 화면 설명을 유지한다.
- valuation의 출처 근거는 제한된 요약으로 저장하고 metricBasis의 중복 상세 근거를 제거한다.
- 상세 화면은 값/기간/통화/출처 식별이 일치할 때 기존 기간별 저장자료의 전체 근거를 읽는다.
- 캐시 형식9로 전환하며, 이전 캐시의 가격 스냅샷은 보존한다.
- 첫 조회용 메모리 캐시에도 같은 경량화를 적용한다.
- 원본 DART, 참고 재무자료, 추가 지표 저장값, 산식, 수집 설정 및 DB 전송 한도는 변경하지 않는다.

검증
- 운영에서 가져온 로컬 DB의 2,659행 목록을 실제로 계산·저장·재조회했다.
- 새 캐시 9,322,742바이트(약8.9MiB): 종전 계산 결과 대비 약58.1% 감소.
- 실제 DB 바인딩 파라미터 최대 9,322,865바이트로 16MiB 미만.
- 경량화 전후 목록의 숫자·가격·정렬 입력·주의 문구를 전체 행 대조했다.
- 재시작한 모델에서 PERSISTED_HIT 확인.
- 2025/2026년 KOSPI·KOSDAQ 목록 API 정상, STALE 없음.
- 상세 원본 근거가 긴 종목 및 삼성전자 상세 API의 근거를 기존 저장자료와 대조했다.
- dart_financial_filings / financial_statements / period_valuations 체크섬 변경 없음.
- 관련 자동 테스트23개 통과. shared 빌드 및 backend 타입 검사 통과.

상태 및 반영
로컬 수정·검증 완료. 사용자 승인에 따라 PR 검증·병합 후 1.2.25 운영 배포를 진행한다.
최종 운영 배포 및 원본 보존 검증 결과는 이 보고서를 연결한 PR의 배포 결과 댓글에 기록한다.
배포 시 형식8 캐시는 다음 갱신에서 형식9로 전환된다. DB 마이그레이션 및 원본 데이터 이관은 없다.
실제 수집 중 revision 변경이나 통신 장애 등 별도 실패에는 기존 이전 캐시 보존 동작을 유지한다.

복구
로컬 변경 전 캐시는 작업 폴더의 비공개 압축 사본에 보존했다.
문제 발생 시 코드 변경을 되돌리고 필요하면 파생 캐시만 재생성한다.
원본 재무자료와 지표 테이블을 복원하거나 덮어쓸 필요는 없다.
