# v1.2.42 종목 관리·손익 상세 및 ROE 기준 개선

- 범위: 종목 관리 카드/독립 가치지표 탭, 목록 복원, 결산·추정 공통 상세 직접 진입, 동일 연간 보고기간 확정 우선 표시, 현재가/표시 정밀도, 연간 손익의 월 클릭 시 연도 전체 상세 거래 카드와 월 포커스.
- BPS/주식수는 정수 표시, EPS와 나머지 지표 최대 소수 둘째 자리. 외화 원문 표시 및 원본/입력/저장/계산 정밀도는 유지한다. 추정 자료는 조회 전용이며 확정 자료와 혼합하지 않는다.
- ROE: 확인된 연간 연결 지배주주 순이익 / 기말 지배주주 자본. 기존 값 대비 절대 1%p 이상 차이는 투자 주의 표시. 수동 값·다른 지표는 보존한다.
- 로컬 보완 결과: 1,437기간, 주의 451건. W 계산 가능 1,706 -> 1,747 / 대상 2,555. 운영 결과는 최신 상태 재대조 후 별도 기록한다.

## 검증
- 공통 계산·W·기간 검증 40개 통과.
- 사용자 권한/손익/연간 상세 전환 DB 통합 2개 통과.
- 종목 관리 10개, 손익/스크랩 회귀 18개 브라우저 테스트 통과 (370x465 / 725x396).
- 프런트 빌드 및 프런트/백엔드/수집기 타입 검사 통과. Windows 실행 중 Prisma DLL 복사 잠금은 공유 모듈 직접 컴파일로 검증했으며 CI에서는 정상 전체 빌드를 확인한다.
- 외화 원문 정밀도 회귀 2개 통과. 공통 원문 표시는 반올림하지 않고 명시된 지표만 표시 반올림한다.
- 실제 로컬 결산·추정 직접 진입/현재가/조회 전용/가로 넘침 확인. 운영 확인은 배포 후 별도 기록한다.

## 선별 데이터 반영
`collector/dist/scripts/reprocess-closing-parent-roe.js`를 사용한다. 기본은 계획만 출력하며 `--apply`가 있을 때만 저장한다.

필수 인수: `--symbols-file <로컬에서 보완한 종목의 비공개 JSON allowlist> --output-dir <비공개 백업 경로>`. 운영에서는 `--production`도 명시한다.

2025 ANNUAL 지정 종목만 최신 공시/출처/기간/통화와 대조한다. 수동 ROE 보존, 기존 금융 lease, 원천 hash 및 updatedAt 조건부 저장, 변경 전후 사본/체크포인트/다른 지표 불변 검증을 사용한다. 보완 도구는 외부 API 호출·과거 수집 대기열·스케줄을 시작하지 않는다. 이미 완료된 필드는 건너뛴다. 로컬 재계획에서 ALREADY_APPLIED 1437 / eligible 0 확인.

## 복구
- 코드: 배포 전 구성요소 이미지 SHA를 보존하고 해당 이미지로 필요한 서비스만 복구한다. APK/인증 정책 변경 없음.
- 데이터: 전체 DB를 과거 사본으로 덮어쓰지 않는다. 선별 before/after 사본을 비교하여 이후 변경이 없는 행의 ROE 및 관련 원천/주의 메타데이터만 복구한다. 수동 입력/다른 지표/운영 추가 데이터를 보존한다.
- 과거 보완 스케줄은 계속 폐기 상태로 유지한다. 이번 작업은 이후 257/155종목 추가 보완을 실행하지 않는다.
