# 인제니아테라퓨틱스 증권신고서 2025 비교 연간 W 연결

2026-10-30 KST. 로컬 코드·DB 반영 및 검증 완료. 운영 배포/운영 DB 변경은 하지 않았다. 표시 버전 v1.2.45 유지. 집계 정책 SECURITY_W_ANNUAL_V10, 목록 캐시 스키마 17. DB 스키마·APK 변경은 없다.

## 결과

- 인제니아테라퓨틱스(950260) 2025년 연간 **원화 참고 W 계산 가능**. 전체 W 미충족 **67 → 66**, W 가능 2490. 이번 원화 참고 검토 12종목 모두 W 계산 가능.
- 검증 당시 BPS 443.77원, EPS -621.88원, 기말 자본 기준 ROE -134.87%, W 약 -0.2493. 음수 W를 0이나 절댓값으로 바꾸지 않았다.
- EPS가 음수여서 PER은 정상 미적용. 확인된 양수 PBR은 없어 **PBR 미수집 유지**. W 가능·지표 미수집은 37종목, 모두 충족 2453종목. 대상 2556·제외 105 유지. W 계산 가능이 전체 재무·지표 충족이라는 뜻은 아니다.
- 기존 저장 ROE와 참고 기말 ROE 차이는 -53.37%p. 1%p 기준을 넘는 주의 표시를 제공한다.

## 계산과 보호 기준

- 선택 열의 기수와 날짜를 BS·손익·자본변동표 모두에서 검사한다. 자산-부채=자본, 당해 연도 자본변동표 각 행의 구성 합계와 기초+변동=기말을 전 열 대조한다. 순손익 행과 기말 자본도 원문 본문과 일치해야 한다. 현재 분기·전기·별도 자료를 섞지 않는다.
- 귀속은 연결 자본변동표에서 비지배 열 없이 합계가 완전히 연결되고, 네이버의 지배주주 자본/순손익이 동일 제공처의 연결 합계와 정확히 같은 경우에만 **참고 귀속 계산**으로 적용한다. 직접 DART API 지배주주 태그를 수집했다고 주장하지 않는다. 제공처 수정 주식수 BPS를 쓰므로 주의 표시를 유지하고 보통주 분모를 확정했다고 표시하지 않는다.
- 기존 한투·네이버 교차 검증과 원화 환산 일관성 검사를 재사용한다. BS 기말 환산과 연간 손익 환산을 구분하며, 제공처 반올림의 기존 절대 오차 한도를 유지한다. 원화 지배주주 자본 19,610,000,000원·연간 순손실 -26,448,000,000원으로 기말 ROE를 계산했다.
- W에 직접 쓰이지 않는 매출 ‘—’는 0으로 만들지 않는다. 이 별도 공개 비교 원천 경로에서만 원문 매출 ‘—’·네이버 null·한투 0이 함께 확인되면 매출 대사만 제외하고 나머지 자산·부채·자본·영업손익·순손익·귀속 대사를 모두 수행한다. 일반 API 경로의 검증은 완화하지 않는다.
- 새 정규 연간 API 원천이나 수기/상위 출처가 있으면 이 비교 참고 경로를 우선하지 않는다. 해당 기간·종목의 원천을 다시 검증해야 한다. 기존 수기 항목이 있으면 덮어쓰지 않는다.
- 원화 참고 EPS/BPS/ROE는 KRW·조회 전용, 재무 본문과 원문 기반 순손익은 USD·조회 전용으로 표시한다. 상단 자료 기준은 ‘증권신고서 비교 연간 참고자료 / 제공처 수정 주식수 참고’로 구분한다. 설정 팝업을 다시 요구하거나 USD를 KRW로 저장하지 않는다.
