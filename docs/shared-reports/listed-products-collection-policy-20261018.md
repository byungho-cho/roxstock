## 목적과 범위

일반 기업 재무분석 기준을 그대로 적용하기 어려운 상장상품을 구분하고, 구조상 수집할 수 없는 재무·가치자료에 대한 불필요한 자동 재시도를 보류한다. 재무제표·가치분석 목록에서 자료 해석에 주의가 필요하다는 사실을 표시한다.

사용자가 정한 작업명은 ‘파생상품 수집 기능 보완’이다. 이 명칭으로 리츠·ETF·ETN을 모두 파생상품으로 분류하지 않는다. 실제 상품 유형은 각각 유지한다. 일반 기업이 아니라는 이유만으로 미확인 종목을 일괄 제외하지 않는다.

## 확정 정책

| 대상 | 처리 |
| --- | --- |
| 리츠 | 현재 재무자료 수집 보류를 유지하고 기존 자료는 보존한다. 반복 결산 지원은 추후 개발한다. |
| ETF·ETN·상장 파생상품 등 | 유형과 재무분석 적용 가능성을 확인한다. 재무·가치자료가 미지원 또는 구조상 수집 불가로 확인되면 이후 자동 재무 수집·보완에서 보류한다. |
| 일시적 통신·인증·호출 한도·DB 오류 | 상품 미지원과 구분하고 기존 오류·재시도 정책으로 관리한다. |
| 일반 기업의 결산월 변경·정정 공시 검토 | 별도 원인으로 관리한다. 비일반 상품으로 분류하지 않는다. |

- 주가·투자동향 수집은 재무 수집 보류와 별도 정책으로 유지한다.
- 보류는 성공이나 자료 없음으로 바꾸지 않고 사유를 보존한다.
- 기존 저장 자료를 삭제·초기화하지 않는다. 사용 가능한 자료는 기존 기준으로 표시한다.
- 근거가 부족한 지표를 임의로 계산하거나 다른 기간 자료로 채우지 않는다.
- 분류는 기존 종목 마스터의 신뢰할 수 있는 유형 정보를 우선 사용한다. 이름에 ‘리츠’ 등이 포함됐다는 이유만으로 확정하지 않는다.
- 유형 미확인과 수집 불가 확정을 구분한다.

## 자동 수집·보완 보류

- 기존 DB 작업 상태와 제외 정책을 재사용하고 필요한 경우 최소한의 분류·보류 사유 필드를 추가한다.
- 일반 DART 자동 수집과 가치지표 자동 보완 양쪽의 후보 선정 단계에서 보류 정책을 적용한다.
- 자동 후보에서 제외된 자료를 같은 조건으로 매번 호출하거나 재시도 큐에 재등록하지 않는다.
- 보류 유형·사유·적용 시각과 근거를 추적 가능하게 기록한다.
- 자동 수집 대상 여부를 판단하려고 전체 재무자료를 메모리에 올리지 않는다. DB 필터와 제한된 조회를 사용한다.
- 기존 보류 해제·수동 재검토 경로가 있다면 유지한다. 이번 결정이 수동 강제 수집 또는 검증 우회를 승인한 것은 아니다.
- 반복 결산·단기 결산을 지원하게 될 때 근거와 정책에 따라 재검토한다. 현재 보류를 영구 지원 불가로 단정하지 않는다.

## 재무제표·가치분석 목록 표시

커버 카드와 태블릿 목록 행 모두 동일한 분류 기준을 사용한다.

- 일반 종목과 구분되는 옅은 황갈색 배경을 적용한다.
- 종목명 옆에 실제 유형을 표시한다: ‘리츠’, ‘ETF’, ‘ETN’ 등.
- 노란색 주의 아이콘과 ‘지표 참고 주의’ 표시를 사용한다.
- 상승 적색·하락 청색 등 기존 수치 색상과 선택·포커스의 가독성을 유지한다.
- 색상만으로 의미를 전달하지 않고 유형·텍스트·아이콘을 함께 제공한다.
- 클릭 시 작은 툴팁 또는 안내 박스로 해당 종목의 적용 사유를 표시한다.

공통 안내 문구:

> 일반 기업과 분석 기준이 달라 지표 해석에 주의가 필요합니다.

재무 수집 보류가 적용된 리츠 안내 예시:

> 일반 기업과 결산 구조가 달라 일부 재무자료 수집과 가치지표 계산을 보류하고 있습니다. 표시된 지표만으로 투자 판단하지 않도록 주의해 주세요.

다른 상품은 실제 분류·보류 사유에 맞게 문구를 조정한다. 모든 상품에 ‘결산 구조’를 동일하게 적용하지 않는다.

‘투자주의’ 단독 표시는 사용하지 않는다. 거래소의 공식 투자주의종목 지정이나 해당 상품 자체의 투자위험 판정으로 오해하지 않도록 자료·지표 해석 안내임을 명확히 한다.

## DART 실행 #10480 조사와의 관계

[전체 조사 보고서](https://github.com/byungho-cho/roxstock/blob/investigation/dart-10480-20261018/docs/shared-reports/dart-run10480-investigation-20261018.md)의 기준 집합은 208개 작업·29개 고유 종목이다.

| 판정 | 작업 수 | 후속 방향 |
| --- | ---: | --- |
| 코드 수정 필요 | 9 | 일반 기업 3종목의 정상 대상 연도 기간 선택 오류를 별도 수정 |
| 검토 보류 타당 | 189 | 원인별 보류 유지. 리츠 등의 반복 결산 지원은 추후 검토 |
| 근거 자료 부족 | 10 | 근거 확보 전 보류 |

- 189건 전체가 리츠나 파생상품인 것은 아니다.
- 글로본·이화산업 등 일반 기업의 복수 결산과 KCC 등 정정 관계 보류를 상품 유형 보류와 혼동하지 않는다.
- 에이텀·프레스티지바이오로직·위더스제약의 9건 수정은 별도 작업으로 유지한다. 기간 선택 수정이 원본·통화 검증 통과나 수집 성공을 보장하지 않는다.
- validationResult의 API 전달 및 구체적인 화면 사유 표시는 연관 개선으로 관리하되, 상품 분류와 오류 사유는 별도 필드·의미로 유지한다.
- 208건 일괄 초기화·재수집 또는 검증 조건 일괄 해제는 이번 범위가 아니다.

## 구현 시 검증 기준

- 신뢰할 수 있는 종목 분류와 화면 표식이 일치한다.
- 리츠·ETF·ETN 등이 서로 다른 유형으로 표시된다.
- 확정된 보류 종목이 자동 재무 수집·보완 후보에 반복 등록되지 않는다.
- 일시적 실패나 일반 기업의 기간 검토가 상품 미지원으로 잘못 분류되지 않는다.
- 기존 재무자료·지표와 주가·투자동향 수집이 보존된다.
- 커버·태블릿의 배경·텍스트·툴팁과 손익 색상이 읽기 쉽다.
- 실제 구현 시 최신 main 기준 브랜치·PR·필수 검사를 거쳐 병합하고 필요한 서비스 배포를 시작한다. 코드 배포 버전은 기존 정책대로 증가시킨다.

## 이번 문서 작업

결정 사항만 기록한다. 운영 코드·DB 상태·수집 일정·분류 데이터 변경, 외부 DART 호출, 재수집, 재시작 및 배포는 수행하지 않는다. 문서만 변경하므로 앱 버전 증가는 없다.
