## 실제 프로그램 문제와 수정

1. 공개 원문 계정 보완을 별도 근거로 검증한다. 종목·접수번호·연결·통화·실제 기간·본문 URL/해시와 원문 6개 합계를 검사하며 API가 이미 제공한 귀속 값과 충돌하면 적용하지 않는다. 자본변동표는 실제 당해 연도 소유주 열·총계 열·기초/기말과 순손익을 대조한다.
2. JTC의 네이버 영업이익은 매출총이익-판관비이고 원문 영업이익은 기타영업수익/비용을 포함한다. 매출-원가=매출총이익, 일반 영업손익+기타영업수익-기타영업비용=공시 영업이익을 모두 검증한 경우만 제공처 표시 기준을 별도 대조한다. 기존 원문 영업이익은 변경하지 않는다.
3. 네오이뮨텍의 극소 매출은 제공처의 0.01억원 반올림으로 환산비율을 불안정하게 만들었다. 매출 하나 대신 절댓값이 가장 큰 손익 항목으로 기간 환산 비율을 대조하고, 모든 손익 항목의 기존 절대 오차 한도를 유지한다. 단순 검증 생략·오차 확대를 하지 않는다.
4. 네오이뮨텍의 참고 귀속 경로는 소유주 자본 구성, 동일 공시 주석의 모든 종속기업 당기/전기 100%, 연간 자본변동표 각 행 합계와 전 열 롤포워드, 원문/네이버 손익의 환산 일치를 함께 요구한다. 소유주 순손익의 직접 태그 수집으로 기록하지 않는다.
5. 상세 화면은 검증된 원문 기반 지배주주 순손익도 실제 원문 통화와 조회 전용 출처로 표시한다. 원화 참고 EPS/BPS/ROE는 KRW, 재무 원문은 USD/JPY로 구분한다.

## 인제니아테라퓨틱스의 구체적 보류 사유

최신 발행조건확정 문서(20260728000400)는 발행조건 위주여서 재무가 없었지만 실제 기재정정 신고서(20260721001229)에는 재무 본문이 있다. 2026년 1분기 열이 첫 열, 2025년 연간이 두 번째 열이다.

원문 2025년 USD: 자산 20,400,740·부채 6,734,510·자본 13,666,230·영업손실 -23,338,334·당기순손실 -18,596,626. 매출(영업수익)은 ‘—’. 한투/네이버 EPS·BPS 참고값은 있으나 이를 근거로 매출 ‘—’를 임의의 0으로 바꾸거나 지배주주 계정을 확정하지 않았다. 현재 경로는 검증된 정규 연간 공시 행을 기준점으로 삼으므로, 이 증권신고서 비교 연간 자료를 별도 원천으로 연결하는 후속 경로가 필요하다.

따라서 ‘공식 자료 자체 없음’이 아니라 **공식 비교 재무는 확보했고 현재 저장·검증 경로 연결이 미완료**인 사례다. 사업보고서 접수번호를 합성하거나 원문 표의 2026년 분기를 2025년 연간으로 저장하지 않았다. 기존 값을 그대로 보존했다.

## 검증 및 복구

- 관련 테스트 192개, shared 빌드·backend/collector 타입 검사·frontend 빌드 통과. 기존 번들 크기 경고는 유지. 커버 370×465·태블릿 725×396 원화 참고/원문 순손익 출처·단위·조회 전용 검사 2개 통과.
- 기존 12종목의 실제 DB·목록·상세 API를 재대조: W 가능 11종목, 보류 1종목. DART 원본의 **금액·계정 정보**와 PeriodValuation values/provenance 불변 확인. 단, 아남전자의 잘못 추정될 수 있던 누락 통화 메타데이터 1건은 USD로 정정했다.
- 수기 값·기존 자료·다른 기간·오류 이력·수집 제외 정책은 변경하지 않았다. 과거 수집 스케줄·대기열을 재개하지 않았다. 실제 금액·검증 상태와 무관한 오류 카드 정리는 하지 않았다.
- 공통 financial lease·수집 제외 검사·revision·행별 트랜잭션·원본 해시 및 체크포인트를 사용했다. 재실행 중복 저장 없음 확인.
- 비공개 work/fx5-before-private.json·fx5-applied-private.json에 전후 사본, fx5-verification-private.json에 실제 API 대조, fx5-documents-private/·fx5-notes-private/·fx5-registration-private/에 본문과 해시를 보관했다. 비밀값·개인 데이터를 공유하지 않는다.
- 복구는 변경 후 해시와 현재가 같은 행에 한해 같은 잠금 아래 supplemental만 선별 복원한다. 원문 숫자나 values/provenance를 덮어쓰지 않는다. 아남전자의 통화 정정은 사실 확인된 USD이므로 기본 복구 시 유지한다. 과거 sourceValidation으로의 단순 복원은 USD를 KRW로 오인하게 할 수 있으므로 피한다. 문제 시 참고 W 적용만 보류하고 통화 방어를 유지한다.
