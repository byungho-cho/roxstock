# 통합 알림 v1.3 개발 (2026-10-22)

기준 main: 866fd925, 별도 브랜치 feat/unified-notifications-v13-20261022. Figma C4001/T4001 v1.3의 목록·연결 매수·거래 폼을 확인했다. 이전 Firebase 서버 확인 문서 PR #297과 작업을 분리한다.

## 변경
- 공통 알림 목록과 좌측 44px 플로팅 버튼. 매수/매도/배당/소식/목표 구분, 99+ 배지, 표시할 알림이 없을 때 숨김.
- 기존 StockTradeForm과 LiveCashPage 등록 폼 재사용. 알림 진입만 자동 포커스/전체 선택 생략. 확인 가능한 값만 채움. 기존 소유권·거래·예수금 검증 유지.
- 매도 후보: 현재 로그인 사용자의 현재 계좌/종목에 한정하고 수량·한국 날짜 비교. 후보를 합치거나 자동 선택하지 않음.
- Android 상단 보관함 버튼 및 웹 대기목록 메뉴 제거. SQLite v2의 owner 별 보관함과 상태 tombstone 유지. 과거 owner 미확인 행은 보존하되 노출하지 않음.
- 서버 알림 이벤트에 읽음/무시/표시 필드 추가. 개인 인증 범위에서만 조회/수정. 거래 원문 서버 동기화 없음.
- 목표 알림은 기존 판정식을 조건별 호출하고 사용자/계좌/종목/조건/한국 날짜 unique identity에 저장. 동일 종목 여러 Lot·시세 재진입·동시 스캔은 하나로 합쳐짐. 읽음/무시는 identity를 지우지 않음.
- 종류별 사용자 설정에 거래 알림 기본 OFF 추가. 카카오 알림 접근과 OS 푸시 권한을 분리.

## 보수적 입력
현재 지원 원문은 미래에셋증권 전량체결/배당 입금 안내다. 파싱되지 않는 계좌는 현재 계좌나 기본계좌로 추정하지 않는다. 계좌 마스킹이 여러 계좌와 일치하거나 종목이 유일하지 않으면 수동 확인을 요청한다. 연도가 없는 거래일을 수신 연도로 추정하지 않는다. 매도일/수량/단가가 불명확하면 Lot 선택을 진행하지 않는다. 일반 웹에서는 카카오 원문을 읽을 수 없다.

## DB 적용과 복구
운영 적용은 하지 않았다. 배포 전 기존 절차로 DB를 비공개 백업하고 20261022090000_unified_notifications migration을 적용해야 한다. 신규 열은 additive이며 기존 거래와 알림 발생 이력을 삭제하지 않는다. 문제 시 이전 이미지로 복구하되 새 열/기록은 유지한다. 네이티브 DB v2를 v1으로 강제 downgrade하지 말고 동일 서명·더 높은 versionCode 수정 APK를 사용한다. 키/원문 DB/개인정보를 공개하지 않는다.

## 검증 현황
로컬 TypeScript 검사 및 backend 단위 테스트 148 통과/1 skip. 파싱/계좌/매도 후보 순수 테스트 2 통과. Chromium 설치 파일 다운로드 오류로 로컬 UI 실행 불가. CI에서 MariaDB 통합·커버 370x465/태블릿 725x396·Android 빌드/에뮬레이터 확인 예정.

실제 카카오 수신·실기기 키보드·FCM 발송·수신·클릭 이동은 미검증. 운영 DB migration·운영 배포·APK 배포는 미실행. 검증 완료 전 완료/배포로 표시하지 않는다.
