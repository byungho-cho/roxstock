## 저장 및 프로그램 보완

1. 기존 FinancialStatement의 DART_PUBLIC_REFERENCE 경로를 재사용했다. 실제 감사 접수번호·URL·해시·당기 열·단위·회계기준·기간을 보존했다. 사업보고서 접수번호나 API 성공을 가공하지 않았다.
2. 원/천원/백만원을 검증해 원 단위로 저장했다. 대차 합계·실제 1~12월 흐름·당기/전기·연결/별도를 대조했다. 단순 대시를 0으로 간주하는 파서 경로는 사용하지 않았다.
3. 정밀화한 한투 참고 13건의 이전 행 전체는 sourceMetadata.priorReference와 비공개 사본에 보존했다. 수기·상위 출처는 교체하지 않았다. 엘리스의 현재주식수 참고 EPS/BPS 2필드만 원문·네이버·한투 대조 후 연간 지표로 교체했으며 이전 값과 근거는 replacedFields와 사본에 보존했다.
4. 제공처 PBR 0은 기말 주가 근거가 없는 상태에서 정상 배수로 채우지 않았다. 과거 PER/PBR을 현재가로 계산하지 않았다. 비양수 EPS/BPS에 따른 정상 미적용을 유지했다.
5. 제공처 원래 평균 자본 ROE는 스냅샷에 그대로 둔다. 명시적 검토 대상이고 감사 원문과 6개 합계가 일치할 때만 기말 지배주주 ROE를 저장한다. 1%p 이상 차이는 주의 기록을 남겼다.
6. API 원본을 우선하면서, 없는 상세 화면에서도 외부 참고 재무를 실제 출처로 표시하도록 수정했다. 기준이 불충분한 참고 자료는 조회 전용이다. 자료가 없는 화면의 기존 최초 기준 설정 동작은 유지한다.
7. 한투 기본 조회는 기존 12월을 유지한다. 명시적인 실제 결산월을 전달한 경우만 다른 월을 조회한다. 4월 자료를 12월 자료로 오인하지 않으며 자동 수집 범위는 확장하지 않았다.
