## 계산·검증 개선

- 검증된 소유주 자본 구성항목에서 `이익잉여금(결손금)`과 `결손금`을 같은 계정 의미로 인정한다. 합계·비지배지분·접수번호·원문 URL/해시·중복 항목 검증은 유지한다.
- 이전에 KIS 억원 단위 참고값으로 보완했다고 명시된 순이익만 정밀 공시값과 구분한다. 원래의 KIS 단위·원시값·보고월·다른 5개 재무 앵커가 모두 확인되고 차이가 반올림 해상도 이내인 경우에만 허용한다. 실제 DART 순이익이나 수기 값의 불일치는 계속 차단한다. 기존 숫자를 덮어쓰지 않는다.
- 주요 계정 API의 순이익 행이 비어 있어도 매출·영업이익 두 항목과 기말 자본이 같은 접수번호·범위·일자로 정확히 일치하면 보고기간을 검증한다. 숫자가 있는 상충 행은 무시하지 않는다.
- 원문 지배주주 계정의 천원 단위는 명시적 원문 단위와 정확한 환산을 검증한다.
- 별도 감사자료에 현재 주식수를 사용하는 경로는 명시적으로 선택한 참고 계산이다. 연간 원문 6항목·회계기준·기간·원화·균형식·주식수 출처와 관측일을 검사한다. 없는 EPS는 임의로 채우지 않는다.
- 공식 공시의 원화 환산표는 외화 표와 동일 공시·기간·연결/별도 기준으로 대조한다. 기말 자본과 연간 손익 환산을 구분하며, 공시 환산액을 새로운 공식 환율 API라고 표현하지 않는다. 현재 주식수 기반 EPS/BPS는 참고값으로 표시한다.
- 코오롱티슈진은 연결 공시가 아니라 별도 공시임을 확인했다. 별도 원화 환산 자료의 연말 자본 기준 ROE는 기존 값과 약 -112.35%p 차이 나므로 투자 주의를 표시한다. 더 보수적인 값이라는 보장은 하지 않는다.
- 1%p 이상 ROE 차이와 현재 주식수·우선주·환산 참고 계산은 가치지표 상세에서 주의 안내를 제공한다. 참고 자료는 조회 전용이며 실제 기준·출처를 숨기지 않는다.
- 연간 판정 버전은 `SECURITY_W_ANNUAL_V11`, 가치 목록 캐시는 schema 18이다. 이전 버전 갱신 시 기존 주가 스냅샷을 유지한다.

## 운영 선별 반영 절차

1. 최신 운영 자료와 로컬 변경 전 사본을 다시 대조한다. 준비 시점 선별 계획은 216종목, 242행 작업(기간 지표 215, 재무 참고자료 21, 원천 통화 메타데이터 6)이며 충돌 0이었다. 시간 경과 후 다시 검증한다.
2. PR 검사·병합·기존 배포 워크플로로 v1.2.46 서비스를 반영한다. 배포 전 비공개 전체 DB 백업을 보존한다.
3. 최신 추가 백업과 선별 사본을 보존한 후, 비공개 manifest의 기본 읽기 전용 계획을 실행한다.
4. 실제 반영은 명시적 `--apply`로 수행한다. 기존 financial lease와 수집 정책·수기 값 보호·행 잠금·종목별 트랜잭션을 사용한다. 현재 값/출처가 변경됐으면 중단하며 전체 DB를 복원하거나 통복사하지 않는다.
5. 반영 후 원본 재무 숫자·다른 지표 보존, W 판정, DB revision·목록 캐시·실제 API·관리자/일반 사용자 권한을 확인한다. 과거 수집이 재개되지 않았는지 확인한다.

실행 코드·manifest·원문·변경 전후 사본은 비공개 보관한다. 개인 자산 데이터·자격 증명·DB 덤프는 Git에 포함하지 않는다. 복구는 기록된 변경 후 값과 일치하는 경로만 역대조하며, 신규 사용자 변경을 덮어쓰지 않는다. 코드 복구에는 인증·소유권 검사가 유지되는 직전 운영 이미지를 사용한다.
