# 종목소식 요약 최초 1회 정책 (1.1.22)

- 최초 소식 수집에서 제공된 요약을 저장하고, 요약이 없는 신규 소식에 한해서 공개 근거 추출을 한 번 시도한다.
- 제목이 저장되면 요약 유무와 무관하게 해당 소식은 성공이다. 제목 등 소식 메타데이터 수집 자체가 불가능하면 기존 원천 실패 기록을 유지한다.
- 요약 HTTP 요청의 전송 재시도도 하지 않는다. DART 공용 한도·수동 우선권·잠금 정책은 유지한다.
- 요약 없는 신규 항목은 NO_DATA, summaryAttempts=1, summaryNextRetryAt=NULL로 기록한다.
- 별도 보완 스케줄 호출을 제거하고 기존 news-summary 명령도 DISABLED를 반환한다. 기존 PENDING/RETRY 행은 보존하지만 처리하지 않는다.
- 모니터링은 종목소식 카드만 표시한다. 과거 요약 보완 이력은 삭제하지 않는다.
- DB 스키마 변경 없음. 이전 이미지 롤백 시 기존 미요약 행의 재시도 동작이 재개될 수 있으므로 수집기를 중지한 상태에서 정책을 검토한다.
- 검증: 수집기/서버 TypeScript 통과, 요약 테스트 8개 통과. 운영 외부 API를 이용한 강제 실패 재현은 하지 않음.
