# 2026-10-08 · 8·9차 개선 및 운영 상태 현행 명세

## 적용 원칙

1~7차는 [통합 명세](./20261007-improvements.md)를 유지한다. 같은 항목은 이 문서의 8·9차 확정 요구가 이전 시작연도·단일 사업연도 수동 갱신·유동비율 표시 규칙보다 우선한다. 과거 문서는 당시 이력이며 구현, 배포, 원천 데이터 보충 완료, 실기기 QA를 구분한다.

## 8차: 수집과 기간별 가치지표

- 우선종목은 활성 계좌의 매수 이력(전량 매도 포함), 수동 보유, 관심종목의 중복 없는 합집합이다. 추천종목은 우선순위에서 제외하며 기존 데이터는 삭제하지 않는다.
- 우선종목의 현재 연도 공개 자료를 먼저 처리한 뒤 과거를 역순으로 2015년까지 보충하고 일반종목을 처리한다. 신규 수집 하한은 2015년이다.
- 재무제표 저장과 가치지표 보충 상태는 별도다. 기존 정상 값·수동 보정을 보존하고 미공시·미수집·근거 부족·오류를 구분한다.
- ROE는 같은 연결/별도 기준의 순이익과 평균 자본으로 계산한다. PER/PBR은 해당 기간 말 이전 7일 내 마지막 거래일 비수정 종가와 동일 기간 EPS/BPS를 사용한다. 현재 주가·현재 주식 수를 과거 값으로 대체하지 않는다.
- 필요한 공시 EPS·주식 수·소유주 자본·과거 종가는 원천 보충 경로로 확보한다. 다른 사이트의 기록값은 출처·가격일·연결/별도·연환산 기준이 확인되지 않으면 혼용 저장하지 않는다.
- 종목 이전/다음 및 스와이프에서 선택 연도·연간/분기·조회 조건을 유지한다. 차트 드래그와 입력 조작은 종목 스와이프에서 제외한다.
- 계산식과 provenance 상세는 [8차 개발 명세](../development/improvements-phase8-20261007.md)를 참조한다.

## 9차: 표시·종료연도·공통 수동 갱신

- 종목 상세 보유현황의 날짜는 14px, 흰색, Bold(700)로 표시한다.
- 보유 요약 제목 우측에 '(재무제표)' 링크를 둔다. 기존 상세보기와 동일한 보조 텍스트 디자인으로 현재 계좌·종목의 재무제표 화면에 연결한다.
- 연간 비교는 선택 연도를 종료연도로 한 3개 연도다. 2026 → 2024·2025·2026, 2025 → 2023·2024·2025. 2015~2018 선택은 2018 종료연도로 정규화하여 2016·2017·2018을 표시한다. 이 화면 경계 규칙은 수집 하한 2015년과 별개다.
- 기존 시작연도 URL은 종료연도 계약으로 변환한다. 종목 이동 시 연간/분기와 기간 조건을 보존한다.
- 유동비율은 표·차트·범례에서 숨기고 기존 저장 값은 보존한다.
- '전체 재무지표'의 재무제표 갱신 진입과 가치분석 상세는 동일한 입력 폼/공통 팝업을 재사용한다.
- 공통 폼은 기존 입력 디자인의 시작연도·종료연도·갱신범위 선택과 '저장 데이터 차트 보기', '수동 업데이트' 버튼으로 구성한다. 갱신범위는 1분기·반기·3분기·사업보고서·연도 전체다. 시작연도가 종료연도보다 늦으면 실행을 막는다.
- 최초 기본 범위는 화면에 표시된 기간이며 사용자가 지정한 기간·보고서와 현재 종목만 갱신한다. '저장 데이터 차트 보기'와 화면 GET은 외부 수집을 시작하지 않는다.
- 갱신 중 실행 버튼/기간 입력을 비활성화하고 모래시계 진행 아이콘을 표시한다. 완료 후 호출 화면을 재조회하고 버튼을 활성화한다. 실패도 기존 데이터 보존·오류 안내·재시도를 제공한다.
- 서버 공유 락과 RUNNING 검사를 재사용한다. 팝업 닫기·재진입 후 요청 ID로 상태를 추적한다. 진행 상태 조회 실패 시 완료로 추정하거나 중복 실행하지 않는다.
- 클릭 직전 스크롤 저장으로 매매일지 일별손익 전환·복귀 회귀를 보완한다.

## 데이터 검증 범위와 남은 확인

[9차 QA 보고서](../qa/phase9.md)의 내부 테스트 DB에서 2024·2025년 연간 재무제표 1,104건을 보충 계산했다. ROE 1,049건, PER/PBR 0건이다. 외부 수집은 네트워크 제한으로 검증하지 못했으며 이 결과는 운영 DB 보충 완료 근거가 아니다.

- 운영의 공시 원천·과거 종가 수집 성공 및 실제 지표 저장/API 대조는 미확인이다. 기능 배포 성공을 모든 가치지표 채움 완료로 보고하지 않는다.
- 과거 종가 API는 전용 DATA_GO_KR_STOCK_PRICE_KEY 또는 기존 DATA_GO_KR_SERVICE_KEY를 사용한다. 인증 설정·권한·응답은 실제 운영 실행으로 확인해야 한다.
- 일반 사이트 대체 수집의 추가 구현/운영 성공은 확인되지 않았다.
- 일회용 운영 인증정보 백업은 최신 트리에서 제거됐지만 이전 Git 기록에 남는다. 관련 인증정보 교체 완료는 확인되지 않았으며 후속 운영 항목으로 관리한다. 비밀 값은 문서에 기록하지 않는다.
- 타입·빌드·관련 회귀 결과와 fixture/실제 내부 DB 캡처는 QA 보고서에 있다. 운영 실기기 전체 QA·Figma 최신 동기화는 이번 확인에서 수행하지 않았다.
- Markdown을 현행 원본으로 사용한다. 기존 PDF는 과거 작성 시점 배포본이며 8·9차 현행본으로 간주하지 않는다.
