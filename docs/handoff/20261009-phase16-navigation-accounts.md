## 구현 계약 및 확인 사항

계좌 선택은 기존 공통 accountId 상태와 연결한다. DB 기본계좌 변경으로 대체하지 않는다. 항목 이름은 계좌명이며 종목명이 아니다. 커버/태블릿 모두 한 줄 이름(계좌번호), 오른쪽 사용 중, 행 세로 중앙, 굵은 녹색 사용 중을 적용한다. 긴 계좌명은 말줄임하며 전체 계좌 식별을 제공한다. 활성 계좌 목록/표시 순서는 기존 계좌 관리 규칙을 따른다.

종목 추가 검색은 종목 마스터 존재 여부와 선택 계좌 등록/분류를 구분한다. 전역 symbol 중복을 계좌 중복으로 안내하지 않는다. 기존 거래 이력/잔여수량에 따른 분류 변경 제한을 임의 해제하지 않는다. 직접 추가 409는 기존 종목으로 연결하거나 가능한 등록 경로를 안내한다. 실제 KODEX 200의 운영 등록 상태는 개발 시 확인한다.

거래 성공 응답에서 정확한 연결 예수금 ID를 얻는다. API가 ID를 제공하지 않으면 서버 응답 계약을 보완한다. 매수/매도 저장 실패에는 제세금 확인창을 표시하지 않는다. 제세금 취소/수정 실패에도 이미 저장된 거래를 유지한다. 이중 제출·거래/예수금 중복 생성 방지, 다른 계좌의 내역 수정 차단을 검증한다.

일반 팝업 history 처리에는 중첩 팝업과 X/외부 닫기 시 history 정리를 포함한다. 가장 위 일반 팝업을 우선 닫고 배경 조회 조건을 유지한다. 확인/알림은 제외한다. 구현 방식은 현재 라우터 구조에 맞춘다.

## 추가 보완 · 계좌 관리 카드의 계좌번호 표시 (2026-10-09)

상태: 사용자 후속 확정에 따른 개발 보완 항목. 문서 기록이며 이번 작업에서 앱·Figma 화면 수정이나 배포를 수행한 것은 아니다.

- 설정 → 계좌 관리의 각 카드에서 계좌명 오른쪽에 저장된 계좌번호를 괄호로 감싸 같은 줄에 표시한다. 예: `초기 계좌 (010-2222-0000-1)`. 예시 번호를 고정값으로 사용하지 않는다.
- 계좌명은 기존 제목 스타일을 유지한다. 괄호를 포함한 계좌번호는 카드 하단의 ‘최근 수정’ 문구와 동일한 글꼴·크기·굵기·색상으로 표시한다. 별도 크기를 임의 지정하지 않고 해당 보조 문구 스타일을 재사용한다.
- 선택 계좌의 노란 제목·테두리, 금액, 사용 중/선택 버튼, 수정 아이콘 및 최근 수정 날짜 표시는 유지한다. 노란 제목 강조를 계좌번호의 보조 글씨에 함께 적용하지 않는다.
- 긴 계좌명·계좌번호가 선택 버튼이나 수정 아이콘과 겹치지 않도록 하고, 좁은 화면에서 말줄임이 필요한 경우 전체 계좌 식별 정보를 확인할 수 있게 한다. 계좌번호가 없는 기존 데이터에는 빈 괄호나 예시 번호를 표시하지 않는다.
- 검증: 선택/미선택 카드 모두 이름 옆 실제 계좌번호, 최근 수정과 동일한 계좌번호 글씨 스타일, 커버·태블릿에서 겹침 없음, 계좌 수정 후 번호 갱신을 확인한다. 홈의 계좌 선택 팝업에 관한 기존 16차 요구는 유지한다.
