# 2026-10-16 작업 중단 및 재개 메모

현재 브랜치의 수정 파일은 로컬에 저장되어 있으며 아직 커밋·푸시·배포하지 않았다. 사용자 요청으로 오늘 작업을 종료하고 다음에 이어서 진행한다.

## 구현 내용
- 투자동향 모바일 거래실적 날짜 줄바꿈 방지, 행 간격 축소, 단위 라벨 정리.
- 날짜 변경은 당일 순매수만 갱신하며 이전 숫자를 응답 전까지 유지. 차트와 거래실적 기준일은 유지.
- 개인 청록색, 외국인 살구색, 기관 보라색의 실선 차트. 종가 및 등락 색상을 툴팁에 추가.
- 출처 설명을 문단 단위 툴팁으로 이동. 조회 기간을 차트 제목 옆에 표시.
- 당일 순매수 금액은 절댓값 1억원 이상 억원, 미만 만원. 거래량은 1억주 이상 억주, 미만 만주. 소수 최대 두 자리. 시장 거래량 원본 천주를 주로 환산한 뒤 적용. 차트와 거래실적 단위는 기존 유지.
- KRX/NXT 종목별 별도 수집 및 보관, 화면 조회 시 합산. 한 거래소 자료가 없으면 0으로 간주하지 않음. 종가는 KRX 기준.
- NXT 로컬 테스트는 2026-08-16 이후 약 두 달, 37개 대상 완료. 전체 2020년 로컬 수집은 하지 말 것.
- KIS 최신 참고 지표 및 주식수·외국인 보유 정보 보완: 별도 테이블과 예약 수집. 과거 DART/KRX 계산값은 덮어쓰지 않음.
- 신규 마이그레이션 20261016130000_kis_fundamentals는 로컬에만 적용.

## 확인 결과와 남은 사항
- 수집기 테스트 20개, 백엔드 투자동향/합산 테스트 10개 통과(이전 검증).
- 모바일 370/725 폭 UI 및 날짜 전환·툴팁 검증 통과(이전 검증).
- 마지막 단위 포맷 단위 테스트 2개 및 프런트 타입 검사 통과. 마지막 단위 변경 후 브라우저 검증은 다음 작업에서 수행.
- 시장 전체 KOSPI/KOSDAQ NXT 투자자 동향은 공개 KIS 명세상 별도 선택 지원을 확인하지 못했다. 종목 합계를 전체 시장으로 대신하지 않는다.
- 10/15 타 서비스 비교에서 거래소 범위 및 외국인 분류 차이가 확인되었으나 모든 차이의 최종 근거는 미확정. 정확한 통합 시장값이라고 단정하지 않는다.
- 설명 툴팁/조회 기간/단위 표시 마지막 변경을 포함해 최종 리뷰와 필요한 회귀 검증 후 배포 준비.
- 운영의 당일 수집은 계속되어도 된다. 배포 시 운영 DB 유지, 로컬 DB를 운영에 덮어쓰지 않는다. 운영 진행 상태·마이그레이션 호환성·수집기 중복 실행 여부 확인 필요.
- 키/토큰/운영 데이터는 Git에 추가하지 않는다. 로컬 도우미와 QA 산출물은 저장소 상위 폴더에 있다.
