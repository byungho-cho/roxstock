- 예수금은 거래일이 아닌 등록시각/id 기준 최신 1건만 수정·삭제 가능. 현재 잔액에서 이전 영향을 취소하고 수정 영향을 반영하며 과거 스냅샷은 재계산하지 않는다. 삭제 후 다음 최신 1건을 차례로 보정 가능. 매수/매도 예수금 내역 보정은 원본 거래/보유수량에 영향을 주지 않는다. 서버에서도 최신 여부 검증 및 Serializable 트랜잭션 적용.
- 입금·출금·배당·매수·매도 삭제 확인창: 유형별 제목/대상/날짜/금액, 외곽선 취소/적색 삭제. 원본 거래 삭제와 예수금 내역 보정을 구분한다. 연결 매도 있는 원본 매수 삭제는 차단한다.
- 매매일지→일별손익은 URL 이력으로 이동하여 브라우저 뒤로가기 복귀. 거래현황 카드 전체 스와이프 시 날짜제목 상단 정렬 유지, 달력 스와이프 시 스크롤0. 축 고정 및 스와이프 후 클릭 차단.
- 일별손익에 조회일 스냅샷의 보유 종목 평가손익/기여도 카드 추가. 과거 데이터 없으면 없음을 표시하고 현재값으로 대체하지 않는다. 일별손익 매수/매도는 각각 독립 거래 상세로 이동(수정·삭제 포함), 매매일지 기존 이동은 유지.
