## 2026-10-07 · 개선 개발 지시문 (사용자 확정)

상태: 1차 요구 확정 당시 기록. 현재 구현·배포 여부는 개발 기록과 별도로 확인한다. 올해 투자금 요약은 아래 3차 명세로 변경되며, 종목 상세 코드 행은 QA 후 명세가 우선한다.
이번 절은 동일 항목의 이전 명세보다 우선한다. 2026-10-06 인수인계의 미완료 요구는 계속 유효하다. 기존 데이터 복구와 이번 소스 개선을 구분한다.

### 1. 종목 상세 보유현황 정렬
보유 Lot 카드는 매수일 내림차순으로 표시하여 최근 매수일이 맨 위에 온다. 같은 날짜는 일관된 보조 키로 정렬한다. 커버·태블릿 모두 적용하고 보유량·손익 계산은 변경하지 않는다.

### 2. 종목 상세 거래내역 상단 카드
거래내역 탭의 현재가·전일 대비 카드를 해당 종목 전체 기간의 **매매손익 금액·수익률** 요약으로 교체한다. 현재 계좌·종목의 투자손익 상세 ‘매매손익’과 동일한 집계·분모를 재사용한다. 총 매수금 대비 기준을 확인하여 두 화면의 금액·비율이 일치하도록 한다. 배당과 미실현 평가손익은 제외한다. 매수 동작은 유지한다. 요약·보유현황 탭의 현재가 카드는 기존 정책을 유지한다. 전량 매도 종목·부분 매도·손익 0·분모 0·조회 실패를 구분한다.

### 3. 과거 내역 화면 자동 갱신 제거
투자손익 및 과거 거래 조회 등 한 번 조회한 자료를 재사용할 수 있는 화면은 재활성화·포커스 복귀·화면 재진입에 따른 무조건 재조회와 주기적/실시간 갱신을 제거한다. 캐시가 있으면 즉시 표시한다. 거래·배당 등록/수정/삭제 성공 시 관련 캐시를 무효화하고, 계좌·연도·종목 등 조회 조건 변경 시 해당 조건 자료를 조회한다. 계좌·기간·종목별 캐시를 격리하고 오래된 응답 혼입을 차단한다. 현재가가 필요한 홈·보유평가 화면 및 서버 수집 기능의 갱신은 유지한다. 실패를 0원으로 대체하지 않는다.

### 4. 종목 이동 이름 한 줄 표시
투자손익 종목 상세의 좌우 이전/다음 종목명은 한 줄 말줄임으로 표시한다. 폭이 부족한 경우 최대 5글자와 …로 축약하고 중앙 종목명을 침범하지 않는다. 전체 이름은 접근성 이름으로 제공한다.

### 5. 투자손익 종목 상세 스와이프
본문 좌우 스와이프로 종목을 전환한다. 왼쪽은 다음, 오른쪽은 이전이며 진입 목록의 현재 정렬 순서와 좌우 버튼 순서를 따른다. 처음·마지막 종목에서는 멈춘다. 인접 종목을 선조회하되 다른 종목 데이터를 새 제목 아래 표시하지 않는다. 세로 스크롤·버튼·입력·차트·뒤로가기 제스처와 충돌하지 않게 한다.

### 6. 연도별 투자손익의 투자금 기준
지난 연도는 해당 연말 스냅샷의 투자금을, 진행 중인 올해는 해당 연도의 가장 마지막 유효 스냅샷 투자금을 사용한다. 올해를 무조건 어제 날짜로 고정하지 않는다. 기준일을 함께 확인할 수 있게 한다. 누적 매수금·실시간 평가금액으로 대체하지 않는다. 연말 스냅샷 누락 시 대체일 정책은 별도 확정 전까지 미수집으로 구분하며 임의 날짜로 조용히 치환하지 않는다.

### 7. 종목별 손익 정렬·총계 위치
연도 상세 ‘종목별 손익’과 투자손익 종목별 탭 ‘종목별 누적 수익’은 **부호를 포함한 손익액 내림차순**을 기본으로 한다. 절댓값·수익률 정렬이 아니다. 제목 오른쪽에 내림/오름 토글을 두며 재정렬 시 종목·수익률·금액을 함께 이동한다. ‘총 N개’는 제목 옆으로 옮긴다. 선택 종목 상세의 이웃 이동도 현재 목록 정렬을 따른다.

### 8. 월별 매매·배당 텍스트 색상
투자손익 종목 상세 ‘월별 손익·배당 내역’의 유형 텍스트는 매매=해당 행 손익색(이익 적색/손실 청색/0 중립), 배당=노란색으로 표시한다. 금액 색상은 기존 정책을 유지한다.

### 9. 홈 로딩 성능 개선
첫 진입과 재진입의 API 응답 시간·중복 요청·직렬 의존·렌더링 대기를 측정하고 병목을 튜닝한다. 캐시가 있으면 즉시 표시하고 필요한 갱신은 뒤에서 수행한다. 캐시가 없는 첫 진입은 준비된 카드부터 표시하고 미완료 카드에만 로딩 상태를 둔다. 전체 API가 끝날 때까지 화면 전체를 막지 않는다. 임시 0원이나 다른 계좌의 자료를 표시하지 않는다. 동일 조건의 수정 전후 첫 유효 카드 표시 시간·전체 로딩 시간·요청 수를 보고한다.

### 10. 매매일지 거래현황 스와이프 개선
날짜·요약·거래 목록·빈 상태를 포함한 거래현황 카드 전체에서 날짜 스와이프가 동작하도록 영역을 넓힌다. 거리·속도·가로/세로 방향 판정을 조정하여 짧은 의도적 가로 움직임도 자연스럽게 인식한다. 세로 스크롤을 우선 보호하고 버튼 클릭을 오인하지 않으며 한 제스처당 한 날짜만 전환한다. 왼쪽 다음 날/오른쪽 이전 날, 날짜 버튼과 동일한 경계 규칙을 사용한다. 인접 날짜 선조회와 요청 중복 방지를 적용한다. 거래 없는 날짜도 동일하게 동작한다.

### 11. 일별손익 스와이프 추가
날짜 선택부·전체손익·실현손익·거래현황 등 본문 전체에서 좌우 스와이프로 날짜를 전환한다. 방향·감도·축 판정은 거래현황과 공통으로 관리한다. 세로 스크롤·행 상세 진입·버튼 동작을 보존한다. 헤더·하단 메뉴는 고정하고 인접 날짜 캐시를 재사용한다.

### 12. 투자금 화면의 누적 매매손익 표시
현재 평가금액 카드 아래 ‘투자금 대비 차액’을 **선택 연도의 누적 매매거래 실현손익**으로 변경한다. 올해는 ‘올해 누적 매매손익’, 과거는 ‘YYYY년 누적 매매손익’으로 표시한다.
- 금액 = 해당 연도 매도 거래의 실현손익 합계. 배당·미실현 평가손익 제외.
- 비율 = 해당 연도 누적 매매손익 ÷ 해당 화면의 누적투자금 × 100. 분모 0은 —.
- 색상은 손익 금액의 양/음/0을 따른다. 상단 평가금액의 값은 변경하지 않는다.
- 분기 선택은 기존대로 차트·투자내역에 적용하며 이 요약은 연간 값이다.
- 사용자 확인용 예시: 평가금액 81,845,732원 / 누적투자금 107,317,732원 / 올해 누적 매매손익 +39,720,500원 / +37.0%. 화면 예시이며 운영 API 검증값으로 간주하거나 코드에 고정하지 않는다.

### 개발 순서·검증·인계
손익·스냅샷 기준(2/6/12)을 먼저 구현하고 정렬·표시(1/4/7/8), 캐시·로딩(3/9), 공통 스와이프(5/10/11)를 진행한다. 소스 변경은 별도 브랜치와 PR로 제출하며 v0.1 복귀 기준을 유지한다. 이번 개선으로 기존 매수·매도·배당·예수금 원본이나 과거 스냅샷을 임의 수정하지 않는다.

**웹서버 담당:** 필요한 API·집계·캐시 계약 변경 및 API 검증만 수행한다. 브라우저 검증은 요구하지 않는다. 정상 응답뿐 아니라 집계 대조·빈 결과·실패·계좌/연도/종목 경계·배당 제외·분모 0을 검증하고 응답 예시와 결과를 남긴다.

**프런트 담당:** 화면 연결·캐시 무효화·정렬·색상·스와이프·홈 성능을 구현하고 브라우저/실기기 검증을 맡는다. 작은 화면·태블릿, 가로/세로/대각선 제스처, 빈 날짜, 빠른 전환, 뒤로가기·스크롤 복원, 포커스 복귀 시 불필요한 요청 제거를 확인한다.

## 2차 · 투자금 차트 및 투자내역 (2026-10-07 확정)

### 요약 카드와 차트
- 초기투자금·누적투자금·배당 카드의 배당 제목과 금액 모두 이익색 적색. 투자손익 월별 배당 유형 텍스트의 노란색 규칙과 적용 화면이 다르다.
- 요약 차트를 유지하고 가로 가이드선 옆/위에 작은 만원 단위 눈금(예: 6,800만)을 표시한다. 실제 범위에 따라 계산한다.
- 터치/가로 드래그 및 마우스 조회: 실제 스냅샷 날짜의 세로 가이드선, 시계열 선택점, 날짜·투자금·평가금액 툴팁. 툴팁 금액은 쉼표 포함 원 단위.
- 없는 값을 0으로 채우거나 임의 보간하지 않는다. 툴팁 잘림, 세로 스크롤·연도 스와이프 충돌을 방지한다.
- 제목 오른쪽 상세보기로 크게 보는 내부 상세 화면에 진입한다. 계좌·연도·분기를 전달하고 복귀 시 조건과 스크롤을 복원한다. 브라우저 Fullscreen API는 필수가 아니다.
- 상세보기는 시범 적용이며 실제 서비스 확인 후 채택한다. 이후 사용자 결정: 차트 기능은 수용, 상세 화면 추가 개선은 보류, 뒤로가기 오류만 3차에서 수정.
- 현재 구현을 우선 활용한다. 라이브러리 필요 시 React/TypeScript·모바일·번들·성능·다크 테마·라이선스·변경 범위를 비교하여 먼저 제안한다. 다른 차트까지 임의 확대하지 않는다.
- Figma 검토 예시: [요약 3663:3](https://www.figma.com/design/HFguP6QYb6xnO9FRsjYlc2?node-id=3663-3), [상세 3667:2](https://www.figma.com/design/HFguP6QYb6xnO9FRsjYlc2?node-id=3667-2). 디자인 샘플 금액은 고정 데이터가 아니다. 예시에는 이후 표·3차 변경이 모두 반영된 것이 아니다.

### 투자내역 및 일별손익
- 날짜 | 투자금 | 평가금액 | 일별손익. 최신 날짜순, 금액 우정렬, 커버에서 잘림 방지.
- 일별손익 = 당일 총자산 − 전일 총자산 − 당일 외부 순입금. 외부 순입금 = 외부 입금 − 외부 출금.
- 매수·매도는 내부 이동이며 배당은 이익이다. 둘 다 외부 입금으로 차감하지 않는다.
- 평가금액이 예수금 포함 총자산인지 확인하고 주식평가액만이면 매매·예수금을 반영하여 총자산 기준으로 계산한다.
- 같은 계좌 일별 스냅샷 사용. 실시간 시세를 과거값에 혼합하지 않는다. 전일 누락은 —, 여러 날 차이를 하루 손익으로 표시하지 않는다.
- 필터 첫 행의 전일 자료도 조회 범위 밖에서 확보한다. 단순 입출금만 있으면 손익이 발생하지 않아야 한다.
- 양수 적색/+·음수 청색/−·0 중립색. 차트·툴팁·표는 동일 날짜/스냅샷 기준. 기존 API 우선, 중복/실시간 조회를 추가하지 않는다.
- 원본 거래·예수금·배당·스냅샷을 수정하지 않는다.

## 3차 · 화면·차트·로딩 개선 (2026-10-07 확정)

### 1. 종목목록 카드
평가손익 → 손익. 손익 레이블도 금액 부호에 따른 적색/청색/중립색. 카드 레이블·금액 볼드, 손익 금액 굵기를 위 평가금액과 통일.

### 2. 종목목록 정렬
평가금액 바로 아래 손익률 추가. 카드 평가손익률 사용. 손익 금액·손익률은 수익 → 0 → 손실 그룹 순서 유지:
- 내림차순: +100 → +10 → 0 → −100 → −10.
- 오름차순: +10 → +100 → 0 → −10 → −100.
수익/손실 각각 크기로 정렬하며 손실 그룹은 절댓값 비교. 전체 절댓값 정렬이 아니다. 누락 마지막/동률 일관된 보조 기준. 이 변경은 종목목록만 대상이며 투자손익 목록의 부호 포함 수치 정렬은 유지.

### 3. 검색 초기화
종목목록 검색어 있을 때 우측 X. 검색어만 초기화하고 분류·정렬 유지. 빈 검색어는 버튼 숨김.

### 4. 기간 성과 구성
제목 우측 날짜/기간을 볼드·노란색 강조. 계산은 유지하고 다음 순서:
1. 기간 시작자산
2. 기간 종료자산
3. 기간 투자손익
4. 투자수익률
5. 구분선
6. 총입금
7. 총출금
8. 순입출금
9. 구분선
10. 평가손익
11. 실현손익
12. 배당수익
13. 수수료·세금

### 5. 자산추이
2차 투자금의 가이드선·선택점·터치/드래그·원 단위 툴팁을 대시보드와 자산분석 자산추이에 적용. 기존 시계열과 데이터를 유지한다.
- 그래프 영역은 각각 기존 높이의 2배. 앞선 높이 확대 지시와 통합하며 4배 확대 금지.
- 범례·Y축 금액 레이블·차트 전용 상세보기 없음. 총자산 등 다른 상세 이동은 유지.
- 하단 날짜 작게. 자산분석 1개월 MM/DD(09/07), 전체 YYYY(2024), 나머지 기존 유지. 전체에서는 같은 연도 눈금 반복 방지.
- 가로 차트 드래그와 세로 스크롤/화면 스와이프 보호, 툴팁 잘림 방지.
당초 2차 확인 후 적용 조건이었으나 사용자가 차트 기능 확인 후 적용을 확정했다.

### 6. 최근 매수
제목 우측 이달 N건 = 한국시간 이번 달 1일부터 현재까지 실제 매수일 기준 현재 계좌 매수 거래수. 종목수가 아니며 같은 종목의 여러 매수도 각각 집계.
- 기본 최근 목록은 유지. 제목 집계 변경으로 목록을 이달 거래만으로 제한하지 않는다.
- 시세·거래 데이터 판정 불가 N건 안내 숨김. 계산불가 — 및 조회 실패/재시도 유지.
- 더보기는 화면 이동 없이 같은 카드에 이전 달 단위 거래를 순차 추가. 기본 목록에 포함된 거래 중복 제거, 최신 매수일순, 중복 클릭/응답 보호.
- 확장해도 이달 건수 유지. 더 조회할 과거 거래가 없으면 버튼 숨김.
- 수익률은 매수단가 대비, 손익은 잔여수량 기준으로 계산되는 불일치는 별도 점검. 임의 정책 변경 없이 원인/권장안 보고.

### 7. 보유종목 상세 이동
하단 더보기 제거. 제목 보유종목 (상세보기), 제목 영역 전체 클릭 → 현재 계좌 보유종목 목록. 개별 행 상세 이동 유지.

### 8. 올해 평가손익
올해 투자금 상단의 올해 누적 매매손익 → 올해 평가손익.
- 금액 = 올해 실현 매매손익 + 현재 보유종목 평가손익.
- 보유 평가손익 = 현재 주식 평가액 − Lot별 잔여수량 × 해당 매수단가 합계.
- 전년도 매수 잔여분도 원래 매수가 기준 포함. 이미 매도한 수량 중복 금지.
- 비율 = 위 금액 ÷ 화면의 기존 누적투자금 × 100. 분모0 —.
- 예수금/배당 제외. 추가 매도 수수료·세금 제외. 현재가에 전량 체결 가정이며 연초 대비 총자산 변화액과 다르다.
- 합산 부호에 따른 색상. 현재 평가금액 값 유지, 분기와 무관한 올해 요약. 과거 연도는 기존 연간 실현손익 유지하며 오늘 평가손익 합산 금지.
- 시세누락 0 대체 금지. 1차 12항의 올해 표시를 대체한다.

### 9. 투자금 차트 상세 뒤로가기
브라우저와 화면 뒤로가기 모두 직전 투자금으로 복귀. 계좌·연도·분기 보존, 상세 진입 이력 정상 기록. 다른 화면으로 빠지는 오류 수정. 상세 디자인 추가 개선 보류.

### 10. 투자금 요약 차트 배치
금액 눈금 우측 → 좌측. 눈금/그래프 여백 최소, 필요 시 내부 오버랩으로 폭 확보. 평가금액·투자금 범례는 차트 내부 상단 중앙 오버랩. 별도 범례 공간 축소, 글자 가독성 및 터치 보호. 작은 화면 눈금·툴팁 잘림 방지. 상세 추가 배치 개선은 보류.

### 11. 당겨서 새로고침
브라우저 기본 기능 우선. 본문 최상단에서 현재 본문 스크롤 구조로 작동하는지 확인하고 정상일 때 별도 앱 원형 표시/제스처 추가하지 않음. 기존 앱 기능과 이중 실행 방지. 미작동 시 원인/최소수정안 보고, 스크롤 전면 변경 금지. 기본 동작은 페이지 재로드이며 앱이 브라우저 UI를 직접 제어하지 않는다. 최상단 실행이므로 임의 스크롤 위치 유지 요구는 없다.

### 12. 메인 로딩바
공통명칭 메인 로딩바. 앱 최상단 헤더 위 2~3px 진행선, 주소창 제어 없음, 레이아웃 이동 없음, 완료 후 숨김.
- 일반 조회의 반복 로딩/갱신 문구 대체. 현재 화면 필요 요청의 동시 상태를 하나로 표시.
- 주기 시세/선조회마다 깜빡임 방지. 진행률 모르면 indeterminate, 가짜 완료율 없음.
- 기존 데이터 유지, 최초 빈 영역 스켈레톤 유지. 오류/재시도·수집 작업 실제 진행상태 유지.

## 6차 · 종목 탭·손익 연결·분기 선택 스크롤

- 종목 상세에서 스와이프로 종목을 이동해도 현재 요약/보유 현황/거래내역 탭을 유지한다. URL detailTab, 진입 목록 순서, 선조회 및 뒤로가기 상태를 보존한다.
- 거래내역 연도 제목에 작은 회색 일반 굵기 (상세보기). 제목바 클릭 → 현재 계좌·해당 종목의 투자손익 상세(종목 전체 기간). 연도 제목 클릭을 계좌 연도 상세와 혼동하지 않는다.
- 요약의 거래 요약 제목·스타일을 유지하고 내용은 전체 거래 요약으로 교체한다: 매수총액/매도총액/매매손익 및 수익률/배당포함 총손익 및 수익률. 제목 우측 (상세보기), 카드 전체 → 종목 투자손익 상세.
- 요약에 계좌 전체 기준 연도별 손익 카드 추가. 제목바 → 계좌 연도별 목록, 연도 행 → 계좌의 해당 연도 상세. 당시 추가한 별도 거래내역 제목은 7차에서 제거한다.
- 투자금 요약 차트의 전체/분기 클릭 후 차트 제목을 고정 헤더 바로 아래에 맞추고 조회 완료 후에도 그 위치를 유지한다. 단순 문서 최상단 이동이 아니다. 지연 응답·빈 분기·태블릿 내부 스크롤 및 기존 복원 훅과 충돌하지 않게 한다.

## 7차 · 차트 상세 완성 및 손익 화면 연결

- 투자금·자산추이 상세 차트 모두 왼쪽 만원 단위 Y축을 표시한다. 제목·선택 버튼을 제외한 가용 높이를 채우며 고정 큰 높이로 컨트롤을 밀어내지 않는다. 눈금·X축·가이드·선택점·툴팁이 잘리지 않게 한다.
- 자산추이 상세 하단에도 1개월/3개월/6개월/1년/전체 버튼을 모두 표시한다. 진입 기간을 이어받고 상세에서 변경 가능. 복귀 시 원래 요약 화면 기간과 스크롤을 복원한다.
- 투자금 상세 제목은 `투자금 차트`. 차트 우측 상단에 연도 셀렉트. 전체/1분기/2분기/3분기/4분기 버튼은 상세에서 항상 표시·선택 가능하며 연도를 바꿔도 선택 분기를 유지한다. 데이터 없는 기간은 빈 상태, 마지막 선택만 반영한다. 상세용 조건 변경은 요약 조건과 분리한다.
- 종목 요약의 별도 거래내역 제목과 해당 여백은 제거한다. 거래내역 탭·거래 요약·연도별 손익 카드는 유지한다.
- 연도 상세의 종목별 손익 행 전체 → 해당 종목 투자손익 상세. 일반 종목 상세가 아니다.
- 종목 투자손익 상세의 연도별 손익 제목 옆 (상세보기). 제목바 전체 → 계좌 연도별 목록, 개별 연도 행 → 계좌 해당 연도 상세. 제목/행 클릭은 중복 이동 없이 구분한다.
- 화면/브라우저 뒤로가기는 진입 화면·계좌·종목·탭·연도·정렬·스크롤을 복원한다.

### 성능 조사 결정

매매일지 원격 측정 8개 시나리오×5회=40개는 원격 제어 왕복 시간이 포함되어 순수 React/API/DB 비용으로 해석할 수 없다. 월별 캐시·인접 월 선조회·같은 월 날짜 필터는 구현되어 있다. 전체 Lot 682건·약 428KB는 후보일 뿐 병목으로 확정하지 않는다. Network/Performance/React Profiler/서버·DB 자료가 부족하므로 성능 수정안은 확정하지 않았다.

사용자 결정에 따라 후속 성능 계측과 최적화는 보류한다. 이는 느린 구간이 없다는 증명이 아니다. 메뉴를 거친 매매일지 재진입은 오늘을 표시하는 현행 정책을 유지한다. 운영 원본 거래·예수금·스냅샷, Lot 손익·계좌 분리·변경 후 캐시 갱신·시세 동작은 유지한다.
