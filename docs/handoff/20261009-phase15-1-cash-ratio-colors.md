# 15.1차 · 예수금 비율별 색상 수정

확정일: 2026-10-09 (Asia/Seoul).

사용자가 제공한 세 상태 예시의 색상 순서를 변경한다. [15차 통합 명세](./20261009-phase15-accounts-cash-ratio.md)의 예수금 비율 색상에 한해 이 문서를 우선한다. 구간 경계와 계산식은 유지한다.

## 확정 색상

| 예수금 비율 | 왼쪽 주식평가액 | 오른쪽 예수금 |
|---|---|---|
| 30% 이상 | 파랑 | 빨강 |
| 20% 이상~30% 미만 | 녹색 | 노랑 |
| 20% 미만 | 빨강 | 파랑 |

예수금 비율 = 예수금 ÷ (주식평가액 + 예수금) × 100. 표시 반올림 전 비율로 판정한다. 정확히 30%는 주식 파랑·예수금 빨강, 정확히 20%는 주식 녹색·예수금 노랑이다.

- 35% 예시: 주식 65,000,000원·65.0% 파랑 / 예수금 35,000,000원·35.0% 빨강.
- 25% 예시: 주식 75,000,000원·75.0% 녹색 / 예수금 25,000,000원·25.0% 노랑.
- 15% 예시: 주식 85,000,000원·85.0% 빨강 / 예수금 15,000,000원·15.0% 파랑.
- 기존 23.8% 예시: 주식 651,000,000원·76.2% 녹색 / 예수금 203,200,000원·23.8% 노랑.

## 적용 범위

홈의 주식평가액·예수금 카드, 평가자산 카드와 자산구성, 자산분석 자산구성, 현재예수금, 계좌별 예수금 금액에서 막대·금액·비율에 같은 판정을 적용한다. 각 계좌의 실제 비율을 사용하며 예시 금액으로 색상을 고정하지 않는다.

기존 공통 색상 토큰의 값을 바꾸지 않고 해당 화면 요소의 연결만 변경한다. 월 증감·평가손익·수익률의 부호 색상, 종목별 비중 색상, 계좌 선택 테두리·제목의 노란색은 유지한다. 비율 계산 불가·분모 0·시세 누락은 중립색과 — 표시를 유지하고 확인된 금액은 보존한다.

계좌 추가·수정·초기화·삭제 조건과 팝업, 12차 현재예수금 데이터 기준, 수집·손익 계산식은 이번 수정 대상이 아니다.

## 디자인 반영과 개발 검증 구분

- Figma 커버·태블릿의 세 구간 상태 예시와 홈 카드를 시각 확인했다. 평가자산·자산분석·현재예수금·계좌 카드 및 관련 명세의 색상 연결을 수정했다.
- [커버 상태 예시](https://www.figma.com/design/HFguP6QYb6xnO9FRsjYlc2?node-id=1054-2) · [태블릿 상태 예시](https://www.figma.com/design/HFguP6QYb6xnO9FRsjYlc2?node-id=1061-110).
- 이번 작업은 디자인·문서 수정이다. 15.1차 앱 코드 적용·런타임 검증·운영 배포는 미실행이다. 기존 [15차 검증 결과](../qa/accounts-cash-ratio15.md)는 당시 색상 기준의 결과이며 15.1차 통과 근거로 재사용하지 않는다.
- 개발 시 기존 공통 색상 판정의 반환 색상과 관련 기대값을 변경하고, 모든 적용 화면을 확인한다.

## 15.1차 검증 기대값

| 반올림 전 예수금 비율 | 주식 / 예수금 |
|---|---|
| 19.99%, 19.999% | 빨강 / 파랑 |
| 20%, 23.8%, 29.99%, 29.999% | 녹색 / 노랑 |
| 30%, 35% | 파랑 / 빨강 |
| 분모 0·비율 계산 불가·시세 누락 | 중립색 / 비율 — |

계좌 전환·새로고침·커버/태블릿에서 금액·비율·막대의 일치와 손익 색상 회귀를 확인한다. 구현 PR·검사 결과·실제 배포 SHA는 구현 후 기록한다.
