# 10차 현행 명세 — 화면·수집·운영 등록 분리

기준일: 2026-10-08. 동일 항목은 이 문서를 8·9차와 초기 10차 종료연도 설명보다 우선한다. 기존 1~9차의 다른 기능은 유지한다. 코드·배포 상태는 [개발현황](../개발현황.md), 구현 세부와 검증은 아래 각 담당 문서에서 관리한다.

## 화면 개선 (PR #130, 상태 조회 API #127)

- 재무지표 제목 14px, 제목 옆 갱신 아이콘과 Small 버튼, 같은 줄 우측 연간/분기 Small 버튼. 버튼 높이·정렬 통일.
- 다음 줄 기간·이전/중앙/다음 연도를 데이터 열에 맞춘다. 왼쪽은 1년 이전, 오른쪽은 1년 다음, 중앙은 연도 셀렉트. 초기 중심은 한국 시간 현재 연도−1. 중심 범위 2016~현재 연도−1. 2015·현재 연도는 데이터 유지·이동 비활성. 범위 밖 입력 보정, 기존 endYear/annualStart/startYear URL 호환, 종목 이동 및 분기 선택 유지. 2026년 초기 표시 2024/2025/2026.
- 재무지표·가치분석 공통 팝업: 기존 입력폼 디자인, 시작/종료연도 2열, 다음 줄 갱신 범위(기본 연도 전체), 모두 Small. 저장 데이터 차트 보기·설명 제거, 범위 아래 수동 업데이트, 제목/닫기 유지·본문 스크롤. 갱신 대상 미래 연도는 제외한다.
- 실제 서버 작업을 3초 간격 조회. 진행 중 입력·버튼 비활성 및 진행 아이콘, 실제 연도·보고서·단계 표시. 재진입은 active API로 복원하고 중복 실행 방지. 일시 조회 오류는 종료로 처리하지 않는다. 최종 완료/실패에서 조회 종료 및 재활성화, 관련 데이터 재조회.
- 결과는 기간·상태·공시 완료·가치지표 완료·미공시·보충 실패 건수로 요약. 중복 사유 제거·상세 내용 접기. 실패로 정상 데이터 삭제 금지.
- 가치지표 회색 장문 안내를 노란 경고 아이콘의 터치/클릭 툴팁으로 이동. 재클릭·외부 클릭·Esc 닫기, 키보드 접근과 이름, 모바일 경계 및 내부 스크롤. 안내 없으면 숨김. API에서 isEstimated=true인 행에만 E·노란색 Bold 표시.
- 각 차트 제목 우측 상세보기 링크. 기존 전체화면 Dialog를 재사용해 2015~한국 시간 현재 연도 전체 데이터 조회. 연간/분기·종목·지표·범례 유지, 화면 높이 활용·터치 가이드선·값 툴팁. 앱/브라우저 뒤로가기로 선택 및 스크롤 복원.
- 전부 없으면 “내용이 없습니다.”. 지표별 최초 제공 전 누락은 상세 차트에서만 표시용 0, 툴팁 “데이터 없음”, 하단 노란색 “2023년도부터 데이터가 제공됩니다.” 형식 안내. 실제 0은 유지, 중간 누락·미공시는 선을 끊는다. DB/API 수정 금지.
- [화면 구현·QA·캡처](../qa/financial-ui.md). 370×465/725×396 모의 API 검사와 실제 운영/실기기 확인은 구분한다. 별도 예상치 API를 차트 행에 자동 통합하지 않으며 해당 연결은 남은 작업이다.

## 수집 로직·오류 개선 (PR #129/#131)

- 화면 변경과 별도 PR. DART 공시 저장 성공과 가치지표 보충 성공 분리. 실패/미공시 시 정상 데이터·출처 보존.
- 서버 전용 KRX_API_KEY, 승인된 KOSPI/KOSDAQ 일별매매·기본정보. 인증·권한·호출 제한·통신·데이터 없음·응답 해석 오류 분리, 인증/통신 오류는 휴장일로 취급하지 않는다.
- 과거 재무 DART·과거 종가 KRX 우선, 2015 하한. 실제 기간말 거래일 종가/EPS와 종가/BPS 사용. 거래량 0의 이월 종가는 실제 거래일로 표시하지 않는다. 시장·날짜 조회 공유.
- 액면분할·연결/별도·지배/전체 자본·보통/우선주 및 같은 공시 주당 기준 검증. 부족한 근거는 null/사유 유지, 현재가 대체 및 임의 0 금지. 출처·기준일·수집/계산시각 기록.
- 저장 공시의 누락 근거·지표를 별도로 보충, 보충 실패는 공시 성공을 취소하지 않는다. 삼성전자 검증 이후 보유→관심→거래 이력 확대.
- 올해 예상치·확정·TTM 구분. 승인된 제공기관 어댑터, 예상 EPS/BPS와 적합한 최신 가격, 예상 이익/자본으로 ROE. 연말 종가 고정 및 다음 해 확정 공시 전환, 예상 원본 보존. 실제 공급 경로 미확보 상태에서는 기본 비활성 유지.
- 새 annual_consensus_snapshots 테이블과 annual-estimates API, 기존 active/진행 API 및 counts/valuationErrors 계약은 [수집 설계·계약](../collection/krx-valuation.md), 실제 확보표와 모의/실조회 구분은 [수집 QA](../qa/collector-krx.md) 참조.

## 운영 키 사전 등록 (Draft PR #128)

- 우선 목표는 기존 운영 환경 파일에 KRX_API_KEY 한 항목을 숨김 입력으로 저장하는 것. 개발 .env 전체 복사, 키 값 출력·Git 저장 금지.
- 서버 저장과 실행 컨테이너 전달 여부를 별도로 확인. 등록 단계에서 컨테이너 재생성·수집·DB 변경·전체 배포를 실행하지 않는다.
- 서비스 이용기간 2026-10-08~2027-01-07. 키 값 없이 갱신 절차 기록.
- SSH 대화형 실행의 Registration/check stopped 보고는 등록 완료 근거가 아니다. 수정된 스크립트의 서버 반영·정확한 실패 검사·원인을 값 노출 없이 확인한다. 배포 잠금이나 검사를 임의 해제하지 않는다.
- 도구·가상 파일 테스트 완료와 운영 저장 완료는 구분한다. [준비 PR #128](https://github.com/byungho-cho/roxstock/pull/128)은 이 기준일에 미병합 초안이다.

## 검증·완료 기준

타입·빌드·관련 기능 검사, 커버/펼침 확인 결과와 실제 API 미검증 범위를 명시한다. 개발 PR은 기존 필수 검사·자동 병합·배포 계약을 적용한다. 키 등록 초안은 실제 등록 완료로 보고하지 않는다. 운영 환경변수와 원본 DB를 유지하며 관련 마이그레이션은 서버 로컬 사전 백업 절차를 따른다.
