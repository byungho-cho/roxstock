# Documentation

RoxStock의 기획, 설계, 개발 규칙 및 운영 문서를 관리합니다.

## 문서 관리 원칙

- Markdown(`.md`) 파일을 변경 이력을 추적하는 원본 문서로 관리합니다.
- DOCX(`.docx`) 파일은 열람과 공유를 위한 배포본으로 관리합니다.
- 문서 내용이 변경되면 Markdown 원본을 먼저 수정하고 DOCX를 다시 생성합니다.
- 확정된 과거 버전은 삭제하거나 덮어쓰지 않고 버전별로 보존합니다.
