# 1 서비스 개요

이 서비스는 매수 건별 보유수량과 매도 손익, 현재 실제 예수금, 실시간 주식 평가액, 가치투자 지표와 장기 복리목표를 한곳에서 관리하는 개인용 주식 매매일지다. 초기 버전은 증권사의 모든 정산 규칙을 재현하지 않고 사용자가 투자 판단에 필요한 현재 상태를 단순하고 명확하게 확인하는 데 집중한다.

매도는 종목 전체 평균단가가 아니라 사용자가 선택한 특정 매수 건에 연결한다. 예수금은 거래 원장을 다시 계산해 복원하는 값이 아니라 현재 증권계좌에서 확인한 실제 현금 잔액을 기준으로 한다.

# 2 제품 설계 원칙

- 개인용 초기 버전에 꼭 필요한 기능만 포함하고 후속 기능은 단계적으로 추가한다.

- 매수 한 건을 하나의 독립된 Lot으로 관리하고 매도는 반드시 특정 매수 건에 연결한다.

- 예수금은 현재 추가 투자 가능한 실제 현금으로 관리하며 사용자가 직접 수정할 수 있다.

- 거래 수정이나 삭제로 과거 예수금을 자동 복원하거나 재정산하지 않는다.

- 현재 평가는 최신 시세로 계산하고, 일별 스냅샷은 같은 날짜의 행을 주기적으로 갱신한다.

- 재무제표, 가치평가 지표, 관심종목과 복리목표를 매매일지와 함께 제공한다.

# 4 핵심 사용자 흐름

## 4 1 최초 설정

1\. 계좌와 증권사명을 등록한다.

2\. 기존 매수 건을 매수일, 종목, 수량, 평균 매수단가 기준으로 등록한다.

3\. 현재 증권계좌에서 확인한 실제 예수금을 입력한다.

4\. 보유종목과 관심종목의 최신 시세 및 가치투자 정보를 확인한다.

## 4 2 일상적인 매수와 매도

1\. 신규 매수를 등록하면 매수금액을 현재 예수금에서 한 번 차감한다.

2\. 매도할 매수 Lot을 선택하고 잔여수량 범위에서 매도수량과 단가를 입력한다.

3\. 매도를 등록하면 매도금액을 현재 예수금에 한 번 더한다.

4\. 거래를 수정하거나 삭제해도 예수금은 자동으로 변경하지 않는다.

5\. 실제 예수금과 차이가 있으면 현재 예수금을 직접 수정한다.

## 4 3 배당과 입출금

- 입금과 출금은 외부 현금흐름으로 기록하고 수익률 계산에서 투자손익과 구분한다.

- 배당은 종목별 실제 세후 입금액으로 기록하며 투자수익으로 분류한다.

- 배당, 입금, 출금도 신규 등록 시 예수금에 한 번만 반영한다.

# 6 매수 Lot과 매도 손익

하나의 매수 거래는 독립된 보유 Lot이다. 한 매수 Lot에는 여러 건의 분할매도가 연결될 수 있으며, 한 매도 거래는 반드시 하나의 매수 거래에만 연결된다. 여러 매수 Lot을 한 번에 매도한 경우에는 Lot별로 매도 행을 나누어 저장한다.

# 7 거래비용 관리

종목별 또는 거래별 수수료와 세금은 저장하지 않는다. 사용자는 증권사에서 확인한 월간 거래비용 합계를 계좌 단위로 입력하고, 서비스는 월간 및 연간 합계를 참고정보로 제공한다. 거래비용은 예수금, 평균단가와 기본 실현손익에 자동 반영하지 않는다.

# 9 실시간 평가와 일별 스냅샷

대시보드의 현재 평가금액은 positions의 잔여수량과 market_prices의 최신 현재가를 이용해 조회 시 계산한다. 사용자는 스냅샷 생성 시각을 기다리지 않고 현재 평가금액과 가격 기준시각을 확인할 수 있다.

| **구간**  | **처리**                                                |
|-----------|---------------------------------------------------------|
| 장중      | 최신 시세를 수집하고 현재 평가액을 계산한다.            |
| 매시간    | 오늘 날짜의 계좌 및 종목 스냅샷을 같은 행에 UPSERT한다. |
| 23시      | 당일 마지막 스냅샷 갱신을 실행한다.                     |
| 다음 날   | 새 snapshot_date로 새로운 행을 생성한다.                |
| 수집 실패 | 마지막 정상 가격과 가격 기준시각을 표시한다.            |

- 별도의 is_final 상태는 두지 않는다.

- 계좌와 기준일 조합에는 한 행만 유지한다.

- 계좌, 종목과 기준일 조합에도 한 행만 유지한다.

- 시간대별 스냅샷 이력은 초기 버전에서 보존하지 않는다.
