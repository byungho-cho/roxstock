# 수정 Dietz 기간 수익률 계산 사례

**버전:** v0.1  
**기준:** 매매일지 설계 v0.6

# 1. 계산 범위

- 기간은 한국 시간의 시작일 00:00부터 종료일 23:59:59까지입니다.
- 시작자산은 시작일 직전의 마지막 계좌 스냅샷입니다.
- 종료자산은 종료일의 마지막 계좌 스냅샷입니다.
- 입금은 양수, 출금은 음수의 외부현금흐름입니다.
- 매수·매도·계좌 안에서 받은 배당은 외부현금흐름이 아닙니다.
- 입력 시각이 없으므로 외부현금흐름은 해당 날짜 시작에 발생한 것으로 간주합니다.

# 2. 공식

```text
T = 기간의 전체 달력 일수
dᵢ = 시작일부터 현금흐름 발생일까지 지난 일수
wᵢ = (T - dᵢ) / T

투자손익 = 종료자산 - 시작자산 - ΣCFᵢ
가중투자원금 = 시작자산 + Σ(wᵢ × CFᵢ)
수정 Dietz 수익률 = 투자손익 / 가중투자원금 × 100
```

# 3. 계산 사례

조회 기간은 2026-01-01~2026-01-10, 총 10일입니다.

| 항목 | 날짜 | 금액 | 가중치 | 가중금액 |
|---|---|---:|---:|---:|
| 시작자산 | 직전 스냅샷 | 100,000,000원 | - | 100,000,000원 |
| 입금 | 01-03 | +20,000,000원 | 0.8 | +16,000,000원 |
| 출금 | 01-08 | -5,000,000원 | 0.3 | -1,500,000원 |
| 종료자산 | 01-10 | 121,000,000원 | - | - |

```text
순입출금 = 20,000,000 - 5,000,000 = 15,000,000원
투자손익 = 121,000,000 - 100,000,000 - 15,000,000 = 6,000,000원
가중투자원금 = 100,000,000 + 16,000,000 - 1,500,000 = 114,500,000원
수익률 = 6,000,000 / 114,500,000 × 100 = 5.24%
```

# 4. 산출 불가

다음이면 숫자 대신 `산출 불가`와 사유 코드를 반환합니다.

| 조건 | 코드 |
|---|---|
| 시작 또는 종료 스냅샷 없음 | `UNAVAILABLE_MISSING_SNAPSHOT` |
| 가중투자원금 0 이하 | `UNAVAILABLE_NON_POSITIVE_DENOMINATOR` |
| 기간에 수기 예수금 조정 포함 | `UNAVAILABLE_MANUAL_CASH_ADJUSTMENT` |
| 필수 가격 누락으로 스냅샷 무효 | `UNAVAILABLE_INVALID_SNAPSHOT` |

수기 예수금 조정 금액과 사유는 저장하지 않습니다. 조정 당일의 `has_manual_cash_adjustment`만 저장해 그 날짜를 포함하는 기간 수익률을 산출 불가로 판단합니다.

# 5. 개발 전달사항

백엔드에 순수 TypeScript 계산 함수 하나를 두고 대시보드와 자산분석이 동일 함수를 사용합니다. 금액은 Prisma Decimal 등 정밀 타입으로 계산하고, 최종 표시 단계에서만 소수점 둘째 자리로 반올림합니다.
