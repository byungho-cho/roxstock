# 주식 매매일지 웹 서비스 기획서

**버전:** v0.1

| 핵심 목표   | 매매와 입출금 기록을 바탕으로 현재 자산과 실제 투자성과를 정확히 보여준다 |
| 주요 사용자 | 여러 종목을 직접 매매하고 투자 성과를 스스로 관리하려는 개인 투자자       |

# 1 서비스 개요

이 서비스는 주식 거래, 입출금, 예수금, 보유종목과 실시간 시세를 한곳에서 관리하는 개인용 매매일지다. 사용자는 단순히 매수와 매도 내역을 보관하는 데 그치지 않고 현재 총자산, 주식 평가액, 실현손익, 미실현손익과 기간별 수익률을 같은 계산 기준으로 확인할 수 있다.

1차 개발의 중심은 정확한 계산과 빠른 현황 확인이다. 거래 원장과 현금흐름을 기준 데이터로 유지하고, 장중에는 최신 시세로 평가액을 갱신하며, 하루가 끝난 뒤 일별 스냅샷을 생성해 자산 변화를 기록한다.

# 2 기획 배경과 해결할 문제

| **현재 문제**                                         | **서비스가 제공할 해결 방식**                                      |
|-------------------------------------------------------|--------------------------------------------------------------------|
| 매매 기록과 현재 자산이 분리되어 있다                 | 거래 보유현황 예수금 실시간 평가액을 하나의 계좌 흐름으로 연결한다 |
| 입출금이 수익처럼 보이거나 손실처럼 보일 수 있다      | 외부 현금흐름과 투자손익을 구분하고 TWR과 MWR 적용을 검토한다      |
| 분할매수와 분할매도 후 손익 확인이 어렵다             | 잔여 취득원가 실현손익 미실현손익을 거래 순서에 따라 다시 계산한다 |
| 장중 자산과 과거 자산을 같은 화면에서 비교하기 어렵다 | 장중 실시간 평가와 일별 스냅샷을 구분하여 제공한다                 |
| 기록이 틀렸을 때 어디서 오류가 났는지 찾기 어렵다     | 원장 데이터를 유지하고 파생 결과를 다시 계산할 수 있게 한다        |

# 3 서비스 목표

- 계좌의 총 평가자산과 주식 평가액을 한눈에 확인한다.

- 매수 매도 입금 출금이 예수금과 보유현황에 미치는 영향을 일관되게 계산한다.

- 분할매매 이후 실현손익과 잔여 보유분의 미실현손익을 정확히 구분한다.

- 입출금 영향을 분리한 기간별 투자성과를 확인한다.

- 일별 스냅샷을 이용해 자산과 수익률의 변화를 차트로 조회한다.

## 3 1 성공 기준

| **구분**      | **판정 기준**                                                                     |
|---------------|-----------------------------------------------------------------------------------|
| 계산 정확성   | 동일한 거래 사례에서 예수금 보유수량 취득원가 손익 총자산이 항상 같은 결과를 낸다 |
| 데이터 정합성 | 거래 원장으로 보유현황과 스냅샷을 다시 계산할 수 있다                             |
| 현재성        | 장중 시세의 수집 시각과 오래된 가격 여부를 사용자가 확인할 수 있다                |
| 사용 편의     | 대시보드에서 총자산 주식 평가액 예수금 손익을 추가 이동 없이 확인한다             |

# 4 핵심 사용자 흐름

## 4 1 최초 설정

> 1\. 계좌를 등록하고 계좌명과 초기 예수금을 입력한다.
>
> 2\. 보유 중인 종목과 초기 보유수량 및 취득정보를 입력한다.
>
> 3\. 등록된 종목의 최신 시세를 수집하고 초기 평가 상태를 확인한다.

## 4 2 일상적인 사용

> 1\. 대시보드에서 총 평가자산과 당일 변화를 확인한다.
>
> 2\. 매수 매도 입금 출금이 발생하면 해당 거래를 입력한다.
>
> 3\. 보유종목 화면에서 현재가 평가액 평균단가 손익을 확인한다.
>
> 4\. 성과 화면에서 기간별 자산 추이와 수익률을 확인한다.
>
> 5\. 필요하면 거래일지에서 과거 기록을 검색하고 수정한다.

## 6 1 대시보드 표시 원칙

대시보드의 기본 자산 값은 보유주식 실시간 평가액과 예수금을 더한 총 평가자산이다. 사용자가 이 값을 선택하면 예수금을 제외한 주식 평가액을 확인할 수 있게 한다. 현재가가 오래됐거나 수집에 실패한 경우에는 금액만 표시하지 않고 기준 시각과 상태도 함께 보여준다.

# 7 데이터와 계산 원칙

- 거래와 입출금 기록을 기준 원장으로 보존한다.

- 총 평가자산은 보유주식 평가액과 예수금의 합으로 계산한다.

- 실현손익과 미실현손익을 분리한다.

- 입출금은 투자손익과 구분되는 외부 현금흐름으로 처리한다.

- 장중 최신값과 거래일 종료 후 일별 스냅샷을 구분한다.

- 파생 데이터는 원장으로부터 재계산할 수 있어야 한다.

# 12 다음 작업

기획서와 기본설계서 v0.1을 기준으로 DB 스키마 v0.2를 작성한다. 이 단계에서 계좌 종목 거래 현금흐름 보유현황 현재가 일별 스냅샷을 실제 테이블로 정의하고, 실제 매매 사례를 통해 모든 계산값을 검증한다.

> 1\. 테이블별 책임과 관계를 확정한다.
>
> 2\. 컬럼 타입 NULL 허용 여부 기본값과 소수점 자릿수를 정한다.
>
> 3\. PK FK UNIQUE INDEX를 정의한다.
>
> 4\. 매수부터 분할매도와 출금까지 계산 시나리오를 실행한다.
>
> 5\. 검증 결과를 반영해 스키마와 화면 지표를 확정한다.
