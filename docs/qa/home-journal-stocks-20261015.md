## 최종 표시 기준

- 홈 평가손익: 상단 제목 오른쪽 수익률을 제거한다. 매입금액 아래 평가손익 행을 제목(왼쪽)·수익률(가운데)·금액(오른쪽)으로 표시한다. 전일대비도 같은 12px·금액 굵기와 한 줄 배치를 사용한다. 상하 패딩은 각 8px이며 불필요한 24px 하단 공간을 제거한다.
- 홈 보유종목·최근 매수: 코드/계좌/API 대기 중 카드와 제목·목록 공간을 표시하되 목록·건수·갱신시각 스켈레톤은 표시하지 않는다. 기존 후속 조회·캐시·계좌 분리·오류 처리를 유지한다. 목표가 도래의 기존 로딩은 유지한다.
- 종목목록: 이전의 초기 빈 카드 3개/빈 표 행을 표시하지 않는다. 고정 탭·검색·정렬만 먼저 제공하며 데이터 도착 후 실제 카드/표를 표시한다. 기존 데이터가 있는 재조회는 목록을 유지한다.
- 종목 상세 거래내역: 매도 내역만 연도별로 표시·집계한다. 매도 카드의 연결 매수 원가·날짜와 수정/삭제 동작은 유지한다. 거래 원본은 변경하지 않는다.
- 매매일지: 월 선택 아래 월손익을 제거하고 달력 아래 별도 월별 거래현황 카드에 매수/매도 건수·금액과 실현손익·수익률을 표시한다. 일별 요약은 제목을 왼쪽, 건수/수익률을 오른쪽으로 표시하며 세 칸 사이에 구분선을 둔다. 일별·월별 매도금액은 각 기간의 실현손익 색상을 적용한다.
- 일별 이전/다음 및 스와이프: 월별 카드를 실제 본문 스크롤 상단에 맞춘다. 본문과 카드 높이를 측정해 일별 영역 최소 높이를 확보한다. 태블릿은 왼쪽 월별 카드와 오른쪽 일별 내역을 각각 상단 정렬한다. 지연 응답에서도 정렬을 유지하고 직접 스크롤·뒤로가기 복원을 방해하지 않는다.
