## 검증 근거

- 프런트/백엔드 TypeScript 및 프로덕션 빌드 통과.
- 백엔드 **228건 통과**, 프런트 단위 검사 **52건 통과**. 무제한 거래 API의 계좌/종목 조건·160건·합계·일별 건수 일치, 스냅샷 기준일 일치·0·미수집·미래 제외 검증 포함.
- [28차 최종 CI](https://github.com/byungho-cho/roxstock/actions/runs/38367891297): 커버 370×465, 태블릿 725×396, 430×932, 1024×768 각각 7검사 = **28건 통과**. 매매·설정 회귀 **18건 통과**. 같은 제품 코드의 [전후 화면 원본·trace](https://github.com/byungho-cho/roxstock/actions/runs/38367401568/artifacts/11798615362).
- 화면 검사: 올해 손익 +230원/+23%, 다른 계좌 -170원/-17%, 빈 연도 0원/분모 0 `—`, 서울 연도 경계. 여러 연도의 매수80+매도80=160건을 선택 종목 1요청으로 표시, 빈 목록 및 지연 응답 후 대상 격리. 홈 4px 계산 스타일·더보기 DOM 유지, chart API 0회. 메뉴 진입·활성·설정 모니터링·뒤로가기. 큰 금액 및 동일 기준일 테이블과 기존 차트 포인트 유지.
- [26차 회귀](https://github.com/byungho-cho/roxstock/actions/runs/38367891142): 화면16 + 계좌/종목 캐시2 + 홈 로딩·오류6 = **24건 통과**.
- [27차 회귀](https://github.com/byungho-cho/roxstock/actions/runs/38367891109): 순환 이동·Lot·시세·툴팁·화면32 + 매매/조건18 = **50건 통과**.
- [튜닝1](https://github.com/byungho-cho/roxstock/actions/runs/38367891185), [튜닝2](https://github.com/byungho-cho/roxstock/actions/runs/38367891186) 모두 성공. 기존 행 유지·중복 방지·재시도·계좌 전환·단일/묶음 조회 회귀 보존.
- 복리 전용 구형 테스트 응답에는 새 테이블 스냅샷 필드가 없었고 3열 이름을 기대했다. 차트/편집/새로고침 검사를 유지하면서 4열·명시적인 스냅샷 fixture로 현행화했다. 추가 전용 CI 결과는 후속 검증 기록에 기재한다.

## 제한·미확인

- main 직접 push, 자동 병합, 운영 배포 및 PR #137 병합 없음. DB 마이그레이션·운영 자료 보정 없음.
- 실제 Galaxy Fold/Android WebView·Safari·글꼴 확대는 미검증. 운영 거래를 생성/변경/삭제하지 않았다.
- 과거 스냅샷이 없으면 `—`를 표시한다. 최신 현재 평가자산을 테이블의 과거·미수집 값으로 채우지 않는다.
- 종목 상세와 복리 화면의 기존 태블릿 좌우 패널 스크롤은 유지하며 해당 상세 본문에 추가 목록 스크롤을 만들지 않았다. 홈·대시보드는 본문 하나에서 스크롤한다.
- 저장소 전체의 구형 UI 검사 일부 실패/대기가 남아 있다. 위 26·27·28·튜닝 성공과 전체 PR Gate의 성공은 구분한다. 모든 저장소 검사가 통과했다고 주장하지 않는다.
