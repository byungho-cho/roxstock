# 27차 종목 순환·보유 Lot 카드 검증

초안 PR [#214](https://github.com/byungho-cho/roxstock/pull/214). 기준 main `258ee8d06db93d171d6ed71504f5dc9198f4daae`는 26차와 튜닝 1·2차를 포함한다. 별도 `codex/phase27-cycle-compact-20261013` 브랜치에서 작업했다. main 직접 push, 자동 병합, 운영 배포, PR #137 병합은 수행하지 않았다.

## 변경

- 진입 목록의 순서로 첫↔마지막을 연결한다. 왼쪽 스와이프는 다음, 오른쪽은 이전이며 상단 이름·클릭·선조회도 동일하다. 1개 목록은 이동/자기 선조회가 없고 2개 목록의 같은 인접 종목은 중복 선조회하지 않는다. 계좌·종목별 기존 query key와 늦은 응답 격리를 유지한다.
- 날짜 옆에 기존 12px·기존 색상의 보유기간을 배치한다. 수정/삭제는 상단 우측 32×32px 영역에 두며 기존 대상·확인·연결 매도 삭제 제한을 유지한다.
- 수익률 행 제목만 `수익`으로 변경한다. 기존 수익률·손익금액·색상을 유지하며 `목표수익률` 제목 행을 제거한다.
- 현재 Lot 평가손익이 유한한 양수일 때만 기존 5/10/15% 목표단가를 표시한다. 손실·보합·계산 불가는 목표 영역 자체를 제거한다. 가격 갱신 시 다시 계산하며 설정 저장 API를 호출하지 않는다.
- 목표 박스는 목표수익률·목표단가 한 줄이다. 클릭/터치하면 잔여수량×목표단가 총액을 툴팁에 표시한다. 바깥 클릭·Esc·같은 박스 재클릭으로 닫고 다른 카드의 박스를 열면 기존 툴팁을 닫는다. Popper flip/overflow 제어로 화면 안에 표시한다.
- 카드 패딩·행·목표 박스 간격과 카드 사이 간격을 줄인다. 큰 금액·긴 보유기간은 필요하면 줄바꿈하여 보존한다. 상하단 44px 및 기존 본문 스크롤 구조를 유지한다.

## 화면 측정

동일한 Chromium·API fixture·날짜·수량을 기준 main과 변경 빌드에서 비교했다. 일반 사례는 2026.10.13 매수, 잔여 7주, 매수단가 304,000원, 현재가 350,000원, 카드 3개다. 운영 데이터나 실기기 측정이 아니다.

일반 이익 Lot 카드 높이 **201.5 → 130px**, **71.5px(35.5%) 감소**. 카드 사이 간격 **8 → 4px**. 큰 금액 또는 긴 날짜가 줄바꿈되는 경우 카드 높이는 자동으로 늘어난다. 아래 표시량은 보유 현황 탭의 상단 위치에서 상하 44px 고정 영역을 제외하고 카드가 완전히 보이는 개수다. 기존 요약 기본 진입은 유지한다.

## 제한

- 위 결과는 지정한 실행/커밋에 대한 검증이다. 저장소 전체 자동 CI의 다른 작업이 모두 끝났다는 뜻은 아니며 운영 반영도 아니다.
- Chromium에서 지정된 4개 viewport를 검증했다. 실제 폴더블 커버/태블릿, Android WebView, iOS Safari, 시스템 글꼴 확대는 실기기 미검증이다.
- API fixture 기반 UI 검증이며 운영 DB 거래를 생성/수정/삭제하지 않았다. 생산 시세 제공처의 실제 수신 지연은 이 검증 범위가 아니다.
- 화면 변화는 기존 저장값을 변경하지 않는다. 숨겨진 목표 박스는 이익 전환 시 같은 목표율로 다시 표시한다.
