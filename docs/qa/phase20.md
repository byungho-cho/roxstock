# 20차 QA

커버 370×465, 태블릿 725×396 CSS px. 신규 검사와 기존 phase16/value-v04/phase18 검사 포함. 실제 DEV DB 읽기 확인은 모의 API의 쓰기·지연 검사와 구분한다.

현재 완료:
- 직전 매수 일시·동일 일시 BIGINT ID 보조 정렬, 원본 배열 보존 단위 검사 1개 통과.
- 신규 브라우저 검사 12개 통과: 전량 매도 매수의 원래 수량, 수정 수량 보존, 다른 종목/기록 없음의 빈 수량·포커스, 지연 조회 중 수량·메모 포커스 보존, 계좌 변경, 메뉴 선표시, 빠른 응답의 표시 없음 및 느린 응답의 200ms 표시·차트/성과 위치 유지.
- 태블릿 직접 매수 진입의 배경 탭 동기화가 팝업을 닫던 문제를 수정·재검증했다.

추가 기존 회귀 검사 및 최종 타입·빌드 결과는 실행 완료 후 아래에 기록한다.

미검증: 실제 Android/iOS 시스템 키보드 및 앱 WebView 실기기. DOM focus와 Chromium 커버/태블릿 검사는 물리 키보드 표시 검증이 아니다. 운영 데이터에 테스트 거래/계좌 쓰기는 수행하지 않는다. 기존 Q4 Select 및 Emotion :first-child 경고는 이번 범위와 구분한다.

캡처: `frontend/test-results/phase20/`의 buy-prefill, settings-menu-pending 및 phase18 오류 고정 높이 캡처. CI artifact `phase20-screen-evidence`로도 보관한다.

최종 결과:
- 모의 API Chromium 검사 총 66개 통과(커버/태블릿): 신규·추가 18개와 기존 48개. 늦은 이전 계좌 응답, 설정 조회 실패, 가치분석 복귀 후 명시적 입력까지 포함.
- 프론트·백엔드 TypeScript 검사 및 프론트 production 빌드 통과. MoreScreens 등 무거운 설정 상세는 별도 chunk 유지.
- 앱 내 브라우저에서 실제 DEV API 가치분석 진입 후 검색창 미포커스와 더보기 고정 메뉴 표시를 읽기 전용으로 확인. 크기별 지연·실패·쓰기 검증은 모의 API 검사이며 실기기 검증과 구분한다.
- 운영 DB 변경, 거래 등록, 수집기 정책 변경 없음. 운영 배포 완료는 자동화 상태와 별도로 확인해야 한다.
