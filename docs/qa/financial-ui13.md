# 13차 화면 QA · 2026.10.08

상단 진입 경로·검색의 현행 기준은 [13.1차](financial-ui13-1.md)를 따른다. 아래 13차 차트 개선은 유지한다.

대상: 재무지표 카드 4종, 연간/분기, 전체화면, 가치분석 상세. API 경계 fixture 기반 브라우저 검증과 배포 후 실제 화면 확인을 구분한다.

로컬 TypeScript·프론트 빌드 통과. 로컬 Playwright 실행은 브라우저 socket() Operation not permitted로 브라우저 시작 전 차단되어 화면 검증 결과로 인정하지 않는다. PR CI의 phase10 검사에 13차 테스트를 추가했다. CI 결과와 배포 후 실제 화면 확인은 PR 완료 보고에 기재한다.

| 크기 | 검사 |
|---|---|
| 370×465 / 725×396 | 13차 선택·배치·갱신·긴 이름·빈 상태·touch drag/스크롤 및 기존 sticky·연도/전체화면·수동 갱신 회귀 |
| 430×932 / 1024×768 | 13차 선택·배치·갱신·긴 이름·빈 상태·touch drag/스크롤 |

13차 자동 검사: 카드 모든 계열의 기간 열 강조·가이드선·선택점, 카드 툴팁 없음, 수치표/제목 클릭 초기화, 마우스 드래그, 터치 선택/드래그, 세로 스크롤, 범례 정중앙/세로 중앙/충돌 없음, 기간 구분선·여백, 전체화면 tooltip 133px·값 오른쪽 끝선·데이터 없음·선택 초기화·전체 기간·복귀, 현재가/공통 Small 8px, 긴 이름/코드와 미수집 빈 상태.

기존 회귀 검사: sticky 불투명/상단 고정, 연도 키보드·터치·Escape·외부 입력, 지연 응답/짧은 데이터 scroll 복원, 전체화면 브라우저 뒤로가기, 실제 0과 선행/내부 누락 구별, 예상연도 색상, 수동 갱신 중복 요청·진행/실패/재진입 상태.
