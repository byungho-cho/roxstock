# 1.0.38 홈·대시보드·복리계획 로딩 표시

카드 제목·고정 레이블·차트 틀을 먼저 표시하고 응답 후 값을 채운다. 홈의 보유종목·최근매수·목표가 도래 목록은 지연 시 기존 부분 로딩을 유지한다. 복리계획의 대기 중 진행 막대도 빈 공간으로 유지한다. 계좌 전환·캐시·조회 순서·계산과 기존 이동 동작은 유지한다. DB·수집 정책 변경 없음.

프론트 타입 검사·빌드 통과. 홈 관련 회귀 40건 통과, 기존 캡처 전용 2건 제외. 공통 빈 화면 28건 통과, 복리계획 최종 수정 후 커버·태블릿 6건 통과. 실제 모바일 기기 검증 미실시. 배포는 PR 검사 통과 후 병합과 자동 워크플로로 진행한다.
