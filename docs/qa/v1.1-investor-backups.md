## 2026-10-16 운영 배포 후속 점검

PR #243 병합 후 백엔드·기존 수집기 배포가 정상 완료됐다. 독립 투자동향 수집기는 시작일 설정이 YAML 날짜로 해석되어 `2026-10-16 00:00:00 +0000 UTC`로 전달되면서 `INVALID_DATE`로 시작하지 못했다. 날짜를 인용한 문자열로 고정한다. 실패한 신규 컨테이너는 배포 스크립트가 중지했으며 성공으로 기록하지 않았다.

추가로 SSH 표준입력으로 전달한 배포 프로그램의 남은 부분을 하위 프로세스가 소비하여 마지막 버전 메타데이터 갱신이 누락되는 문제를 확인했다. SHA별 파일을 먼저 전송하고 표준입력을 닫아 실행하도록 네 배포 경로를 수정했다. Linux 재현·명령 구성·기존 서비스별 롤백 회귀 검사 3개가 통과했다. 격리 검사에서는 Windows 체크아웃의 줄바꿈만 LF로 정규화했다.

후속 PR #244는 운영 설정 수정이 포함되어 릴리스 규칙에 따라 1.1.1로 증가한다. 사용자 승인에 따라 운영 월간 백업·투자동향 수집기 활성화 설정과 Git 밖의 관리자 비공개 파일을 준비했다. 실제 활성화·첫 실행·운영 화면 확인은 후속 배포 완료 후 기록하며, 현재 준비 상태를 완료로 간주하지 않는다.
