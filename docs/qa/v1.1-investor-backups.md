## 자동 검사 내용

- 2^53 초과 수량 문자열, 실제 0, 금액 null, NXT 배제, 잘못된 응답·Z99 차단.
- 보유·관심·거래 분류 우선순위, 누적 Decimal 정밀도, 누락 이후 선 끊기, 미제공 금액을 0으로 만들지 않음.
- 관리자 비밀번호·401·출처·CSRF, 생성/삭제 동시 요청 차단, 실패 파일 비노출, 12+2 목록, 경로·크기 검증, 최신 자동 삭제의 정확한 문구, 삭제 후 다음 자동 보호, 월초 04:29/04:30 및 서버 복구 후 중복 보충 방지.
- UI 경로 중 `/api/api` 중복 문제가 실제 응답 회귀에서 발견되어 수정했다. 전체 데이터 수신 없이 성공처럼 보이는 목업만으로 검증을 종료하지 않았다.

## 화면 증거

로컬 비공개 `work/qa-v1.1.0/`에 실제 API 연결 캡처를 보관한다. CI는 `frontend/test-results/v11`을 아티팩트로 제공한다. 운영 계좌 정보가 포함될 수 있는 로컬 캡처·덤프·세션 파일은 Git에 추가하지 않는다. 본 PR의 화면 검사는 브라우저 에뮬레이션이며 실제 Fold·Android WebView·모바일 키보드 검증은 아니다.
