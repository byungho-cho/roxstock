# 수집 로직 검증 결과 (2026-10-08)

10차 화면 PR과 분리된 백엔드 검증이다. 아래 데이터는 내부 복구 DB의 삼성전자 공시를 읽은 결과이며 운영 API의 실조회 성공 결과가 아니다.

## 실제 연결 및 남은 원인

- 개발 서버 전용 KRX 키 등록 완료(값 미표시/미커밋). 인증 요청은 아직 공급자에 도달하지 못했다.
- `curl`의 KRX HTTPS CONNECT가 현재 환경 프록시에서 403으로 거절됐다. Node 실제 조회 시도는 KRX_COMMUNICATION으로 실패했다. 공급자 응답/운영 수집 오류 로그는 확보하지 못했으며, 인증·권한 문제가 원인이라고 단정하지 않는다.
- runtime source_config_version_id는 기존 `cecfgver_6ac62ca9bd848191866f07f5d475c170`이며 custom allowlist에는 binaries.prisma.sh만 존재했다. 새 게시 버전/도메인은 이 실행환경에 적용되지 않았다. 네트워크 우회는 수행하지 않았다.
- 첫 통신 실패 후 2015/2025 경계 및 나머지 연도는 NOT_ATTEMPTED. 키·서비스 권한·연말 거래일·실제 가격의 검증은 미완료다.
- 내부 삼성전자 2015~2025 연간 저장 공시는 모두 normalizationVersion=1. 2015~2018에는 operatingProfit만 있고, 2019~2025에도 basicEps/parentEquity가 없다. EPS 부족과 가격 연결 실패는 별개다. 우선주 포함 여부/동일 공시 주식수·자본 배분도 실제 보충 검증이 필요하다.

## 모의 응답/내부 검증

- KRX: 인증401, 권한403, 제한429, 통신, 잘못된 JSON/스키마, 빈 시장과 종목 없음의 구분. 오류를 휴장으로 처리하지 않고 이전 날짜 요청을 중단한다.
- 시장/날짜 동시 요청 공유, KOSPI/KOSDAQ 서비스 선택, 정확한 종목·거래일·보통주/ISIN 확인, 실패 캐시 금지.
- PER/PBR의 액면분할·주당 기준 미확인 시 미산출; 동일 공시 보충 계정만 사용하며 원본 계정 미변경; 기존 정상 값/출처 보존.
- 실제 보유 Lot과 관심/매매 이력 우선순위; 공시 성공과 지표 완료의 보고서별 집계; 진행 작업 재조회/중복 접수409.
- 예상/확정/TTM 분리, 서울 연도 경계, 제공기관 이용 조건 미승인 시 HTTP 호출 금지, 누락/음수 지표 처리.
- 연말 종가 불변, 확정 EPS/BPS 적용 시 고정 종가로 재계산, 예상 원본 보존/FINALIZED 전환.
- 위 공급자 응답은 테스트 fixture이며 실제 KRX/컨센서스 성공을 의미하지 않는다.
- TypeScript, 백엔드 빌드/기능 테스트(128개), 프런트 빌드, Prisma schema 검사 통과. 내부 DB 약 64MB 사전 덤프 후 추가 테이블 migration 적용 성공.
- 운영도 기존 검증된 DB 백업/마이그레이션 배포 절차를 사용한다. 운영 키/데이터는 변경하지 않는다.

2026년 예상 EPS/BPS/ROE: 미확보. 네이버 등 승인된 실제 컨센서스 연결 경로가 확인되지 않아 기본 비활성. 승인된 제공기관의 정규화 계약/별도 저장·확정 전환/조회 API는 구현했으나 실제 공급자 연결은 미검증이다.
