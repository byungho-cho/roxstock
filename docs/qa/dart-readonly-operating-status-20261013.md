## 외화 처리와 최소 개발 전달 사항

운영 코드의 `validateDartFiling`은 currency가 KRW가 아니면 `NON_KRW_STORAGE_UNSUPPORTED`를 발생시켜 저장 전에 차단한다. 기존 자료 보완 검증 `validateStoredDartRows`도 비KRW 응답을 차단한다. 실제 자동 run5814의 GRT 작업도 외화 사유로 REVIEW_REQUIRED에 남았다.

사유 코드 흐름은 **validationResult=NON_KRW_STORAGE_UNSUPPORTED → originalCode=DART_SOURCE_REVIEW → task errorCode=REVIEW_REQUIRED**이다. 현재 공개 메시지는 일반적인 DART 요청 실패 또는 출처·기간 검토 필요 문구이다. 운영 API·모니터링의 항목 reason은 이 일반 메시지를 반환하고 errors 집계는 errorCode 기준이어서 외화 미지원을 구분하기 어렵다. 이는 당시 운영 코드와 저장 메시지로 확인했으며 화면을 직접 관측한 결과와는 구분한다.

개발 전달 범위는 다음으로 제한한다.

1. 외화 validationResult를 이용해 API·모니터링에서 **외화 자료 미지원**으로 분류·표시한다.
2. 기존 FAILED·REVIEW_REQUIRED·재시도 정책·저장 차단을 유지한다.
3. 기존 오류 이력을 덮어쓰거나 실패 상태를 초기화하지 않는다. 과거 외화 진단도 표시 시 활용할 수 있게 한다.
4. 외화 저장·환산·PER·PBR·적정주가 지원은 추가하지 않는다.

문구는 현재 충분하지 않으므로 **최소 표시 수정 필요**다. 외화 저장 차단 자체는 정상 확인된 완료 항목이다.
