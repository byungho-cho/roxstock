# 15차 검증 계획 · 계좌 관리·삭제·예수금 비율

## 2026-10-09 · 15.1차 최종 3안 확정

[15.1차 색상 정본](../handoff/20261009-phase15-1-cash-ratio-colors.md)을 우선한다. 금액·%는 예수금 20% 초과~30% 미만일 때 투자금 녹색/예수금 노랑, 나머지 적색/파랑으로 고정한다. 막대만 투자금 비중이 커질수록 진하게, 예수금 비중이 작아질수록 옅게 표현하며 50% 이상은 농도 고정. 예제의 투자금·예수금 라벨은 실제 화면에 추가하지 않는다. 디자인·문서 반영이며 앱 구현·배포 검증은 별도다.

기준: [15차 통합 명세](../handoff/20261009-phase15-accounts-cash-ratio.md). 날짜2026-10-09. 요구 목록과 아래 실행 결과를 구분한다.

## 15차 당시 확인된 범위 (15.1차 검증과 구분)

- 최초 기획 문서 단계에서는 서비스/API/DB 미실행. 아래 구현 검증으로 갱신.

## 15.1차 최종 3안 확인 상태

사용자는 3안과 고정 글씨색을 선택했다. Figma 여덟 예시(예수금 22·28·20·10·30·40·50·60%)에서 실제 막대 길이, 반대 농도 변화, 구간별 고정 글자색을 확인했다. 예제용 투자금·예수금 라벨은 실제 화면에 추가하지 않는다.

앱의 0·20·30·50·100% 경계, 20.001%·29.999% 반올림 전 판정, 50% 이상 동일 농도/다른 길이, 금액·% 고정색, 계좌 전환·계산 불가·손익 색상 회귀 및 배포 검증은 미실행이다. 기존 15차 검사와 캡처는 당시 기록으로 보존하며 최종 3안 검증 완료를 뜻하지 않는다.


15.1차 앱 구현 검증은 [최종 3안 QA](asset-composition15-1.md)에 별도로 기록한다.
