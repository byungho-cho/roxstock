## 현재 상태

실시간 주가 C3400/T3400은 기획 대기에서 **구현·운영 반영**으로 변경됐다. 기존 화면 Figma는 **V1.0**, 금액 알림은 **V3.3 · 2026.11.01 요청문** 기준이며 앱 버전과 구분한다. 홈 다음, 대시보드 앞 두 번째 메뉴로 진입한다. 아이콘은 파형과 옅은 붉은 점을 사용한다. 기존 공통 화면 크기·헤더·검색·탭·버튼·하단 메뉴 체계를 따른다.

한투 외부 웹소켓 → 서버 공유 최신값 → 브라우저 SSE로 전달하고 약 1초마다 변경값을 반영한다. 전체 목록을 다시 만들거나 로딩 화면으로 덮지 않는다. 기존 네이버 60초 수집은 평가·스냅샷용으로 유지한다. 화면 신규 시세 경로와 기존 수집 경로는 별개다.

## 실시간 화면 최종 동작

- 시장 기본은 통합. 고정 52px 시장 버튼을 통합 → NXT → KRX로 순환하며, 그 옆 정렬과 우측 필터를 둔다. 시장별 값을 분리한다.
- 2열 카드에 종목명, 현재가, 우측 같은 줄 등락률, 아래 우측 등락액, 좌측 HH:mm:ss를 표시한다. 주문·체결량·종 옆 삭제 X는 제외한다. 보유는 제목 옆 노란 채움 별로 표시한다. 카드 종은 해당 종목의 금액 조건 설정·관리, 제목 종은 미확인 도달 목록으로 연결한다.
- 현재가 17.6px·500, 제목 공통 RoxHomeInter 22px·700. 고정 행 높이를 없애고 line-height 1, 행 간격 8px, 카드 상하 여백 8px를 적용한다. 긴 종목명·숫자와 드래그 높이는 실제 렌더링을 따른다.
- 실제 가격 변경에만 금액 영역 박스를 약 1초 강조한다. **강조색은 현재 전일 대비 상승 빨강·하락 파랑 기준**이다. 직전 틱 대비 방향을 쓰던 초기 구현은 대체됐다. 최초 값·동일 값으로 강조를 반복하지 않는다.
- 첫 진입은 사용자·시장별 메모리 최신값 우선. 값이 없으면 기존 목록 응답의 KRX 저장값을 사용한다. 통합에서는 KRX 참고값임을 명시하고 통합 실시간 캐시에 섞지 않는다. NXT에는 KRX를 대입하지 않는다. 수신 전·휴장·지연은 마지막 값과 원래 시각을 유지한다.
- 화면을 덮던 5분 인증 재확인을 기존 사용자 화면에서 백그라운드 처리한다. 최초 인증·만료 차단은 유지한다. 재연결과 계좌·시장 전환에서도 카드 키와 편집 상태를 보존한다.
- 상단 필터 전체/보유/관심/거래는 **등록한 표시종목 안에서** 적용한다. 관심은 선택 계좌의 관심/기존 추천 기준이며 다른 계좌를 합치지 않는다.
- 정렬은 직접설정순 / 종목명순 / 주가금액순 / 등락률순 / 보유금액순 / 보유손익순. 보유금액·손익은 보유종목 우선 정렬 후 비보유를 직접설정순으로 배치한다.
- 직접설정순에서 약 500ms 롱프레스로 카드를 잡는다. 확대 1.035·그림자·포인터 추종·이웃 카드 FLIP·가장자리 자동 스크롤·약 180ms 착지로 표현하고 움직임 줄이기 설정을 따른다. 놓을 때 저장하지 않는다.
- 변경 발생 즉시 헤더 중앙 취소/저장 아이콘 표시. 취소는 원복, 저장은 일괄 반영한다. 저장 충돌 시 편집 초안을 보존한다. 종목명 클릭만 보유/거래 종목 요약 또는 기타 종목 가치 상세로 이동한다.

## 표시종목 관리와 최소 저장

상단 + → `/live-quotes/add`의 **표시 종목 관리**. 검색/보유/관심/거래 탭, 공통 검색폼·헤더·탭·버튼을 사용한다. 체크/체크 해제로 추가·제거 초안을 만들고 상단 저장으로 한 번에 반영한다. 취소하면 복원한다. 보유/관심/거래 조건의 전체 선택을 지원하고 검색은 100개씩 더 조회하며 검색 전체 선택은 제공하지 않는다. 하단 딤 영역에 선택·등록 개수를 표시한다.

표시목록은 사용자 설정 `settings.liveQuotes`의 종목 ID 순서와 버전으로 관리한다. 실제 보유·관심·거래·예수금을 추가하거나 삭제하지 않는다. 별도 실시간 테이블·틱 이력·주기 DB 쓰기를 만들지 않는다. React Query 메모리는 사용자·시장별 최신값만 최대 500종목, 비활성 30분 보존한다. 새로운 디스크 캐시나 초기시세 전용 REST 조회를 추가하지 않는다.

표시목록 최대 **50종목**과 KIS 공유 실제 구독 상한 **41**은 별개다. 표시했다고 모두 실시간 수신 중인 것으로 표현하지 않는다. 기존 50개 초과 목록을 임의 절단하지 않고 제거·순서 변경을 허용한다. 목록 저장은 버전 비교로 충돌을 방지한다. DB 테이블 고도화/물리 분리는 여전히 별도 논의 대상이다.

## 함께 반영된 개선

- 대시보드 자산구성: 최대 6개. 6개 초과 시 상위 5개와 나머지 합산 기타, 도넛도 같은 그룹. 하단 16px 여백. 자산구성 우측 실시간주가 링크는 계좌를 유지한다.
- DB 백업 목록 두 번째 줄 날짜: KST `YY/MM/DD HH:mm` (예: `26/12/25 10:20`).
- 공통 토스트: 하단 메뉴·safe area 위, 좌우 16px·최대 600px 가운데. 성공은 기본 파랑, 오류·닫기·재시도·대기열 정책 유지.
- 관심 카드: 기존 PER/PBR/ROE 대신 검증된 적정가 4칸, 별도 제목 없이 32px 행. 팝업 좌우 16px, 오류 재시도도 높이 유지. 테이블형은 기존 표 아래 4칸 행.
- 종목소식 v1.2.54: 사용자별 빨간 NEW, 공통 제목 20px·400. 요약을 성공적으로 열거나 유효한 원문을 열 때 읽음 처리한다. 목록 조회·스크랩만으로 읽음 처리하지 않는다.
- 소식 헤더 종 배지는 현재 필터 전체 서버 미읽음 수이며 아직 표시하지 않은 페이지도 포함한다. 배지 클릭 → 건수 확인 → 확인한 조회 스냅샷만 일괄 읽음. 취소·닫기에는 쓰지 않고 이후 도착 소식은 NEW로 남긴다.
- `StockNewsRead`/`stock_news_reads`는 사용자+소식 복합키·최초 읽음 시각을 보관한다. 같은 사용자의 계좌 간 공유, 타 사용자 분리. 사용자 백업에 포함. 마이그레이션 `20261031060000_stock_news_reads`는 이 기능용이며 실시간 틱 저장과 관계없다.

## 실시간 금액 알림 · v1.2.55

- 조건은 사용자·종목·설정 시장별로 저장한다. OFF와 일시 중지(30분/1시간/2시간/3시간/한국시간 당일 자정)를 분리한다.
- 새 정상 체결만 판정한다. 조건당 열린 도달 항목은 1건이며 값·시각을 반복 갱신하지 않는다. 확인 후에는 조건을 벗어났다가 재진입해야 재발생한다.
- 본문은 서버 기준 종목의 현재 도달 항목을 확인한다. 도달 목록 제목은 선택 항목을 확인하고 현재 계좌의 보유 현황으로 이동한다. 소식 NEW와 별개다.
- 기존 공유 KIS 연결과 앱 내 목록·배지를 사용한다. 서버가 계속 실행되면 브라우저를 닫아도 감시·저장을 지속하지만 OS 푸시는 추가하지 않았다. 장중 실수신과 실제 모바일 키보드는 후속 확인 대상이다.
