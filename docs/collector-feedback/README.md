# 수집기 오류·개선 소통 기록

수집기 원인 분석, 개발 담당 검토, 수정안, 검증 결과와 후속 요청을 이 디렉터리에 기록합니다.

## 기록 방식

- 파일명: `YYYYMMDD-HHMMSS-KST-주제.md`. 날짜·시각은 한국시간(KST)이며 문서에도 작성 시각을 적습니다.
- 새 분석·회신·검증은 새 파일로 남기고 관련 이전 보고서와 PR/Issue를 링크합니다.
- 각 기록에는 대상 커밋, 분석 범위, 근거, 확인된 원인, 미확인 사항, 제안 또는 남은 작업을 구분합니다.
- 운영 변경·수집 실행·재수집 여부는 명시합니다. 보고서 저장 자체는 운영 변경 승인이나 배포 요청이 아닙니다.
- 인증키·비밀 환경변수 값·개인키·인증 헤더·원문 운영 env는 기록하지 않습니다.
- 보고서 논의는 해당 PR/Issue에서 하고 결론과 새 증거를 후속 파일에 반영합니다.
