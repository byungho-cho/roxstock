## 가격·주식수 기준 및 명세와의 차이

연간 과거 PER/PBR의 제공자 산식은 보통주 수정 기말 주가 / 동일 원천 EPS 또는 BPS다. 상단 펀더멘털의 전일 주가 배수와 다르다. EPS는 지배순이익 / 수정 평균 발행주식수(보통주+우선주), BPS는 지배자본 / 수정 기말 발행주식수(보통주+우선주, 자사주 차감)이다. 2026E는 전영업일 수정 보통주 가격 기준이며 원천 페이지 기준일은 2026-10-07이다. 재무 금액 단위는 억원에서 원으로 환산한다.

특히 삼성전자의 제공자 분모에는 우선주가 포함된다. 따라서 NAVER 직접 제공 배수를 “DART 보통주 단독 EPS로 재계산 완료”라고 보고하지 않는다. 제공 그룹 전체와 그 산식을 보관하고, DART 보통주 단독 계산과 분리한다. 기존 삼성전자 우선주·기업행위 검증 조건은 유지한다. 공급자 정의와 보통주 단독 산정 간 차이의 사용자 확정은 자동 전환 전 남은 과제다.

직접 제공 값에 누락이 있을 때만 저장 공시/누락 계정/마지막 거래일 실제 종가/주식수·기업행위 검증을 사용한다. 다른 원천 EPS와 기존 PER을 섞지 않는다. 실제 운영에서 제공 값이 모두 있는 경우 보충 계산을 억지로 실행하지 않는다. 제어 테스트에서는 EPS 6605원과 검증된 종가 1000원으로 PER 0.1514를 확인했고, 기업행위 기준 불일치 시 산출을 차단했다. 이 숫자는 테스트 fixture이며 운영 값이 아니다.

[OpenDART 단일회사 전체계정](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020)은 2015년 이후 재무자료를 제공한다. [KRX 유가증권 일별매매정보](https://openapi.krx.co.kr/contents/OPP/USES/service/OPPUSES002_S2.cmd?BO_ID=JvJFzlAENzZlPBDNGAWC)는 2010-01-04 이후 범위를 안내한다. 과거 DART 계정·기말 실제 종가·동일 공시 주식수·기업행위 근거 조합이 후속 방안이다. 해당 연도 실제 조회 성공이나 전 종목 계산 가능성은 미검증이다. 전체 과거 수집은 추가하지 않았다. 운영 DART 일일 호출은 조회 시 이미 10000건으로, 예산을 우회하거나 키를 변경하지 않는다.
