# 미해결 리포트 검토 — 2026-10-18

운영 1.1.13 배포 완료 후 로컬 미해결 19개 대상을 검토했다. 이번 검토 결과와 추가 코드는 로컬에 반영했으며 운영 DB는 수정하지 않았다.

## 정리 결과

- 동일 실패 실행의 항목 해시와 생성/관측 시각을 대조해 기간 누락 기록 5개의 연도·보고기간을 복원했다. 다른 실패에서 기간을 추정하지 않는다. 같은 종목·기간의 중복 집계가 2개 줄었다. 실제 저장 오류는 해결로 바꾸지 않았다.
- 레메디 2026 Q2, 레몬헬스케어 2026 Q2는 결산일 2026-06-30이 IPO 상장일 이전이다. 시장 종가와 PER/PBR은 적용 불가로 분류했다. 2개 대상의 발생 기록 3개를 PRICE_PERIOD_PRE_LISTING으로 해결하고 수치 NULL은 유지했다.
- 미해결 집계는 19 → 15개 대상, 발생 기록은 29 → 26개다. 이전 이력은 삭제하지 않았다.
