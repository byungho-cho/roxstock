## API·집계

신규 조회 `GET /api/accounts/:accountId/investment-capital`은 저장된 `daily_account_snapshots`의 날짜와 투자금만 읽어 `{data:[{year,date,investmentAmount,status}]}` 반환. 상태는 AVAILABLE/NOT_COLLECTED/YEAR_END_MISSING/AMOUNT_MISSING. 현재 연도 유효 스냅샷은 investmentAmount가 null이 아닌 최신 날짜이며 실제 0도 유효하다. 과거 연말 누락은 이전 영업일로 대체하지 않는다. 조회로 수집기를 실행하지 않는다. 계좌 비활성은 404. 기존 거래 API 집계와 Decimal 8자리 정밀도를 유지한다.

운영 서버의 선택 계좌별 연간 매도 행 실현손익 합계와 API summary가 일치함을 읽기 검증했다. 연간 실현손익/누적투자금 비율도 대조했다. 공개 증빙은 검증 여부만 남긴다. 사용자 제공 예시는 테스트 데이터로만 사용하며 제품 화면은 실제 API 값을 표시한다. 신규 스냅샷 API는 로컬 Fastify inject 테스트 검증이며 아직 운영 배포되지 않았다.

## 홈 성능

동일한 main/작업 브랜치 API 모드 프로덕션 번들, 370×465 DOM 환경, 동일 고정 API 지연/테스트 데이터, 각 3회 중앙값. 실제 브라우저 paint/layout 또는 운영/실기기 측정이 아니다.
