# 평가자산·펼침 메뉴 v0.4

- 평가자산 본문: 상단 0, 좌우 8px, 열 간격 8px, 하단 80px. 공통 본문 스크롤과 오버레이 스크롤바를 사용하며 카드 내부 스크롤은 만들지 않는다.
- 펼침 평가손익은 확정 카드의 174px을 적용한다. 76+68+174+222px 카드와 8px 간격 3개의 실제 합계는 564px이다. Figma 부모의 552px 클리핑을 복제하지 않고 오른쪽 카드도 실제 전체 높이에 맞춰 마지막 내용을 보존한다.
- 10.03 확정 도넛 프레임은 124.8px(이전 156px의 80%)이며 추가 축소하지 않는다. 동적 SVG의 원 오른쪽 끝과 범례 색상 표식 사이 20px을 유지한다. SVG 원본 좌표계의 여백을 고려한 그리드 간격은 8.8px이다. 범례는 색상·이름·우측 정렬 비율이며 숫자와 단위를 줄바꿈하지 않는다.
- 펼침 홈·평가자산·종목 추가: 종목목록, 매매일지, 평가자산, 예수금, 홈, 자산분석, 재무제표, 시세수집, 더보기 순서의 9개 동일 폭 메뉴. 높이 44px, 원본 아이콘 16px 위·8px 메뉴명 아래. 평가자산 선택은 평가자산, 홈에서 진입한 추가 화면 선택은 홈이다. 커버 5개 메뉴는 유지한다.
- 재무제표 메뉴는 더보기와 같은 기존 `/detail/financials` 안내 화면으로 연결한다. 공통 재무제표 상세 구현은 기존 미구현 범위이며, 종목별 재무제표 화면은 유지한다.
- API, 손익 계산, 미수집 처리, 차트 전환, 펼침 보유종목 3건 제한은 기존 동작을 유지한다.
- 최소 개발 검증: 370×465, 400×640, 725×396, 816×616에서 최초·최하단·범례·9개 메뉴 및 이동, 차트 전환, 데이터 상태를 확인한다. 정식 QA 미실시이며 별도 QA 담당 범위다.
- 공통 오버레이 스크롤바는 폭 4px, 본문 오른쪽 끝에 배치한다. 실제 스크롤이 가능한 경우 최초 표시하고 마지막 스크롤 후 1초 뒤 200ms 동안 숨긴다. 재스크롤은 즉시 표시하고 타이머를 재설정하며 화면 이탈 시 정리한다. 숨김은 본문의 스크롤이나 폭에 영향을 주지 않는다.
- 기존 `assets-v03.spec.ts` 경로는 수동 검사와의 호환을 위해 유지하되 기대값은 v0.4로 갱신했다. 평가자산 변경 PR에서는 홈·평가자산 배치, 스크롤바 표시/숨김, 연결 메뉴의 관련 검사만 선택하고 거래 계산과 거래 입력 검사를 반복 실행하지 않는다.
