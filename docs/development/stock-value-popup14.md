# 14차 · 종목목록 보고서 및 가치지표 팝업 (2026-10-08)

기준 main 9880619(13.1차 #143). Figma v0.5의 커버 페이지 305:7 → 실제 목록 238:2, 태블릿 페이지 2978:2 → 목록 2978:164, 팝업 3035:2075, 전체 콘텐츠 3702:5를 디자인 컨텍스트 및 렌더로 확인했다. 태블릿 목록 샘플의 아이콘 미반영 부분은 이번 사용자 지시를 우선한다.

## 구현
- 보유·관심 종목명 앞 18px #60A5FA 보고서 아이콘, 간격 4px. Figma 원본 b5533.svg를 stocks-v05/report.svg로 저장. 버튼 이벤트 분리, 종목명 기존 팝업 동작 유지. 거래종목에는 새 아이콘을 추가하지 않음.
- 팝업: 제목/닫기 → 종목·코드·W → 적정주가/수익성/가치지표 → 기준·상세보기. 화면 내부 최대 높이, 본문만 스크롤. 표·차트는 같은 API rows를 사용하며 null을 0으로 바꾸지 않음. 차트 입력/툴팁 없음.
- 기존 가치분석 적정주가 카드를 FairPriceCard로 추출해 두 화면이 같은 API 계산값·W 지속계수·가격 비교색을 사용. 계산식 변경 없음.
- 목록의 securityAnalysis 지표 나열 대신 value-analysis/:id 읽기 API로 최근 3개 연간 기간 조회. 계좌·종목·연도 query key와 AbortSignal 사용. 별도 수집 요청 없음.
- 하단은 적정주가에 사용된 valuation.kind/fiscalYear/periodType/metricDate에서 생성. ANNUAL_ESTIMATE만 2026E 추정 기준, FINAL_ANNUAL은 연간 실적, REPORTED_INTERIM은 해당 분기. 유효한 적정주가가 없으면 계산 근거 부족. 차트에 E가 있어도 임의로 적정주가 기준을 E로 바꾸지 않음.
- 상세보기의 stockNavigation/returnTo/backgroundLocation 보존. 보유 카드 손익 제목은 평가손익으로 현행화. 기존 이익/손실/보합색, 평가행 시각 없음, 하단 8px 간격 유지.

수집 로직·계산식·스케줄·DB 스키마는 변경하지 않는다. 공통 차트의 기본·전체화면 동작은 유지하고 popup 옵션에서만 비대화형 압축 표현을 사용한다.
