## 적용 범위
로컬 작업 브랜치 codex/cash-empty-loading-20261015. /detail/cash 조회 화면의 최초 코드 다운로드 및 계좌/API 대기 표시를 자산분석과 동일한 빈 프레임 방식으로 변경했다. 입력·수정 화면의 지연 로딩 정책과 데이터 계산·원본·수집 정책은 변경하지 않는다.

현재 예수금·기간 합계·올해 제세금의 값과 내역 건수는 응답 전 비워둔다. 변경내역은 고정 열 제목과 최소84px의 빈 본문을 표시하고 조회 완료 후 실제 내역·빈 상태를 표시한다. 정상0과 미수집 표시는 조회 완료 후 기존 기준을 유지한다.

CashTrendFrame을 코드 다운로드 화면과 실제 CashTrend가 공유한다. 배경·제목·축·날짜·가이드선은 먼저 표시하고 응답 후 선을 그린다. 오류·빈 상태도 같은 영역 안에서 표시하며 오류 안내·재시도를 유지한다. 같은 계좌·조건 재조회에서는 기존 query 데이터가 유지되며 다른 계좌·기간은 별도 query 키를 유지한다. 차트 툴팁·드래그 및 내역 편집/삭제는 기존 기능을 유지한다.

화면 코드는 계속 lazy 로딩한다. 경량 CashDownloadShell만 먼저 표시한다. 다운로드 중 월간/연간·기간 이동 상태를 실제 화면의 계좌별 page memory에 전달하며 최초 계좌 확정 이후에도 유지한다. 전체 페이지·입력폼을 초기 번들에 포함하지 않는다.
