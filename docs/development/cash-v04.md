# C1300 · T1300 예수금 v0.4

기준: Figma v0.4 · 2026.10.04 FINAL/STATE. 커버 305:4, 태블릿 740:2. REVIEW 높이와 디자인 예시 데이터는 구현에 사용하지 않는다.

- 헤더/하단 메뉴 44px, 본문 0/8px, 카드 8px. 커버 전체 스크롤, 태블릿 8px 간격의 두 독립 스크롤 열. 각 끝 80px 여백, 콘텐츠 폭을 차지하지 않는 4px overlay scrollbar와 1초 후 fade.
- 현재 예수금 → 기간 요약 → 저장 잔액 추이, 변경내역. 태블릿의 추이 카드는 남은 기본 화면 높이를 채운다. 확정 9개 메뉴와 예수금 선택 상태를 사용한다.
- `cash-overview`의 월/연 요약 계산은 유지. `cash-transactions`의 동일 from/to 조건, 서버 전체 total, 100개씩 모든 페이지 조회를 사용한다. 이전 1개월 조회는 시작일을 한 달 확장하며 동일 ID를 중복 표시하지 않는다. 계좌/기간 변경 시 추가 조회 범위를 초기화한다.
- 추이는 기존 `/accounts/:id/asset-history`의 저장된 `cashBalance`를 사용한다. 일별 계좌 스냅샷 제공 범위이며, 거래별 즉시 잔액 추이는 아니다. 스냅샷 없는 날짜/잔액 미수집은 선을 끊고, 정상 빈 결과·오류/재시도·계산 불가를 구분한다. 운영 예시 데이터를 추가하지 않는다.
- 운영 API 입력 화면은 커버의 일반 화면, 태블릿의 커버 재사용 중앙 팝업이다. 기존 `/detail/cash` URL을 유지하며 커버 입력/검색 단계만 선택적 `cashInput` query를 사용한다. 계좌/조회 조건과 원래 history entry를 유지하여 돌아올 때 스크롤을 복원한다.
- 36px Small 입력, 날짜 선택 유지, 첫 입력 포커스, 기존 값 전체 선택, Enter 다음 입력/최종 저장. 배당 전체 종목 검색은 48px 검색폼, 52px 결과 카드와 실제 조회 결과 건수/일치 문자열 강조를 사용한다.
- 최초 입출금의 예수금 반영, 배당 gross/net 저장 및 세후 최초 반영은 기존 POST를 유지한다. 수정은 기존 PATCH, 삭제는 기존 DELETE만 실행하며 현재/과거 예수금 재계산을 추가하지 않는다. 매수/매도 자동 내역은 기존처럼 읽기 전용이고 거래 원본을 변경하지 않는다.

연동 확인: 전체 건수와 날짜 범위 조회, 저장 잔액 시계열, 전체 종목 검색은 기존 API로 제공된다. 거래별 시계열을 새로 요구하지 않는 이번 범위에서 추가 백엔드 연동은 없다. 스냅샷 수집 전 기간은 자료 없음 또는 수집 공백으로 표시한다.

검사: `cash-v04.spec.ts`에서 계좌/기간 동기화, 100개 초과 페이지 조회, 이전 달 확장, 미수집 선 분리, 색상/금액 기준선/독립 스크롤/80px 여백, cover 일반 화면/tablet 팝업, 포커스/Enter, 입금/배당 저장 payload, 수정/삭제 잔액 유지, 오류 재시도 및 빈 결과를 확인한다. TypeScript와 빌드는 분리 실행한다. 광범위 회귀 QA와 실기기 시각 QA는 별도 담당 범위다.
