## 화면

`useChartDismiss`가 문서의 capture 단계 pointerdown/click을 관찰한다. 기본 동작/전파를 차단하지 않아 바깥 버튼·링크·메뉴가 같은 입력으로 동작한다. SVG 선택 영역과 실제 툴팁만 내부이며 제목·범례·수치표는 외부다. Escape, 자료/기간 변경 시 함께 초기화하고 unmount에서 이벤트를 정리한다. SnapshotChart·AssetTrendChart·FinancialChart·GrowthChart와 이를 재사용하는 요약/상세/전체화면에 적용한다. 비상호작용 재무 미리보기 팝업은 원래 툴팁이 없다.

복리 차트는 선택 사각 테두리를 없애고 노란 단일 선·선택점을 사용한다. 툴팁은 내용 너비와 화면 내 max-width로 제한한다. pan-y와 세로 제스처 감지로 스크롤을 유지한다. 매매일지 날짜 선택은 기존 DateField와 같은 네이티브 date picker이며 선택 일자에서 열리고 selectDate로 월·상세 상태를 함께 바꾼다. 예수금의 원본 일시·정렬은 유지하며 표시만 MM/DD로 바꾼다.

## 수동 갱신의 독립 작업

신규 MANUAL_PROTOTYPE 및 기존 같은 모드 요청은 `processIndependentRefresh`에서 처리한다. 자동 수집 경로와 이전 레거시 요청 처리 경로는 유지한다. DART 재무제표 작업과 가치지표 작업은 기간마다 동시에 시작하며, 한 작업이 실패/시간 초과되어도 다른 작업을 취소하지 않는다. 네이버 연간 자료는 한 요청에서 기간별 공통 크롤링을 캐시한다. 부족한 지표는 기존 원천·계산 정책과 저장된 공시/주식수/기초계정만 사용한다. 가치지표 작업의 보완 경로에서는 DART 재요청을 하지 않는다. 기초자료가 부족하면 보완 불가로 보고한다.

- FULL: 선택 기간의 DART 재무제표와 가치지표 독립 갱신. 누락/빈 응답은 정상 값과 실제 0을 지우지 않는다. 같은 분류의 기존 기초값을 유지할 경우 원래 공시 근거를 기록한다.
- SUPPLEMENT: DART 요청 없이 누락 가치지표만 채운다. 기존 정상 지표/재무제표를 유지한다. 정상 분모와 새 원천 비율의 기준이 다르면 그 비율은 보완 불가로 처리해 혼합을 막는다.
- DART 인증/설정 문제도 작업별 실패로 반환하므로 네이버 보완을 접수 단계에서 차단하지 않는다.

## 시간 제한·중복·보존

외부 수동 요청은 최대 20초(기존 더 짧은 원천 제한도 유지), 기간별 작업은 120초, 실행 전체는 600초, 대기 요청은 30분을 제한으로 둔다. 네이버 재시도는 기존 유한 횟수만 허용하고 작업·전체 제한을 넘기지 않는다. 수동 AsyncLocalStorage 범위의 AbortSignal을 DART/네이버/가격/거래소 요청에 연결하며 자동 작업에는 적용하지 않는다. 수동 DB delegate와 transaction 내부 쓰기를 검사해 종료된 작업의 늦은 응답이 저장하지 못하게 한다.

`collectorRun.metadata`에 refreshMode·clientRequestId·deadlineAt·lockOwner·작업별 상태·결과를 저장한다. 기존 DB 스키마를 재사용한다. 접수 공통 잠금과 종목별 진행 요청 검사에 더해 클라이언트 UUID를 멱등 키로 사용한다. 응답 유실 후 같은 키로 재시도하면 같은 작업을 반환한다. 조회 API는 만료된 수동 작업을 terminal로 전환하고 정확한 소유자 토큰의 잠금만 해제한다. worker publish/finish는 RUNNING 조건으로 갱신해 만료된 상태를 덮지 않는다.

프론트 POST/상태 요청은 15초 제한이며 실패 후 서버 active 상태를 재조회한다. 서버 상태가 불명확하면 새 갱신을 차단한다. 종목/요청 ID별 query key, 컴포넌트 key와 처리한 요청 ID로 이전 응답/완료 콜백을 분리한다. 결과 팝업은 닫지 않으며 DART 실패 토스트, 각 작업 진행 상태, 부분 완료 및 유지 안내를 표시한다.

안전 로그는 작업 ID·수집원·연도/기간·소요시간·오류 코드만 기록하고 요청 URL/인증키/응답 본문을 출력하지 않는다. DART 장애를 단정하지 않는다. 실제 운영 실패 원인은 운영 로그 접근이 확보된 범위에서만 보고한다.
