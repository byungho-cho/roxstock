# 복리 연도별 실현금액 및 활성 강조 (2026-10-09)

표는 연도 → 실현금액 → 목표금액. 과거 실현금액은 해당 계좌의 정확한 12월 31일 DailyAccountSnapshot.totalAssetValue, 올해는 기존 포트폴리오 currentAssets, 미래/연말 누락은 null(—)이다. 실제 0은 0원으로 유지한다. 현재 연도는 Asia/Seoul로 판정하고 DATE 스냅샷 키는 연말 달력 날짜와 정확히 대조한다. 시세/예수금 누락으로 현재 자산 계산이 불가하면 null이다.

API goal.rows에 realizedAsset, realizedTargetMet, annualAchievementRate를 추가했다. 과거 목표 이상/미달 판정은 Decimal로 처리한다. annualAchievementRate는 해당 행 목표 기준이며 기존 최종 목표 기준 progress와 별개다. 목표가 0 이하거나 자산이 없으면 달성률은 null이다. 기존 목표 계산식·원본 거래·예수금·스냅샷은 변경하지 않는다.

과거 목표는 회색, 올해/미래는 흰색. 과거 실현은 목표 이상 빨강(동일 포함), 미달 파랑, 누락 중립. 올해 실현은 흰색 중립으로 유지한다. 표의 색상은 유지한다. 목표 상세·자산분석 요약 카드의 현재 자산 색상은 후속 [복리 카드·차트 명세](compound-goal-cards-chart.md)의 올해 목표 대비 90%/110% 경계로 확정한다. 올해 목표 금액은 흰색이며 기존 최종 목표 기준 진행률은 유지한다.

목록 노란 테두리는 시작~종료에 올해가 포함된 계획에 적용하며 열람 선택과 무관하다. 비교/목표 상세 요약 카드의 노란 테두리는 isDefault와 연결한다. 기본 목표 변경 시 강조가 이동한다. 일반 테두리, 등록 제목색과 focus-visible 키보드 표시는 유지한다.

검증: 양쪽 TypeScript/빌드, 백엔드 159건, 실제 격리 MariaDB(정확한 연말/다른 날짜 제외/다른 계좌 제외/0/목표 동일), 브라우저 커버370×465·태블릿725×396(3열/색/활성 변경/다른 계획/긴 금액/키보드/계좌 전환/늦은 응답) 검사. 화면 API는 모의이며 MariaDB는 별도 검사다. 실기기·운영 데이터 쓰기는 수행하지 않았다. 스키마 변경/마이그레이션 없음.

운영 배포는 main 병합 후 기존 자동화로 진행하며 상태는 Actions에서 별도로 확인한다.
