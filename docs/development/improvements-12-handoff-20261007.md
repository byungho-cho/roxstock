## 회귀 실패의 원인과 해결

확정 근거는 `docs/handoff/20261006-user-tests-design.md`의 사용자 검토 일괄 확정 절과 `docs/매매일지 기획 v0.5.md`의 선택 계획 흰색 2px 표시, PR #104/Figma 3659:2 명세다. 이미 폐기된 화면/산식을 되살리지 않았다.

- 예수금: 날짜 최초 포커스/전체 종목 검색/잔액 미변경을 기대하던 검사였다. 금액·세전 최초 포커스, 거래 경험 종목 필수 선택, 세전→세후→세금→메모, 등록시각/id 기준 최신 1건 보정으로 교정했다. fixture도 실제 잔액 변화를 유지해 입금 1,000→500→삭제 후 원래 잔액으로 복귀하는 것과 최신 행 1개만 수정 가능한 것을 검증한다. 원본 매수·매도 쓰기가 없음을 계속 검사한다. 행 위치를 고정하지 않고 매수 유형으로 찾아 색상도 검증한다.
- 매매일지: 기존 거래현황의 매수 클릭은 보유현황으로 이동하므로 수정폼을 직접 기대하면 틀린다. 일별손익→독립 거래 상세→수정→거래 상세→뒤로가기의 실제 지원 경로를 검사한다. 보유 Lot 요청은 remainingOnly=true, 과거 원가 조회는 false로 구분해 fixture를 제공하며 매도 연결 원가 확인을 유지한다.
- 매매일지 제품 오류: 태블릿의 독립 거래 상세에 뒤로가기 버튼이 감춰져 있었다. 해당 화면에서 showBackTablet을 켰다. 수정 후 연결 Lot의 원가/손익 갱신과 선택 날짜 복귀를 두 태블릿 크기에서 재검증했다.
- 복리: ‘기본 목표로 선택’이라는 옛 접근성 이름은 현재 ‘설정’으로 교정했다. 선택 계획 흰색 테두리는 명세상 필요하므로 테스트 기대값을 낮추지 않고 제품을 고쳤다. 2번 계획 선택 후 팝업 취소까지 테두리·선택과 두 열 스크롤을 검증한다. 커버 전용 폼 검사는 커버 크기를 명시하고, 태블릿의 두 열 조회 실패 알림은 열 범위를 지정해 각각 확인한다.
- 큰 화면: 투자금/투자손익 검사가 프로젝트 이름이 ‘tablet’으로 시작하는지를 기준으로 1280px를 모바일로 오판했다. 실제 600px 반응형 경계를 기준으로 교정하고 기존 스크롤/연도 순환/복귀 기대값은 유지했다.

검사 전체를 제외하거나 시간초과/허용오차를 늘리지 않았다. 기존 순수 계산의 화면 크기 간 중복 실행 제외만 유지한다. 실패를 그대로 반복하지 않고 원인 수정 후 실패한 항목을 재실행했다.

## 검증 결과

- 프런트/백엔드 TypeScript와 프로덕션 빌드: 통과. 기존 약 1MB 단일 번들과 500KB 경고는 유지한다.
- 백엔드 자동 검사: 103/103 통과. 이번 인계에서 운영 DB 또는 원본 데이터에 쓰기하지 않았다.
- 프런트/스냅샷 API 단위 검사: 17/17 통과. 이 중 API 2건은 백엔드 103건에도 포함되므로 서로 더해 독립 검사 수로 주장하지 않는다.
- 로컬 Chromium 회귀: 예수금·매매일지·복리 72개, 1차 변경·투자금·투자손익 59개 = 131개 통과. 기존 순수 계산의 다른 크기 중복 4개 제외 유지. 최종 수정 전 확대 실행의 실패와 수정 후 재실행 결과를 구분했다.
- 회귀 크기: 370×465, 725×396, 400×640, 816×616. 1차·투자금·투자손익은 370×465, 725×396, 1280×800.
- 로컬 Playwright 표준 Chromium 다운로드는 손상된 ZIP을 반환했다. 기존 대체 Chromium에 GPU를 비활성화한 옵션으로 실행했고, 한글 폰트를 추가해 한글이 정상 렌더되는 화면을 확인했다. 제품 의존성/폰트 파일은 변경하지 않았다.
- CI: [GitHub Actions #37572543198](https://github.com/byungho-cho/roxstock/actions/runs/37572543198) 통과. 표준 Playwright Chromium에서 회귀 72건 + 1차 19건 + 투자금/투자손익 40건 = 131건 통과, 순수 계산의 크기 간 중복 4건 제외 유지. 타입/빌드·백엔드 103건·프런트 단위 15건 통과. 증빙 artifact `improvements-12-handoff-evidence`(2026-10-14까지 보관). 검증 소스는 위 e689de0이며 이 보고서 추가 커밋은 문서만 변경한다.

재현:

```sh
npm ci
npm run prisma:generate
npm run typecheck:frontend && npm run build:frontend
npm run typecheck:backend && npm run build:backend
npm --workspace backend test
node --import tsx --test frontend/tests/unit/*.test.ts
cd frontend
npx playwright install --with-deps chromium
npx playwright test -c playwright.handoff.config.ts --workers=2
npx playwright test -c playwright.improvements.config.ts
npx playwright test -c playwright.handoff.profit.config.ts --workers=2
```

대체 Chromium 로컬 검증에는 `ROX_CHROMIUM_EXECUTABLE`을 지정하는 handoff 설정을 사용한다. CI는 표준 Playwright Chromium이며 로컬 실행 파일 경로가 필요 없다.
