# 1.1.16 운영 보완 실행

앱 PR #264 / 커밋 `90b612f057ae22c66a54935ae7072d3e32523bc4`의 backend/collector/frontend 배포, DB 백업과 `20261019080000_native_currency_precision` 마이그레이션은 성공했다.

첫 운영 보완 job은 GitHub Actions가 비밀정보와 겹칠 수 있는 SHA 출력을 제거(`Skip output 'sha' since it may contain secret`)해 TARGET_SHA가 비었고, 파이프라인 종료코드가 전달되지 않아 보완을 실행하지 않은 상태에서 성공으로 표시됐다. 운영 API에서 여전히 외화 317기간과 다른 원문 보류 47기간인 것을 확인했다.

운영 전용 워크플로 `Native Currency Recovery`는 job output에 의존하지 않고 이미 배포·검증한 앱 SHA를 직접 고정한다. 빈 SHA/다른 이미지/잘못된 버전/SSH 실패/집계 없는 실행은 실패한다. 기존 앱의 제한 복구 스크립트와 공용 잠금·호출 제한·수동 우선권을 그대로 사용한다. 종료 후 제한된 최근 실행의 집계만 출력하며 DB 덤프와 키는 내보내지 않는다.

이 PR에는 앱·스키마·이미지 변경이 없으므로 앱 버전은 1.1.16을 유지한다. PR 검사와 병합 후 main push로 실행한다. 잠금 또는 수동 작업 때문에 양보하면 재실행해 미완료 대상만 이어갈 수 있다. 잘못된 원문을 강제로 저장하거나 다른 47기간을 일괄 해결하지 않는다.
