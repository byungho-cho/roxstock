# 17차: 영문·숫자 종목코드 (2026-10-09)

- 등록 코드: ASCII 영문·숫자 6자리. 앞뒤 공백만 제거하고 ASCII 소문자를 대문자로 변환한다. 선행 0을 보존한다.
- 입력·붙여넣기에서 잘못된 문자나 초과 길이를 제거/절단하지 않는다. 오류를 표시하고 저장을 막는다. 텍스트 입력을 사용한다.
- API는 동일 정규화 값으로 중복 검사와 저장을 수행한다. 기존 종목 발견 시 검색·계좌별 등록/분류 흐름을 재사용한다. 거래 이력 제한도 유지한다.
- 0163Y0와 016300은 별개의 종목이다. 제공자 A 접두어는 7자리 A+6자리 코드에서만 제거하며 6자리 A 시작 코드는 보존한다. 등록 API는 접두어를 제거하지 않는다.
- 마스터 수집, Naver 시세/연간 자료, KRX 가격, DART 매핑, 실시간 시세 조회·캐시에 동일 코드 범위를 적용한다. 호출 예산·자동 스케줄·지표 계산·검증된 원천 허용 목록은 변경하지 않는다.
- 운영 securities.symbol은 information_schema 조회 결과 VARCHAR(20). 컬럼 변경 및 DB 마이그레이션 없음. 조회 당시 0163Y0/016300 미등록. 운영 계좌/거래 테스트 쓰기 없음.

## 검증

- 격리된 로컬 MariaDB roxstock_phase16_test: 영문 코드 생성(201), 소문자 검색, 중복(409), 잘못된 코드(400), 016300 별도 생성, 현재가 조회, 기존 숫자 코드 및 계좌 분류 회귀 통과.
- 백엔드 단위/회귀: 코드 정규화, 잘못된 Unicode/특수문자, 마스터 파싱, Naver 시세, 실시간 캐시 구분 검사.
- 커버 370×465 / 태블릿 725×396: 입력·붙여넣기 이벤트, 소문자 정규화, 초과 길이 보존 및 저장 차단, 기존 종목 재사용과 검색 검사. API 응답은 모의 데이터이며 DB 검사는 별도로 수행한다.
- 실제 Naver 원천 읽기: HTTP 200, itemCode 0163Y0, stockName KoAct 코스닥액티브, closePriceRaw 10950. 시세는 조회 시점 값이며 고정값으로 사용하지 않는다.
- 실제 모바일 키보드/시스템 클립보드와 운영 계좌 등록은 미검증. 브라우저 붙여넣기는 paste/input 이벤트로 검증한다.
- PR 필수 검사 통과 후 기존 자동 병합·배포 절차를 사용한다. 배포 완료는 Actions 및 운영 이미지 커밋으로 별도 확인한다.
