## 처리 및 계산 정의

1. 올해 손익: 기존 `/accounts/:accountId/investment-profit?securityId=...`와 종목별 연도 손익 집계를 공통 hook으로 재사용. 서울 당해 연도의 Lot 연결 매도 실현손익 + 해당 종목 세후 배당. 현재 보유 평가손익은 포함하지 않는다. 분모는 해당 연도 해당 종목 매수총액으로 기존 거래 요약과 동일하며 과거 매수 Lot를 올해 매도한 경우 분모 0으로 비율은 `—`, 금액은 유지한다. 기존 계산과 같이 거래 수수료·세금은 별도 차감하지 않는다. 금액·비율은 BigInt 8자리 정밀도, 계좌·종목·연도 캐시 분리 및 연도 변경 감시.
2. 거래내역: 기존 trades API는 이미 서버 제한 없이 모든 매수·매도를 한 요청으로 반환한다. 연도 화면 제한과 더보기 제거. 매수도 표시하며 매수 Lot·분할매도·수정/삭제 연결 유지. 매수 단가/일자는 같은 응답의 매수 기록으로 찾아 추가 allBuyLots 조회 제거. 계좌/종목 query key, AbortSignal, 변경 후 invalidatePortfolio 유지. 인접 종목 선조회는 27차 정책 유지.
3. 복리목표: 기존 realizedAsset은 총자산 평가액(지난 연도 12/31 스냅샷, 올해 현재 총자산). 기존 차트·범례·목표·달성 판정은 그대로 보존한다. 테이블 전용 evaluationAmount/investmentAmount/valuationDate를 추가한다. 서비스 투자금액은 스냅샷 investmentAmount(잔여 보유 매입금액 + 예수금)이며 계획의 누적 투입금과 구분한다. annualInvestmentCapital을 재사용하여 과거는 정확한 12/31, 올해는 투자금액이 유효한 최신 스냅샷을 선택하고 평가금액도 동일 행을 사용한다. 과거·미래 자료 없음은 null, 프런트 `—`. 올해 차트 현재값과 테이블 스냅샷값은 기준일이 다를 수 있다. 기준일은 행 title에 기록한다.
4. 홈 두 줄 목록: 위·줄 사이·아래 4px, 이전 고정 높이와 마지막 행 예외 제거. 보유/최근 매수 카드는 내용 높이에 맞춰 목록 겹침을 방지한다. 더보기 원본 객체/DOM 보존 및 스켈레톤 튜닝 유지.
5. 대시보드: 홈 다음 하단 메뉴 `/detail/assets`, 제목 변경. 모니터링은 하단에서 제거하고 설정의 시세 수집 위로 이동. 기존 경로 및 설정으로 돌아가기, 메뉴 선택 시 자동 스크롤.
6. 홈: 기존 자산추이를 공통 PerformanceCard로 교체. 통합 home bootstrap의 불필요한 trend 조회 제거 및 legacy home history query 비활성화. 평가손익 금액·비율, 주식평가액·매입금액·전일 대비는 기존 dashboard 데이터/계산 재사용. 다른 asset-history API는 유지.
7. 대시보드: AssetQuickCards(주식평가액·예수금)만 제거. 28차 당시 평가자산·평가손익·자산구성과 관련 데이터 유지. 후속29차에서 대시보드 평가손익을 삭제하고 자산구성 도넛 아래에 자산추이를 배치했다. 현행은 ../handoff/20261014-phase28-29-current.md 참조.
