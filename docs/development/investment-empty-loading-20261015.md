# 투자금·투자손익 빈 프레임 표시 · 2026-10-15

## 구현
예수금 후속 작업과 같은 로컬 브랜치에서 적용했다. /detail/investment와 /detail/investment-profit의 lazy 코드 다운로드 및 계좌/API 대기에서도 카드·제목·고정 레이블을 표시한다. 무거운 페이지와 상세 화면은 lazy 로딩을 유지하며 경량 프레임만 공유한다.

투자금: 현재 평가금액·손익·합계 값은 응답 전 빈 칸, 차트는 고정188px 틀과 축·범례·날짜·가이드선을 유지한다. 상세 차트도 화면의 사용 가능한 높이를 유지한 빈 프레임을 표시한다. 오류·빈 상태 안내와 다시 시도는 유지한다. 연도·분기 선택은 다운로드 전후 및 최초 계좌 확정 후 같은 계좌별 메모리를 사용한다. 대기 중 초기 투자금 기준을 스냅샷 없음·0원으로 미리 표시하지 않는다.

투자손익: 누적 투자손익 카드·연도/종목 목록 제목·열 제목과 상세 요약/손익 카드 제목을 먼저 표시하고 금액·수익률·건수는 비워둔다. 목록과 Compact 내용 영역은 최소 높이를 유지한다. 빈 결과·실패에서도 프레임을 유지하고 조회 완료 후 안내를 표시한다. 탭·종목별 정렬도 코드 다운로드 전 조작과 계좌 확정 후 상태를 이어받는다. 기존 숫자 계산·기준·계좌별 query 키·캐시·조회 취소는 변경하지 않는다.

원본 거래·예수금·과거 스냅샷과 수집기에는 변경이 없다. 실제 DEV 확인도 조회만 수행했다. 이번 수정은 아직 로컬 상태이며 병합·배포하지 않았다.

## 검증
프론트 TypeScript·생산 빌드 통과. 커버370×465와 태블릿725×396에서 최초 청크/계좌 대기·연도/분기/탭/정렬 유지·카드 빈 값·스켈레톤0·회전 표시0·투자금 차트 위치/크기 동일·계좌 변경 후 늦은 응답 배제·캐시 유지·오류/빈 결과·긴 금액·원래 계산 회귀를 확인했다. 새 프레임 기준으로 구검사의 카드 삭제 기대를 값 빈 상태 기대로 현행화했다.

투자금 상세 연도/분기·빈 결과·빠른 변경·Y축 및 투자손익 상세 연결/정렬/스크롤/뒤로가기 검사6건은 커버·태블릿·큰 화면에서 통과했다. 실제 실행 중인 DEV 두 화면에서도 코드 다운로드 단계 스켈레톤0·회전표시0 및 실제 API 응답 완료 후 정상 표시를 확인했다. 캡처는 모의 API 기준이다. 실기기 모바일 키보드/터치 검증은 미수행이며 운영 화면 검증도 미수행이다.

최종 관련 검사31건 통과. 태블릿의 순수 계산 중복 실행1건은 기존 정책에 따라 제외(커버에서 계산 검사 실행/통과). 상세 내비게이션6건 포함 총37건 통과.
