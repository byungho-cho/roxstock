# 공통 재무 데이터 원천 정책

## 저장 및 조회

- 기본 재무제표와 공시 주식수는 DART 원본을 사용한다. `DartFinancialFiling`과 `DartShareSnapshot`은 출처 증빙으로 보존한다.
- 결산 연도·보고기간·연결/별도가 검증된 추가 지표는 공통 `PeriodValuation`에 보완한다. 가치분석과 재무제표가 함께 읽는다. 기존 정상 값은 유지한다.
- 현재 시점 추가 지표는 공급자와 관계없이 공통 `FundamentalSnapshot`에 저장한다. 종목·수집일별 하나의 행에 KIS 우선, KRX 보완 값을 저장한다. 두 상세 API가 같은 데이터와 형식을 반환한다.
- `FundamentalSnapshot`의 물리 테이블은 기존 `kis_fundamental_snapshots`를 그대로 매핑한다. 기존 행·키·외래키를 보존하며 테이블 복사, 초기화, DB 마이그레이션은 필요 없다. 이전 배포본으로 되돌려도 기존 행을 읽을 수 있다.
- 투자자별 매매 동향은 `InvestorFlowDaily`로 독립 유지한다.

## 추가 지표 우선순위와 제공 범위

1. KIS: 현재 PER/PBR/EPS/BPS/상장주식수/외국인 보유 수량·소진율.
2. KRX: KIS 상장주식수 누락 또는 현재 조회 실패 시 공식 일별매매 API의 `LIST_SHRS`로 보완. 시장 휴장 시 최근 7일 내 실제 제공일을 확인한다. 요청 사이 2초 이상, 동일 시장·일자는 캐시한다.
3. 현재 사용 중인 KRX 공식 일별매매 API에 없는 PER/PBR/EPS/BPS는 만들어 채우지 않는다. KIS 연간 값은 기존 결산 대조 검증을 통과해야만 `PeriodValuation`에 저장한다.

KIS 우선은 현재 연동의 지표 제공 범위 및 실제 수집 확인을 근거로 정했다. 전체 종목에 대한 통계적 성공률 비교가 완료됐다는 의미는 아니다. 2026-10-17 실제 KRX 조회에서 문배철강·SK하이닉스의 10/16 상장주식수 반환을 확인했다.

## 기준 혼합 방지 및 재수집

- 공통 현재 행의 `raw.fieldSources`에 지표별 원천·원천 기준일·수집시각을 남긴다. KRX 응답은 필요한 필드만 `raw.krx`에 보존한다. KIS 원천 기준일 미제공은 null로 유지한다.
- 현재 배수는 과거 결산 배수가 아니다. 현재 상장주식수는 발행·자기·유통주식수가 아니다. DART 공시 주식수를 현재 상장주식수로 덮어쓰지 않는다.
- 외국인 보유비중은 동일 KIS 관측의 보유 수량과 상장주식수가 모두 있을 때만 계산한다. KRX 보완 분모와 섞어 비중을 만들지 않는다.
- 수집 제외·종목 코드 변경·잠금 소유권을 저장 직전 다시 확인한다. 출처별 오류는 기록하고, 보완 소스만 성공한 경우 실행을 부분 성공으로 남긴다.
- 추가 지표 저장 시 종목 재무 캐시를 무효화한다. KIS를 저장한 당일 중복 수집은 방지한다. KRX만 저장된 당일 행은 기존 1시간 재시도 제한을 지킨 후 KIS로 재시도하여 같은 행을 갱신한다. 누락 값은 기존 보완값을 유지하며 KRX로 KIS 값을 덮어쓰지 않는다.
- 기존 자료는 삭제하지 않는다. 새로운 기준으로 수집되는 행부터 지표별 출처를 기록한다. 과거 결산 원천 대조를 통과하지 못한 값은 보완하지 않는다.

## 검증

수집기 테스트에 KIS 우선·KRX 누락 보완·휴장일 이동·심볼/기준일 오류 거부·혼합 기준 보유비중 차단·수집 제외 필드 원본 제거·현재 소스 실패 시 결산 원본 유지 검증을 포함한다. 두 상세 API의 공통 참고값 일치와 기존 문배철강 EPS/RIM 유지도 실제 로컬 DB로 확인한다.

2026-10-17 로컬 실수집: 삼성전자 실행 9719, 현재 공통 행 1건 저장·연간 빈 항목 2개 보완·오류 0건·지표별 출처 기록 확인. 문배철강의 두 상세 API가 같은 PER 6.3/PBR 0.22/상장주식수 20,503,505를 반환하며, 2024 EPS 323과 2025 결산 RIM 계산 유지 확인. 운영 데이터 초기화·변경·배포는 이 작업에서 수행하지 않았다.

## 핵심 재무지표 표시 및 DART 누락 복구 · 2026-10-17

DART 계정 보완 조회가 KRX 과거주가 검증 종목 목록에 종속되던 조건을 분리했다. DART는 기존 동일 공시·연도·통화 검증을 통과한 계정만 보완하고, KRX 과거주가의 적용 제한은 유지한다. 실제 문배철강 2025 공시(20260319000530) 재조회에서 기본 EPS 314원과 발행/유통주식수 각각 20,503,505주를 확인하여 로컬 `PeriodValuation`과 `DartShareSnapshot`에 저장했다. 기존 재무제표 원본의 동일성을 전후 비교로 확인했다. 2025 EPS를 2024 EPS 또는 현재 주식수로 추정 대체하지 않았다.

자기주식수 직접값이 null이어도 동일 공시·동일 주식 종류의 발행주식수와 유통주식수가 모두 있고 차이가 비음수가 되면 표시용 자기주식수를 계산한다. 원본 null은 유지하며 `shareBasis.treasuryCalculated`와 설명 툴팁으로 계산 근거를 표시한다. 다른 공시·주식 종류의 수치는 섞지 않는다.

핵심 재무지표는 결산값을 우선 표시한다. 결산 PER/PBR가 비어 있으면 공통 최신 참고값을 표시하고 노란색 느낌표 툴팁에 원천·조회일·결산값이 아님을 안내한다. DART 주식수가 없으면 상장주식수로 제목을 바꾸어 공통 참고값을 표시한다. 이 표시용 대체값은 결산 계산이나 RIM에 주입하지 않는다. 별도 최신 참고 지표 카드는 제거하고 외국인 보유 수량·비중·소진율도 핵심 카드에 모았다. 중복 EPS/BPS는 결산값만 표시한다.

검증: DART 보완 및 주식수 회귀 6개 통과, 백엔드 빌드·프런트 타입 검사 통과. 실제 로컬 370/725px에서 주식수·EPS·노란 아이콘·클릭 툴팁·중복 카드 제거·가로 넘침 없음 확인. 문배철강 기존 RIM 주당가치 대조도 유지했다. 운영 DB 변경과 배포는 수행하지 않았다.

## v1.1.5 배포 범위

핵심 지표의 확정 결산 항목명은 파랑과 `(결산연도)`, 컨센서스는 옅은 노랑과 `(연도E)`, 최신 참고값은 옅은 노랑과 `(최신)`으로 구분한다. 계산된 자기주식수는 옅은 노랑, 원형 테두리 느낌표는 회색이다. 요구수익률은 카드 맨 아래에 표시한다. 공통 수집 시각·주의사항은 핵심 재무지표 제목의 툴팁으로 제공한다.

`financial-evidence` 공통 조회는 `PeriodValuation.supplemental.accounts`의 동일 종목·결산 연도·기간·공시 접수번호·연결/별도 계정을 두 상세 API에 연결한다. 원본의 정상 값은 유지하고 누락 값만 투영하며 원본 DB를 덮어쓰지 않는다. 지표 상태가 SUCCESS여도 누락된 DART 현금흐름·기말현금·소유주 항목은 공시 보완 조회가 가능하다. 같은 공시를 이미 조회한 보완 계정은 무한 재조회하지 않는다.

## 한투 결산 종가 및 수동 갱신 통합 · 2026-10-17

과거 종가 조회는 KIS 기간별 일봉의 KRX(`J`) 원주가(`FID_ORG_ADJ_PRC=1`)를 우선 사용하며, 실패 시 기존 KRX/공공데이터 경로를 시도한다. 결산일 이후나 직전 7일 범위 밖 값, 종목 불일치·중복 일자는 거부한다. 별도 수정주가 응답과 종가·거래일이 일치하고 동일 DART 공시의 주식 종류 근거가 있을 때만 연간 EPS/BPS와 결합한다. 기준 불일치는 현재가로 대체하지 않고 빈 값과 오류 근거를 남긴다. 요청은 프로세스 내 2초 간격으로 제한하고 토큰을 재사용한다.

수동 갱신의 과거 연간 지표는 네이버 연간 조회 경로를 사용하지 않고 공통 DART/기간말 종가 보완 경로를 사용한다. 현재 연도의 컨센서스 처리는 별도 유지한다. 기존 정상 지표와 재무제표 원본은 유지하며, 같은 공시·연도·연결/별도 기준으로 DART와 대조된 KIS 연간 EPS만 PER 분모에 재사용한다. 숫자 표기 `323`과 `323.00`은 같은 값으로 검증한다. 새 비율의 분모 출처도 보관한다.

문배철강 로컬 실수집: 2024-12-30 종가 2,320원 → 2024 PER 7.1827, PBR 0.2318. 2025-12-30 종가 2,090원 → 2025 PER 6.6561, PBR 0.2199. 기존 DART 원본 해시 동일, 차트 표시 확인. 2026E는 추정 근거가 없어 null 유지. 운영 데이터 변경·배포 없음.

### 2018년 이전 DART 계정 및 전기 자본 보완

옛 `ifrs_` 계정 코드를 같은 이름의 `ifrs-full_` 코드와 정확하게 매핑한다. 기존 보완 계정이 있어도 원본과 캐시 모두에 핵심 자산·자본·손익이 없으면 다시 조회한다. 같은 공시의 보완 값을 계산에도 투영하고, ROE에 필요한 전기 연간 자본이 비어 있으면 해당 공시의 계정만 추가 조회한다(전기 주식수·종가 재조회 없음). 재무제표 원본 값은 변경하지 않는다. 수동 완료 판정도 이 검증된 투영 값을 사용한다.

문배철강 로컬 2018 PBR 0.5148·ROE 4.7022%, 2019 ROE 2.1432% 복구. 2018~2020년 동일 수동 보완 실행 9722의 연도별 지표 작업 모두 성공. 과거 코드 및 전기 자본 투영 회귀 테스트 포함 전체 110개 통과.

## 한투 접근 토큰 재사용

`shared/lib/kis-token-cache`는 앱키·시크릿·접속 서버를 해시한 구분자로 비공개 토큰 파일을 공유한다. 원문 키·시크릿은 파일명·저장 내용에 넣지 않는다. 만료 1분 전까지 재사용하며, 파일은 0600·디렉터리는 0700으로 생성한다(Windows 로컬은 별도 사용자 ACL 폴더). `KIS_TOKEN_CACHE_DIR`로 Git 밖의 위치를 지정한다. 로컬 환경 로더는 저장소 바깥의 전용 비공개 폴더를 사용한다.

독점 디렉터리 잠금·소유자 확인·heartbeat로 여러 프로세스의 발급을 직렬화하고, 중단된 작업의 2분 이상 오래된 잠금은 별도로 회수한다. 발급 실패 직후 60초 재요청을 차단한다. 파일이 손상되거나 쓰기 권한이 없으면 재발급을 반복하지 않고 안전한 오류 코드로 중단한다. 유효한 토큰 파일은 재시작해도 읽어 사용한다. 실제 토큰·인증 응답은 로그나 Git에 넣지 않는다.

투자동향 수집기와 결산 종가 수집기가 같은 공유 모듈을 사용한다. 두 운영 Compose는 `roxstock-kis-token-cache` 명명 볼륨을 같은 위치에 연결하며 각 이미지가 node 사용자 전용 디렉터리를 초기화한다. 운영 활성화는 이후 배포 시 적용한다. 테스트는 가짜 토큰으로 동시 별도 프로세스·재시작·만료·키 변경·실패 cooldown·손상·고아 잠금 회수를 확인한다.

갱신 팝업은 가치분석 상세 및 연간/분기 차트 모두 `연도 전체(ALL)`를 기본 범위로 사용한다.

## 우선주 발행 기업의 보통주 조회 및 참고 지표

공시의 IFRS 기본 EPS 계정이 단일 값으로 식별되고 우선주 EPS와 충돌하지 않으면 보통주 EPS 근거로 기록한다(`ordinaryEpsVerified`). 기간말 원주가/수정주가 일치·동일 공시 주식수 검증 후 PER 계산을 허용한다. 여러 EPS 값이 충돌하는 경우 임의로 선택하지 않는다.

보통주·우선주가 함께 있으면 동일 공시의 보통주/우선주 유통주식수 합이 합계 행과 일치할 때 `지배주주 자본(별도는 자기자본) ÷ 합산 유통주식수`를 통합 기준 참고 BPS로 계산한다. 이 값은 보통주 전용 자본 배분값으로 취급하지 않는다. PBR도 같은 참고 BPS를 사용하며 `bpsReferenceOnly`와 `OWNERS_EQUITY_DIV_ALL_OUTSTANDING_REFERENCE`를 기록한다. 핵심 지표는 `(참고)`와 계산 연도 E, 차트는 안내 툴팁으로 기준을 설명한다. 참고 BPS는 적정주가/W/RIM 총액 계산에서 제외한다. 기존 정상 지표·원본 DART 파일링은 보존한다.

삼성물산 로컬 2019~2021년 12개 연간·분기 지표 저장 성공, 원본 DART 전체 해시 동일 확인. 연간 PER 17.0437/21.9815/12.0044, 참고 PBR 0.7427/0.7537/0.6498. 한투가 과거 연간 BPS를 제공하는 것을 확인했으나 다른 원천/수정 기준 값을 강제로 DART에 섞지 않는다. 주식 종류 충돌·합계 불일치 차단·참고 BPS의 RIM 제외 회귀 검증 포함 관련 133개 테스트 통과. 운영 배포 없음.

## 자동·수동 재무 보완 경로 통합

자동 `VALUATION_SUPPLEMENT`의 과거 네이버 연간 보완 경로와 저장값만 재계산하던 분기를 제거했다. 수동과 같은 `supplementStoredPeriod` 및 `loadPeriodSupplement`를 사용해 DART 계정·동일 공시 주식수·한투 우선 결산 종가(KRX 보완)를 조회한다. 정확한 계정명 별칭, 과거 IFRS 코드, 전기 자본 투영, 보통주 EPS 검증 및 합산 주식수 참고 BPS/PBR 규칙도 공유한다. 원본 정상 값과 RIM 제외 규칙을 보존한다.

기존 야간/주말 시간대와 DART 공통 잠금·실제 API 일일 할당량을 유지한다. 자동 작업은 한 번에 최대 10기간·하루 최대 200기간을 처리하며, 미해결 자료는 하루 뒤 재시도한다. 과거 `reservedCalls` 예산 기록은 새 기간 예산에서 보수적으로 함께 산입한다. DART 키/기업코드가 없으면 무인증 DART 재요청 없이 저장 자료·가격 보완만 진행한다. API 한도나 시간대 종료 시 배치를 중단하고 기존 자료를 유지한다.

자동 보완 결과에 시간과 상태를 저장하고, 화면은 더 최근의 자동/수동 완료 상태를 사용한다. 자동 성공 후 예전 수동 실패가 남는 문제를 해결하며 새 수동 결과는 계속 우선한다. 일반 자동 수집기·DART 수집기·별도 투자동향 수집기는 같은 영구 토큰 볼륨을 공유한다.

자동 실제 공통 경로 테스트: 누락 공시 계정 별칭 조회 및 한투 종가 PER/PBR 계산, 0·정상값·원본 보존, 우선주 회사 참고 계산, API 한도 실패와 재시도 지연, 하루 기간 제한, 상태 우선순위 검증. 관련 수집기·공통 도메인·토큰 테스트 총 167개 통과. 로컬 자동 전체 수집 활성화나 운영 배포는 실행하지 않았다.

## 결산 당시 주가 기준 및 음수 배수

현재 수정주가와 원주가가 다르더라도 결산일부터 해당 공시일까지의 두 시계열을 조회하여 동일 날짜·종목·원종가, 1원 반올림 범위 내 공통 보정계수, 분할/변경 표시 없음 및 양끝 구간 확보를 검증한다. 해당 구간 안에서 기준이 변하거나 조회가 잘리거나 공급 근거가 없으면 계속 보류한다. 이후 권리 변동으로 과거 전체에 동일하게 적용된 보정은 당시 원종가 계산을 막지 않는다. 검증 구간·관측 수·종목·결산일·공시일을 별도 근거로 저장하고 동일 공시 주식수와 결합한다.

PER = 원종가 / 해당 기간 EPS, PBR = 원종가 / 해당 기간 BPS. 음수 분모는 음수 배수로 계산하며 수집 실패로 보지 않는다. 0 분모는 계산 대상 아님으로 완료 판정에서 제외한다. 기존 정상값과 원본 재무제표는 유지한다. 음수 PER/PBR 숫자는 파랑, 해당 레이블 옆 느낌표는 붉은 테두리·문자로 표시하며 클릭 툴팁에서 적자/자본잠식과 배수 해석 주의를 알린다.
