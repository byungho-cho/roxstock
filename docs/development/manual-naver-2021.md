# 수동 연간 네이버 보완 범위 (2026-10-09)

MANUAL_PROTOTYPE의 연간 네이버/FnGuide 경로 시작연도를 2023→2021로 확장한다. 올해 E와 과거 실적 구분, 정확한 연도·연간 열, 소스별 기준과 실패시 기존 정상 값 보존을 유지한다. 종목별 원천에 없는 연도는 다른 연도 값이나 추정 0으로 채우지 않는다. 2020년 이하와 분기는 기존 경로를 유지하며 이번 수정에서 보완을 확정하지 않는다.

자동 DART 수집기에는 이번 범위 확대를 적용하지 않는다. dart-worker는 기존과 같이 수동 큐를 처리하지만 자동 작업의 정책/원천/일정은 변경하지 않는다. 현대차에 대한 원천 조사에서 2021/2022 값이 확인된 것이며 모든 종목의 자료 존재를 보장하지 않는다.

검증: 2021/2022 정확한 원천·연도 저장, 원천 누락 시 기존 지표 보존, 기존 수동 갱신 회귀 및 백엔드 TypeScript·빌드. 운영 데이터 보완은 실행하지 않는다. 수동 검증 뒤 자동 적용은 별도 단계다.
