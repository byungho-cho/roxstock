# 수동 재무·가치지표 프로토타입 2차

수동 `financial-refresh`만 적용한다. 자동 worker, 스케줄, 기본 적용 종목 제한과 분기 계산식은 유지한다. 요청의 MANUAL 실행 모드를 확인한 경로에서만 NAVER 수집과 수동용 종목 검증 범위를 사용한다.

## 완료 기준

- 과거 연간 재무 필수: 매출, 영업이익, 순이익, 자산, 부채, 자본. DART 동일 공시·CFS/OFS 기준으로 판정한다. 공시 목록 확인은 재무 완성과 별개다.
- 연간 가치 필수: EPS, BPS, PER, PBR, ROE. 연도 말 기준 원천 그룹의 직접 수집값 또는 검증된 종가/분모 계산만 허용한다. 음수 EPS/BPS 및 0 분모의 PER/PBR은 `NOT_APPLICABLE`로 기록하며 정상 산출 불가로 완료 판정에 포함한다. 원천 미제공, 통신·파싱 실패, 근거 부족은 완료에 포함하지 않는다.
- 현재 연간 예상치: 원천 헤더의 해당 연도 `E`/컨센서스 표시가 필수다. 같은 5개 지표를 확인하되 누락 예상치를 계산하지 않는다. 확정 ANNUAL/Q1/Q2/Q3와 분리 저장한다.
- 상태: 현재 예상치 확보=ESTIMATE_READY(파랑), 재무와 지표 완료=COMPLETE(초록), 재무 완료/가치 미완성=FINANCIAL_ONLY(노랑), 미수집=NOT_COLLECTED(회색), 수집·보완까지 끝난 최신 시도 실패=FINAL_FAILED(빨강). 정상 미제공 예상치는 미제공 사유를 기록하고 회색; 일부 확보하되 필수 누락이면 PARTIAL_ESTIMATE(노랑). 실패가 남은 기존 정상값을 삭제하지 않는다.
- 처리 중에는 최종 실패로 판정하지 않고 이전 저장 상태와 최신 시도 진행을 함께 제공한다. 완료 판정은 서버에서만 한다.

## 원천·계산 정책

2024/2025 재무는 DART 우선, 가치지표는 NAVER/FnGuide의 연간 Financial Summary 우선. 펀더멘털 상단의 전일 주가/TTM 배수는 과거 기말 배수로 사용하지 않는다. 직접 제공 그룹의 EPS/BPS와 PER/PBR을 다른 원천의 분모와 무조건 합치지 않는다. 원천의 기말 수정주가·보통주 및 보통주+우선주 EPS/BPS 산식을 저장하고 DART 기반 보통주 계산의 검증 조건을 제거하지 않는다.

누락 지표는 저장 DART 공시, 누락 계정 재조회, 기간 말 실제 마지막 거래일 종가, 동일 공시 주식수 및 기업행위 검증 순서로 보충한다. 가격 기준·보통주 귀속·수정/비수정 기준이 확인되지 않으면 계산 실패 사유를 유지한다. 2023은 별도 검토 결과로 구분한다. 2022 이전 일괄 수집은 추가하지 않는다. 분기는 기존 누적 연환산 방식이고 새 연간 크롤링을 섞지 않는다.

저장에는 항목별 원천/기간/확정·예상/수집·계산/수집시각/가격 기준/산식/실패 사유를 포함한다. null 입력으로 기존 값을 덮지 않는다. 다른 분모를 사용하는 정상 새 원천 그룹으로 정정할 경우 이전 값·근거·새 버전·교체 사유를 보관한다. 수동 중복 요청과 공통 DB lock·DART 호출 예산을 유지하고 외부 크롤링은 종목별 한 번, 제한된 재시도만 한다.

임시 분석·회신·운영 검증 기록은 `docs/collector-feedback-20261008-152215` 브랜치에만 작성하며 PR #137을 main으로 병합하지 않는다. 이 개발 문서는 API/구현 계약이며 임시 소통 기록과 분리한다.

## 검증 및 적용 범위

백엔드 단위·API 테스트 139건, 프론트 상태·연도·스크롤 검사 45건(370×465, 725×396, 1280×800), 양쪽 TypeScript 검사와 빌드를 수행한다. 실제 MariaDB를 사용하는 원천→저장→두 분석 API 동일성·실패 값 보호 검사는 Backend Check에서 수행한다. 자동 수집 기본 모드의 KRX 제한과 수동 모드의 대표 3종목 범위를 각각 검사한다.

원천의 직접 제공 배수는 제공자가 명시한 수정주가 산식과 분모 기준을 기록하며, 별도 KRX 조회는 마지막 거래일 확인 근거다. 제공 배수를 KRX 비수정 종가로 재계산하지 않는다. 현재 컨센서스 가격 기준일은 원천의 기준 날짜를 사용한다. 새로운 계산 보충은 기업행위·보통주 귀속 검증을 통과한 경우에만 실행한다. 과거 모든 공시의 일괄 정정, 자동 수집 전환, 실제 API 미제공 자료의 생성은 범위 밖이다.
