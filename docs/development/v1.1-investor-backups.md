# V1.1.0 투자동향·DB 백업 시험 구현

기준일 2026-10-16. PR #243으로 V1.1.0 앱을 운영 배포하고 투자동향 수집기를 운영 DB에 연결했다. 후속 PR #244의 V1.1.1은 배포 메타데이터 갱신·시작일 문자열·백업 전용 DB 접속을 보완한다. `5316e99ee21d9089cbd9d9cd94f1a1fb4d688147` / `v1.0`은 롤백 기준으로 유지한다. 최종 배포·백업 확인 결과는 QA 문서의 운영 확인 기록을 따른다.

## 확정 범위와 보류

사용자 후속 지시에 따라 최근 3년 보충은 보류하고 **2026-10-16 이후 자료만** 수집한다. 기존 키와 공개 웹 응답으로 시험 구현하며 기존 수집기와 소스·이미지·컨테이너를 분리한다. 공급자의 제공 범위와 이용 조건이 전부 확인된 정식 공급 경로는 아니다. 인증 우회·차단 회피는 구현하지 않는다.

화면 3100은 [커버](https://www.figma.com/design/HFguP6QYb6xnO9FRsjYlc2?node-id=3883-107), [태블릿](https://www.figma.com/design/HFguP6QYb6xnO9FRsjYlc2?node-id=3888-687), [백업](https://www.figma.com/design/HFguP6QYb6xnO9FRsjYlc2?node-id=3910-76)을 기준으로 한다. Figma는 수정하지 않았고 예시 숫자·날짜는 앱 데이터로 사용하지 않았다.

### 10/16 C3100 최신 디자인 후속 반영 · 로컬 작업

최신 확정 기준(3883:207)과 커버·태블릿 렌더를 다시 대조했다. 본문 세로 간격 4px, 카드 12px/16px 패딩·1px 테두리·8px 라운드, 날짜 바 40px, 헤더 탭 32px, 기간 버튼 28px 및 차트 본체 124px를 적용한다. 공통 PageLayout의 헤더·하단 메뉴 44px와 본문 단일 스크롤을 유지한다. 날짜의 네이티브 달력 입력과 좁힌 아이콘 간격도 유지한다.

하단은 일자별 거래실적으로 교체한다. `GET /investor-trends/history`는 선택일 이하의 저장된 날짜를 최신순 50개씩 반환하고 다음 날짜 커서로 이어 붙인다. 날짜·종가·개인·외국인·기관 5열, 날짜 48px 고정/나머지 균등, 행 상하 4px. 대상·날짜·단위별 쿼리 키를 분리해 이전 응답 혼입을 막는다. 끝에서는 더보기를 숨기며 목록은 차트 기간 선택과 별개로 유지한다.

금액은 백만원(소수 둘째 자리 반올림), 수량은 주이며 BigInt로 표시 계산해 큰 정수 정밀도를 보존한다. 원본 정밀도는 값의 title에 유지한다. 종가에는 백만원 환산을 적용하지 않는다. 수집 원문에 KRX 종가와 공급자의 부호 있는 전 거래일 등락값을 추가 보관한다. 등락값이 없으면 이전 저장일을 임의의 전 거래일로 간주하지 않고 기본색을 유지한다. 기존 원문에 없는 종가는 `—`이다. 시장 지수와 거래대금 미검증 자료도 계속 `—`이며 디자인 예시로 대체하지 않는다.

자동 수집 시작일 10/16과 3년 보충 보류는 유지한다. 별도 승인된 로컬 10/15 일회성 자료는 읽기 API에서 조회 가능하다. 종목별 화면의 기본 지표는 실제 제공되는 거래량이다. 운영 DB 쓰기·과거 대량 수집·배포는 이번 디자인 작업에 포함하지 않는다.

## 공급 경로의 실제 확인 결과

한국투자증권 연동 키도 별도 비밀 파일을 만들지 않고 기존 DART·KRX와 같은 환경파일에서 관리한다. 로컬은 현재 실행 설정이 읽는 `D:/workspace/roxstock/backend/.env`, 운영 원본은 `/opt/roxstock/backend/.env.production`이며 변수명은 `KIS_APP_KEY`, `KIS_APP_SECRET`이다. 투자동향 전용 배포는 기존 절차대로 해당 운영 원본을 배포 작업 트리에 권한 600으로 복사하고, 수집기 컨테이너의 `env_file`로 주입한다. 이미지·Git·프론트엔드에는 키를 넣지 않는다. 키 변경 후에는 환경을 사용하는 해당 프로세스/컨테이너를 다시 생성해야 한다. 환경파일 관리 경로 정리는 완료했으나 한국투자증권 인증·데이터 수집 연동은 별도 검증 전이다.

### 한국투자증권 실제 연동 후속 · 10/16 로컬 검증 완료

#### 최종 보충 수집 정책 · 로컬은 2개월만 검증

운영 예정 범위는 2020-01-01 이후이며 한 요청에 포함된 약 30거래일을 즉시 묶어서 저장하고 가장 오래된 날짜 직전으로 커서를 내린다. 요청 시작 간격 최소 2초, 단일 요청, 네이버 호출 없음. 로컬은 사용자 후속 지시로 2026-08-16 이후만 시험했다. 로컬 공통 환경에 `INVESTOR_BACKFILL_ENABLED=false`, `INVESTOR_BACKFILL_FROM=2026-08-16`을 두어 추가 본수집을 막았으며 운영 파일은 변경하지 않았다.

`backfill.mjs`는 별도 `investor-trends-backfill` 실행과 종목별 diagnostics에 from/until/cursor/pages/rows/state/tradingDates를 보존한다. 자료 upsert와 다음 커서·거래일 목록은 동일 DB 트랜잭션에 저장한다. 기존 투자동향 owner 잠금을 공유하고 만료·소유권과 종목 제외·코드 변경을 재확인한다. 실패 시 커서는 진행하지 않으며 일시 오류는 최대 3회 후 1시간 대기, 잘못된 자료·인증 등은 BLOCKED로 남긴다. 제공 이력 소진은 두 번의 빈 응답과 기존 확보 자료를 확인하고 EXHAUSTED로 구분해 2020년 전체 확보로 오인하지 않게 한다.

최초 대상은 기존 거래/관심 이력의 활성·수집 가능 종목(현재 37개), 이후 신규 대상은 실제 잔여 보유 또는 관심 종목만 추가한다. 완료 대상은 조회를 재개하지 않으며 일별 최신 수집은 별도로 유지한다. 데몬은 정규 수집을 먼저 확인한 뒤 보충을 10요청 단위로 진행하고 잠금을 반납해 정규 작업을 장시간 막지 않는다. `--backfill`은 명시적인 보충 단독 실행이다. 운영 시장별 API는 여전히 단위·범위 확인 대기로, 이번 로컬 보충에는 포함하지 않았다.

KIS 관측치는 개인·외국인·기관 합계에 증권/투자신탁/사모펀드/은행/보험/종금/기금 7개를 더해 총 10주체를 저장한다. 기관 세부 결측은 null로 보존한다. 화면 및 누적 API는 개인·외국인·기관 합계 3개만 반환하며 세부를 기관 합계에 재합산하지 않는다. 과거 보충 진행은 모니터링 투자동향 상세에 별도로 표시한다.

누적 계산은 보충 페이지와 함께 원자적으로 저장한 공급자 거래일 목록을 사용한다. 해당 확보 범위 내 휴장일은 자료점 없이 건너뛰고, 공급자 거래일 목록에 있는 날짜/주체의 DB 관측치가 빠지면 선을 끊는다. 일반 평일이라는 이유만으로 휴장일을 누락으로 취급하지 않고, 실제 누락을 0으로 채우지도 않는다.

호출 제한 확인(10/16): 공식 [유량 공지, 2026-04-20 기준](https://apiportal.koreainvestment.com/community/10000000-0000-0011-0000-000000000001/post/d0d1a83f-6f8d-4437-9700-6d26702fd989)은 계좌 단위 실전 REST 18건/초, 모의 1건/초, tokenP 발급 1건/초를 안내한다. [신규 신청 제한 공지](https://apiportal.koreainvestment.com/community/10000000-0000-0011-0000-000000000001/post/c1113824-17c7-47a7-b7b8-8880506a847c)는 신청 후 3일간 3건/초(모의 제외)를 안내한다. 확인한 공지에는 하루 총 호출 횟수 한도가 명시되지 않아 일일 무제한을 보장하지 않는다. 기본 worker는 2초 간격의 직렬 조회이며 같은 계좌를 사용하는 다른 프로그램과의 합산 유량도 고려해야 한다. 발급 키의 개별 확대 한도는 확인하지 않았다.

당일 순매수 셀렉트 옆 단위 표시는 사용자 지시로 제거했다. 일자별 목록과 설명·툴팁에는 백만원/주 단위를 유지하며 숫자 변환 기준은 변경하지 않았다. 커버·태블릿에서 셀렉트 전환 및 가로 넘침 없음을 확인했다.

최신 사용자 지시로 투자동향 네이버 수집은 전부 비활성화했다. worker는 KIS_API만 호출하며 키가 없거나 실패해도 네이버로 자동 대체하지 않는다. 시장별도 네이버를 호출하지 않고 `API_MARKET_NOT_READY` 대기 이력을 남긴다. 기존 저장 관측치는 삭제하지 않아 읽기에서 재사용할 수 있다. 이 지시는 투자동향 수집 범위이며 운영 배포는 미수행이다. 아래의 이전 네이버 수집 경로 설명은 변경 이력이다.

한국투자증권 실제 과거 조회: 008770·005930·000660 모두 입력일 2023-10-16에서 2023-10-16~2023-08-29 30거래일×3주체 응답, 2023-09-01에서 2023-09-01~2023-07-21 응답을 확인했다. 금액·수량 제공을 확인했으므로 날짜를 이전 응답의 최저일보다 앞당겨 반복하는 3년 보충 구현이 가능하다. 이는 과거 구간의 표본 조회 검증이며 전 종목 3년 자료의 무결성 검증이나 DB 저장 완료를 의미하지 않는다. 대량 보충·정규 시작일 변경은 아직 하지 않았다.

위 인증 검증 전 기록 이후 사용자 입력 키로 실전 인증과 종목별 일별 투자동향 조회를 확인했다. `kis-provider.mjs`는 공식 `oauth2/tokenP`와 `investor-trade-by-stock-daily` GET만 사용한다. TR `FHPTJ04160001`, 시장 구분 `J`(KRX), 고객구분 P. 주문·계좌조회 API를 호출하지 않는다. 토큰은 프로세스 안에서 만료 전까지 재사용하고 동시 발급 요청을 합친다. 키·토큰·공급자 원문 오류 메시지는 로그·DB·브라우저로 전달하지 않는다.

공식 공개 명세의 원본 거래대금 단위는 백만원이다. 매수·매도·순매수 금액을 BigInt로 1,000,000배 해 KRW 필드에 저장하고 원래 정수 값과 `MILLION_KRW` 단위를 raw에 보존한다. 수량은 주, 매수−매도=순매수 정확 일치를 검증한다. 금액은 원본 각 항목의 백만원 반올림 차이 최대 1단위만 허용하고 차이도 raw에 기록하며 원본 순매수 값을 임의 보정하지 않는다. 결측·중복 날짜·요청일 이후 자료·비정상 응답은 저장하지 않는다.

키가 있으면 종목 수집은 KIS_API를 사용하며 인증 실패를 네이버 성공으로 감추지 않는다. 읽기 API는 일자·선택 지표 기준으로 개인/외국인/기관 전체가 유효한 KIS_API를 우선하고, 없으면 기존 NAVER_WEB 자료를 사용한다. 하루의 서로 다른 공급자 주체를 섞거나 두 공급자의 값을 합산하지 않는다. 기존 네이버 관측치는 삭제하지 않는다. 시장별 `FHPTJ04040000` 조회 응답은 확인했지만 공식 단위·거래소 집계 범위를 아직 확정하지 않아 연결·저장하지 않았다. 시장 경로는 기존 미검증 원문 상태를 유지한다.

## v1.1.4 결산 기준 한투 빈 지표 보완

한투 연간 financial-ratio/balance-sheet/income-statement를 2초 이상 간격으로 조회한다. 현재가 API의 기준일 없는 EPS를 결산 카드에 대입하지 않는다. stac_yymm=대상연도12의 연간 값만 받으며, 같은 연도 DART 공시의 자본·자산·당기순이익·매출액과 제공 정밀도(억원 반올림 ±0.5억원) 내 일치하고 연결/별도 기준이 하나로 확정되는 경우만 사용한다. EPS는 제공값 자체를 사용하며 기말 주식수로 역산하지 않는다. BPS는 동일 공시 보통주 분모와 자본의 대조까지, ROE는 동일 기준 전년말·당년말 평균자본 계산까지 추가 확인한다. 기존 비어 있지 않은 값과 수정·추정 연도는 덮어쓰지 않는다. PER/PBR은 이 연간 API에서 제공하지 않아 근거 없는 현재 배수로 과거를 채우지 않는다.

연간 보완은 기존 kis-fundamentals 예약 수집에 결합했다. 실제 저장 직전 제외 설정/종목 변경/소유 잠금을 재검증하고 period_valuations 원래 값 중 null만 채우며 원천 응답·공시 대조·항목별 출처를 보관한다. 원자적으로 금융 캐시 리비전을 갱신한다. 연간 API 실패 시 현재 참고값 저장은 유지하되 PARTIAL로 기록한다. 추가 DB 테이블/마이그레이션은 없다.

문배철강의 legacy v1 별도 BPS 기준 표기가 일반 소유주 표기로 저장되어 있던 경우를 호환한다. 동일 연도·별도 공시·접수번호·우선주 없는 보통주 근거와 자본/주식수=BPS 대조를 통과할 때만 초과이익·주주가치를 계산하며 기존 주당 가격은 유지한다. 데이터 캐시 형식을 5로 올려 기존 null 캐시도 재계산한다.
