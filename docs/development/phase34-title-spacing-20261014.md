## 원인과 변경

대시보드·자산분석에는 Toolbar의 왼쪽 여백을 0으로 덮어쓰는 설정이 남아 있었다. AppLayout에 화면별 글자 크기15~22px·굵기·줄높이·정렬·뒤로가기 너비를 덮어쓰는 설정이 누적돼 공통 PageHeader 기준과 달랐다.

- AppLayout의 화면별 타이틀 스타일 덮어쓰기를 제거하고 PageHeader에서 일괄 관리한다.
- 상단 높이44px, Toolbar 좌우8px, 일반 제목22px/줄높이30px/굵기700, 세로 중앙/왼쪽 정렬.
- 뒤로가기가 있는 하위 화면 제목18px, 아이콘과 제목 간격8px. 이미지 아이콘은 종횡비를 보존한다.
- 종목 이동을 위한 두 줄 헤더는 제목14px/줄높이22px로 공간을 분리하고 기존 이동·액션을 유지한다. 홈 계좌 선택 등 제목 안의 전용 콘텐츠는 기존 표시를 유지한다.
- 메인 메뉴의 뒤로가기 제거 정책, 하위 화면 뒤로가기·추가·수정 등의 동작, 본문 스크롤·하단44px·데이터 조회는 변경하지 않는다.

## 추가: 자산분석 차트의 고정 프레임 우선 표시

자산추이 제목·격자·축 공간·기간 버튼을 API 이전에 렌더링한다. 일반 차트 영역224px와 차트200px를 유지하고, 응답 전에는 선을 표시하지 않으며 금액 축은 —로 표시한다. 데이터 도착 시 선과 실제 축 값을 채운다. 동일 조건 재조회는 기존 선을 유지한다. 계좌/기간 변경 시 새 대상의 데이터가 오기 전에는 이전 대상 선을 표시하지 않는다. 빈 결과·오류/재시도는 같은 프레임 안에서 표시한다. 상세보기의 차트 스켈레톤도 고정 프레임으로 바꿨다.

SnapshotChart emptyFrame은 자산분석만 사용하는 선택 옵션이다. 다른 차트의 기존 표시·조회·툴팁·드래그 정책은 유지한다. 기존18·20차 회귀는 ‘프레임 있음 / 선은 응답 후 있음’을 구분해 검사한다.

커버370×465·태블릿725×396 신규4건과 관련 회귀8건을 확인했다. 최초 태블릿 툴팁 검사의 화면 밖 좌표를 수정한 뒤 해당 검사를 재확인했다. 최종12개 시나리오 통과, 프론트 TypeScript·빌드 통과. 계좌 응답 이전 고정 요소 표시, 지연 응답 전후 높이/버튼 위치, 선·툴팁, 상세보기, 오류·빈 상태를 검증했다. 모의 캡처는 docs/qa/assets/phase34/asset-frame-{pending,ready}-{cover,tablet}.png. 로컬 반영이며 병합·배포는 하지 않았다.

## 기간 성과 금액 빈 칸 및 버전

기간 성과 구성의11개 금액/수익률 칸은 API 대기 중 스켈레톤 대신 빈 상태를 표시한다. 고정 행 높이와 최소 값 영역 너비를 유지하며 응답 후 실제 값/조회 완료 후 결측 표현을 표시한다. 동일 조건 갱신은 기존 값을 유지한다.

릴리스 버전을1.0.34로 증가시켰고 DEV 프론트·백엔드를 재시작했다. 실제 DEV API를 지연시킨 Chromium 확인에서 차트 프레임 존재, 차트 스켈레톤0, 기간 성과 스켈레톤0,11칸 모두 빈 값, 응답 후 값 채움과 메뉴/백엔드의1.0.34 표시를 확인했다. 실제 응답 내용·계좌 금액은 보고서에 복사하지 않았다. 관련 커버·태블릿 금액 빈 상태/높이 유지 회귀를 보완했다.

## 自산분석 전체 빈 상태 최종 적용

총자산·자산구성·시세 시각·기간 범위·복리계획에 남아 있던 스켈레톤을 제거했다. 자리 높이/너비는 배경 없는 빈 Box로 유지하고, 자산구성 막대는 조회 전 배경과 조회 중 문구도 비워두되12px 영역을 유지한다. 실제 DEV API 지연 검사에서 화면 전체 MuiSkeleton0·11개 성과 칸 빈 값·차트 프레임 표시 및 API 응답 후 값 채움을 확인했다. V1.0.34 유지. 커버/태블릿 관련12검사 모두 통과했고 최신 대기/완료 캡처로 교체했다.

## 최초 코드 다운로드 대기 화면 수정

API 대기 외에 lazy 페이지 다운로드의 공통 Suspense 화면에도 스켈레톤과 회전 표시가 남아 있었다. /assets 전용 다운로드 화면을 빈 차트·카드 틀과 고정 제목/레이블로 교체하고 회전 표시를 제거했다. 실제 페이지는 lazy 로딩을 유지한다. 카드 테두리·제목 높이를 실제 화면과 맞춰 차트 위치와 크기를 유지한다. 커버·태블릿에서 페이지 코드 다운로드를 지연시킨 신규 검사와 API 대기/오류/빈 상태 관련 검사 총14건 통과. 프론트 빌드 및 타입 검사 통과. 실제 DEV 최초 코드 다운로드 검사도 스켈레톤0·회전 표시0·차트 틀 표시를 확인했다. 로컬 V1.0.34 적용이며 병합/배포하지 않았다.

PR 회귀 검사에서 기존 제목 여백0px 기대를 새8px 기준으로 현행화했다. 차트 프레임이 즉시 나타나면서 제스처 검사가 코드 로딩 프레임을 잡는 경쟁이 발생해 실제 데이터 선 표시 후 검사하도록 준비 조건을 보완했다. 기존 operating-fixes 기능5건 로컬 통과.

자산분석 기존 v0.4 검사에서 오래된 메인 메뉴 뒤로가기 버튼 기대를 현행 정책(상단 뒤로가기 없음·하단 홈 이동)으로 수정했다. 네 화면 크기의 기존 기능16건 모두 로컬 통과.

최초 다운로드 화면 기간 버튼이 기존 페이지와 달리 URL에 period를 기록하는 차이를 제거해 다른 계좌 기본기간으로 전파되지 않도록 했다. 계좌 전환/뒤로가기/결측 툴팁6건 및 최초 코드/API 로딩14건 재검증 통과. 데이터가 없는 초기 프레임과 실데이터를 구분하여 제스처 검사를 시작한다.
