# 복리계획·목표 카드 및 실현자산 차트 보완 (2026-10-09)

기준 main: 65f4f58 (PR #169 포함). 별도 작업 브랜치에서 진행하며 PR #137은 제외한다. 이번 명세가 이전 요약 카드 색상·입력 팝업 이력 규칙을 대체한다.

## 요약 카드 및 이동

`CompoundGoalSummary`를 목표 상세와 자산분석에서 공유한다. 자산분석은 계좌 전체의 복리 조회와 자산 이력 API가 지정한 현재 계획 ID를 대조하고, 해당 계획의 `isDefault` 목표만 사용한다. 기본 목표가 없으면 연결하지 않는다. 계획명·연 수익률·기본 목표·현재 자산·올해 목표·최종 목표·기존 최종 목표 기준 진행률을 표시한다. 기본 목표의 노란 테두리와 등록 제목색을 유지한다.

카드 전체는 계좌·계획·목표 ID와 `view=goal`을 전달하여 직접 상세로 이동한다. 공통 `useListNavigation`/`useReturnNavigation` 및 페이지 메모리·스크롤 복원을 사용한다. 분석 기간·조회 범위·원래 이력 항목으로 돌아간다. 명시된 계획/목표가 없으면 다른 항목으로 대체하지 않는다. 조회 오류·계획 없음·기본 목표 없음은 개별 상태로 표시한다. 응답의 계좌 ID·연도·계획/목표/연도별 행 구조를 확인하여 잘못된 응답이 분석 화면 전체를 중단하거나 다른 계좌 목표를 연결하지 않게 한다.

목표 설정은 기존 `기간 · N년` 행을 유지하고 `시작 연도` 행을 `기간 · 시작 ~ 종료`로 변경한다.

## 금액 색상

올해 목표는 공통 흰색 토큰이다. 현재 자산 / 올해 목표가 90% 미만이면 파랑, 90% 이상 110% 이하이면 노랑, 110% 초과이면 빨강이다. `compoundAchievement`는 소수 문자열을 정수와 배율로 분해하여 BigInt 교차 곱으로 비교한다. 표시 반올림·부동소수점 오차·안전 정수 범위를 넘는 금액 때문에 경계가 바뀌지 않는다. 목표 누락/0 이하 또는 현재 자산 미수집은 중립색이다. 진행률은 기존 현재 / 최종 목표 기준이며 올해 대비 비율로 대체하지 않는다. 목표 자산은 흰색이다. 올해 목표 배경과 노란 기준선·부족/초과 금액 및 현재 자산 상태색의 진행 막대는 [17차 후속 기준](phase17-followup.md)을 공유한다. 과거 표의 금액색은 유지한다.

## 차트

기존 `goal.rows`를 단일 화면 데이터로 사용한다. 과거는 서버가 조회한 해당 계좌의 정확한 12월 31일 스냅샷, 올해는 같은 조회의 `currentAssets`, 미래·연말 누락은 null이다. 0은 유효하다. 기존 예상 자산·누적 투입금 선은 유지하고 실현금액을 공통 붉은색 선/점/범례로 표시한다. null마다 경로를 분리하며 고립된 값도 점으로 보인다. 기존 현재 자산 점은 실현 계열로 통합한다.

마우스 이동·터치 탭·연도별 키보드 초점과 좌우/Home/End 키로 연도/목표/누적 투입금/실현금액을 조회한다. Escape는 툴팁을 닫는다. 툴팁은 차트 내부 폭에 제한하며 긴 금액을 줄바꿈한다. SVG는 `touch-action: pan-y`이고 손가락 이동을 preventDefault하지 않는다. 기존 3열 표와 툴팁은 동일 행 데이터로 표시한다.

## 조회 갱신과 입력 이력

`useCompoundPlans`는 `compound-plans / 계좌 / 서울 연도` React Query 키를 사용한다. 거래·예수금·복리 변경은 기존 `invalidatePortfolio` 흐름을 재사용한다. 현재가 편집도 같은 흐름으로 연결한다. 계좌 키와 AbortSignal로 늦은 응답을 분리하며 연도 변경 시 이전 같은 계좌의 내용을 유지한 채 새 조회를 한다. 활성 화면은 60초마다 저장된 자산/시세를 다시 읽고 창 복귀 시 갱신한다. 서울 연도 확인은 1초 간격 및 창/문서 복귀 시 수행한다. 수집을 실행하거나 일정을 변경하지 않는다.

일반 복리 입력은 기존 URL `form`을 유지한다. 열기는 별도 이력 push, 닫기·취소·저장 후 닫기는 해당 이력을 back으로 소비한다. 직접 입력 URL 진입에는 replace로 form만 제거한다. 저장 완료 시 현재 이력이 저장을 시작한 입력 이력과 같은지 확인하여 뒤로가기로 이미 닫은 입력이 페이지 이력을 다시 소비하지 않는다. 커버는 전체 입력 화면, 태블릿은 동일 URL 기반 팝업이다. 로컬 공통 팝업 이력을 중복 적용하지 않는다. 삭제·기본 목표 변경 확인 및 알림은 기존대로 유지한다.
