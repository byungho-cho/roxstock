# 목록 복귀 상태 공통 규칙 (v0.4 사용자 테스트 1차)

목록에서 상세·입력 화면으로 이동한 뒤 헤더 또는 브라우저 뒤로가기로 돌아오면 해당 이력 항목의 UI 상태와 실제 본문 스크롤을 복원한다. 계좌·화면·이력 항목·목록 조건을 구분한다. 새 메뉴 진입은 독립된 상태로 시작하며, 다른 계좌의 위치나 검색어를 사용하지 않는다. 당겨서 새로고침은 포함하지 않는다.

## 공통 코드

- `usePageMemory(name, initial)`은 화면의 탭·검색·필터·정렬·조회 기간·불러온 범위를 sessionStorage와 메모리에 저장한다. 데이터 자체를 복제하거나 계산하지 않는다.
- `useListNavigation()`은 이동 시 현재 화면의 URL과 이력 인덱스를 `returnTo`로 전달한다. 입력 화면은 가까운 원래 화면으로 복귀한다. 이전·다음 종목 탐색만 `useListNavigation(true)`로 원래 목록을 이어받는다.
- `useReturnNavigation(fallback)`은 원래 이력 항목으로 이동한다. 직접 URL 진입 시 안전한 대체 경로를 사용한다. 브라우저 뒤로가기도 같은 저장값을 읽는다.
- `usePageScrollRestoration(mainRef)`은 실제 main 및 `data-scroll-region`을 각각 저장한다. `window.scrollY`를 사용하지 않는다.
- `data-list-condition`은 조건별 스크롤을 구분한다. `data-scroll-item`은 안정적인 항목 ID이다. 기존 항목이 삭제되면 저장 당시 순서의 다음 항목, 이전 항목, 또는 가능한 최대 스크롤 위치로 복원한다.
- 비동기 목록은 `data-restoration-ready`를 제공한다. 저장 위치가 있는 로딩 영역은 준비될 때까지 숨기고 레이아웃 단계/DOM 변경 직후, 그리기 전에 복원하여 최상단 깜빡임을 방지한다. 오류 응답은 준비 상태로 전환해 오류 안내를 숨기지 않는다.
- 팝업은 배경 이력 항목을 유지한다. 팝업 열기/닫기로 배경 조건·선택 종목·좌우 스크롤을 초기화하지 않는다.

## 현재 적용

종목목록의 분류·검색·정렬·방향과 펼침 좌우 목록, 종목 상세의 선택 탭과 Lot/거래 위치, 가치분석의 연간/분기·조회 선택, 매매일지의 월·선택 날짜·상세 모드·거래 선택·독립 스크롤, 예수금의 월/연간·조회 기간·추가 조회 범위·내역 스크롤에 적용한다. 홈 본문 복귀에도 동일한 공통 스크롤 처리를 사용한다. 서버 거래·예수금·자산 계산과 다른 화면의 기간 스와이프는 변경하지 않는다.

## 이후 화면 적용

목록 조건은 `usePageMemory`, 실제 스크롤 영역에는 고유한 `data-scroll-region`, 항목에는 서버 ID의 `data-scroll-item`, 비동기 데이터에는 준비/오류 상태를 연결한다. 목록→상세·편집은 공통 이동/복귀 훅을 사용한다. URL의 분류를 replace할 때에는 `listEntryKey`를 기존 이력 키로 이어받아 검색·정렬 상태를 유지한다.

## 2026-10-03 검사 조건과 중단 복구

세 분류에 각각 30개 등록/보유/거래 자료를 사용한다. `stock-scroll-restoration.spec.ts`는 실제 스크롤 범위가 420px보다 큰지 먼저 검증하고, 420px 이동 후 입력 닫기와 브라우저/헤더 뒤로가기에서 위치를 각각 비교한다. 종목 선택은 현재 보이는 중간 행을 사용하여 클릭 자체가 목록을 자동 스크롤하지 않게 한다. 각 분류의 검색어·종목명 오름차순·분류 URL도 함께 확인한다. 계측 JSON은 `stock-scroll-evidence`에 남긴다.

직전 검사에서 보유 목록은 충분한 자료로 복원을 확인했지만, 관심·거래의 상세 목적지 검사만으로 스크롤 복원까지 검증했다고 간주하지 않는다. 새 검사는 실제 스크롤 전제를 만족해야 통과하며, 위치가 복원되지 않는 경우 공통 훅의 제품 오류로 처리한다. 통과한 앱 TypeScript/빌드/기존 기능 검사는 관련 소스가 변경되지 않았으므로 재실행하지 않는다. 진행 상태는 [기존 인수인계의 2026-10-03 개발 복구 기록](../handoff/20260927-1617-server-backend-final.md)을 참조한다.
