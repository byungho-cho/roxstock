# 주식수 수집·표시 및 계좌 카드 보완 (2026-10-09)

## 구현 기준

DART stockTotqySttus의 istc_totqy / tesstk_co / distb_stock_co를 각각 발행 / 자기 / 유통주식수로 저장한다. 새 dart_share_snapshots 테이블은 종목·사업연도·보고서·접수번호·원문 주식 종류·분류·결산일·수집시각을 가진다. 보통주/우선주/합계를 별도 행으로 보존하고 비고 행은 제외한다. 동일 종목+접수번호+원문 종류가 유일키다. 마이그레이션은 새 테이블만 생성하며 기존 자료를 삭제하지 않는다.

세 숫자가 있으면 발행-자기=유통을 검증한다. '-'는 null이고 숫자 0은 0이다. 누락 응답은 기존 정상 숫자를 덮어쓰지 않는다. 저장은 트랜잭션이다. 정상 응답에서 명시적으로 미제공된 우선주 항목은 null로 보존하며, 비고 또는 미제공 항목 때문에 정상 보통주 캐시를 계속 무효화하지 않는다.

수동/정기 수집은 같은 추출·저장 경로를 이용한다. 기존 SUCCESS 가치지표라도 구형 유통주식수 캐시만 있으면 sharesOnly 경로로 보충한다. 가치지표 상태·정상 계산값을 유지한다. 최신 정정 접수번호와 캐시 접수번호가 다르면 재조회한다. 기존 성공 수집 상태를 초기화하지 않는다.

EPS 공시 가중평균 기준, 기존 BPS 유통주식수 분모, 기존 RIM 수동 입력 기준은 변경하지 않는다. 기존 BPS는 이미 유통주식수를 사용하므로 자기주식수를 추가 차감하지 않는다. 수동 fundamentals 값도 덮어쓰지 않는다.

## 조회·표시

가치분석 상세는 발행/자기/유통 순서의 독립 행을 사용하고 쉼표+주 단위를 표시한다. API는 shareBasis로 종목의 공시 종류·접수번호·기준일을 제공한다. 기준연도의 최신 공시를 먼저 고르고 그 접수번호의 동일 종류 값을 읽는다. 정정 공시가 아직 미수집이면 이전 공시 숫자로 대신 채우지 않는다. 다른 연도나 현재 수동 주식수도 대신 사용하지 않는다. 기본 종류는 COMMON이며 상세 API의 shareClass=PREFERRED 또는 TOTAL로 별도 검증할 수 있다. 분기 조회는 지정 분기의 공시 기준을 사용한다.

가치분석/재무제표 목록의 발행주식수도 이 저장값을 사용한다. 유통주식수를 발행주식수로 표시하지 않는다.

계좌 카드는 실제 계좌번호를 보조 글씨로 표시한다. 기존 번호가 없는 계좌는 (—)이며 운영 자료를 임의 정정하지 않는다. 선택/사용중 버튼 대신 전체 카드에 키보드 가능한 선택 버튼을 두고 연필은 독립 버튼이다. 같은 계좌 재선택은 무시한다. 공통 선택계좌 상태만 변경하며 DB 기본계좌는 변경하지 않는다. 계좌별 조회 키와 기존 갱신 로직을 유지한다. 상단 연필 1개, 노란 선택 테두리·제목, 15.1차 색상 및 초기화·삭제 조건을 유지한다.

## 기존 자료 보충

```sh
# 환경의 DATABASE_URL을 확인한 후 실행. 기본은 읽기 전용 대상 건수 조회.
npm --workspace backend run supplement:shares
npm --workspace backend run supplement:shares -- --apply --symbol=005930 --limit=50
# 운영 이미지에서는
node backend/dist/scripts/supplement-shares.js --apply --symbol=005930 --limit=50
```

2015~현재 연도의 저장된 최신 공시만 대상으로 하며 올해 우선종목부터 최근 연도 역순이다. 재무제표 전체를 다시 수집하지 않는다. 공유 락, 일일 호출 예약, 2초 간격을 사용하고 제한 시 중단한다. 재실행은 완성된 동일 공시 보통주를 건너뛴다. 필요할 때 기존 공시 캐시의 정확한 접수번호로 같은 종목의 기업코드를 검증해 사용한다. 모호한 연결은 사용하지 않고 기존 매핑을 변경하지 않는다. target/attempted/success/partial/failed/remaining을 출력한다. partial은 원천 미제공 또는 종류 불명확이며 실패와 구분한다. 전체 자동 수집 스케줄은 변경하지 않는다.

## 운영 검증 후 명칭 보완

운영 추가 보충에서 기업은행(024110)의 '의결권 있는 보통주'가 확인되어 명확한 보통주·우선주 변형 명칭을 공통 분류한다. 보통/우선 혼합 명칭, '의결권 있는 주식' 등 명확하지 않은 종류와 원천 오타는 OTHER로 보존한다. 같은 공시·분류에 여러 원문 종류가 있으면 임의의 첫 행을 표시하거나 합산하지 않고 —로 유지한다. 운영 1차 보충: 삼성전자43공시(성공12/부분31/실패0), 우선종목50공시(성공20/부분29/실패1). 실패 060310/20260617000470은 SHARES_PERIOD_MISMATCH이며 원본 공시나 값을 수정하지 않았다. 전체 재무자료26,640건 보존, 주식수219행 저장, 보통주 세 값 완성32공시. 잔여26,608공시는 완전 보충되지 않았으며 부분·미시도 자료를 포함한다. 운영 자동 배포 c154b048 성공 및 백업/마이그레이션 확인. 명칭 후속 보완 배포 결과와 해당 종목 재검증은 완료 보고에서 별도로 남긴다.
