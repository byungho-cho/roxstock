# 23차 구현 기준 · 2026-10-12

사용자 23차 최종 지시를 우선한다. 기준 main은 `2fa7198318d5b131b8880748d8e6021fcc6c5bcb`이다. 21차 구현 #198, 배포 가드 #202, 완료 문서 #203을 유지한다. 작업 중 문서 초안 #204의 22·23차 확정 명세를 대조했다. 22차 구현 PR은 확인되지 않았으며, 본 작업에 22차 가치분석 변경을 섞지 않는다. #197/#204는 별도 문서 작업으로 유지하며 소통 PR #137은 병합하지 않는다.

- 집계의 성공·실패는 해당 기능의 최근 실행에 실제 기록된 대상 행을 기준으로 한다. 과거 DART 전체 계획 진행률은 별도 기존 진행률에 유지한다. 집계 클릭은 동일 실행 ID와 결과 상태를 서버 페이지 조건에 전달한다.
- 조회는 첫 50개와 다음 50개를 서버에서 제한한다. 요약 3개, 상세 본문 단일 스크롤을 유지한다.
- 제외는 전체 외부 수집과 기능별 설정을 구분한다. Z99 접두어는 정규화 후 자동 전체 제외이며 사용자 해제는 불가하다. 일반 사용자 제외는 재활성화 가능하나 별도 재수집 작업을 생성하지 않는다.
- 기존 등록 출처는 `UNKNOWN`이다. 코드·시장·DART 매핑으로 사용자 출처를 추정하지 않는다. 신규 직접 등록은 `MANUAL`, 신규 종목 마스터 수집은 `SECURITY_MASTER`이며 `DART`와 미확인 출처는 코드 정정 불가하다.
- 내부 종목 ID를 유지한다. 코드 정정 전에 수집 자료의 보존 사본과 정정 이력을 기록한다. 기존 행의 코드 근거는 바꾸지 않고 현재 코드가 다른 자료는 현재 조회에서 숨긴다. 이후 새 수집/수동 가격 저장은 현재 코드 근거를 기록한다.
- 삭제는 참조가 없는 종목만 확인 후 마스터 비활성화한다. 보유·매매·관심·배당·과거 보유 스냅샷 참조는 서버에서 차단한다. 물리 삭제와 연쇄 삭제를 하지 않아 기존 수집 자료·이력을 보존한다.
- APK 카드는 기존 배포 메타데이터의 URL/버전을 그대로 사용하며 카드 전체를 다운로드 링크로 만든다.

확정 요구와 실제 검증·배포 완료 상태는 개발·검증 문서에 구분해서 기록한다.
