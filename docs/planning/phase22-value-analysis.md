# 22차 가치분석 최종 구현 기준

기준: PR #204의 22차 명세 및 2026-10-12 사용자 지시. 23차 관리 기능·24차 UI는 별도 범위이며 소통용 PR #137과 기획 초안 #204를 병합하지 않는다.

## 목록

- 선택 연도의 유효한 연간 추정: 1순위, `#C8FF9E`.
- 직전 연도의 유효한 연간 결산: 2순위, 기존 `#FFD96E`.
- 그 외: 3순위, `#BDC3CC`. 기본 목록에서 제외하고 명시적 검색에만 포함한다.
- 자료 유형·연도와 저장 값을 판정하며 최근 작업 상태의 실패만으로 보존된 값을 제외하지 않는다. 빈 추정 행은 결산 자료로 대체한다.
- 반기·분기만 존재하는 종목, 더 오래된 연간 자료는 기본 목록에서 제외한다. 과거 일별 지표가 12월 31일이라는 사실만으로 연간으로 인정하지 않는다. 해당 연간 재무자료가 확인될 때만 이전 지표 호환 경로를 사용한다.
- 그룹 1→2→3, 그룹 내 W 내림차순, 결측 마지막. 실제 표시 목록 길이를 총건수로 사용한다.

## 카드·설명

발행주식수·W·ROE 행에 자료 분류색을 적용한다. 기존 적정주가 공식의 W 0.7/0.8/0.9/1.0을 동일 너비, 계수/가격 두 줄 박스로 표시한다. 기준 안내행은 카드 맨 아래 한 줄로 표시하며 전체 행이 설명 팝업을 연다. 긴 문구는 줄임표로 표시하고 팝업에서 전체 내용을 제공한다.

팝업은 자료·자본의 출처, 주식수 기준, 누락·총액 미표시 사유를 표시한다. 안내행은 종목 상세 진입과 분리한다. 바깥 클릭·Esc·닫기·브라우저 뒤로가기로 닫고 기존 화면 상태를 유지한다. 일반 팝업 이력 처리 훅을 재사용한다.

## 주주가치 총액

기존 `fairPrice` 및 W 가격 계산은 변경하지 않는다. Decimal로 `초과이익 = 검증된 자기자본 × (ROE / 100 − 0.08)`, `총액 = 자기자본 + 초과이익 × 0.8 / 0.08`을 계산한다.

계산 가능 조건:

- 연간 DART 자료의 사업연도·접수번호·결산기준일·연결/별도 구분이 BPS/ROE 원천과 일치한다.
- 연결은 지배주주 귀속 자기자본·ROE, 별도는 동일 별도 자기자본·ROE를 사용한다.
- 동일 공시의 우선주 없는 보통주 유통주식수와 BPS 분모 정책이 명시되어야 한다.
- 원천 자기자본/해당 주식수가 저장 BPS의 기존 소수 4자리 정밀도에서 일치해야 한다.
- 추정 제공처의 BPS 분모가 확인되지 않으면 계산하지 않는다. 직전 결산 자본을 추정 ROE 총액에 임의 조합하지 않는다.

0·음수는 보존한다. 근거 부족은 `null`+`rimReason`이다. `rimBasis`는 검증된 자기자본·주식수·기간·공시 근거를 제공한다. `rimComparison`은 총액/동일 주식수와 기존 W0.8 가격의 차이를 제공하며 기존 가격을 수정하지 않는다. 표시용 발행주식수와 RIM 유통주식수 분모는 구분한다.

## 유지 범위

수집·스케줄·DB·원본 거래·예수금·스냅샷을 변경하지 않는다. 목록 금융자료 조회는 선택/직전 두 연도로 제한하고 기존 짧은 서버 캐시 및 현재가 별도 조회를 유지한다. 기존 상세 재무제표 조회와 내비게이션은 변경하지 않는다.
