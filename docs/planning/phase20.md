- 가치분석 목록 최초 진입·상세 복귀에서는 검색 자동 포커스를 하지 않는다. 직접 검색창 선택 및 검색어 지우기 후 사용자 입력 흐름은 유지한다. 초성·Enter·IME·W 정렬은 변경하지 않는다.
- 신규 매수: 현재 계좌·동일 종목의 매수일시 DESC, 동일 시각 BIGINT ID DESC로 직전 기록 선택. 전량 매도된 기록도 원래 등록 수량을 사용한다. 기록 있음 → 수량 자동 입력 후 가격 포커스; 없음 → 빈 수량과 수량 포커스. 사용자 조작 이후 도착한 결과는 입력·포커스를 덮지 않는다. 수정·매도는 기존 동작 유지.
