# 18차 기획 현행 명세

[계약 및 범위](../handoff/20261011-phase18-current.md)을 기준으로 한다. 차트 상태별 고정 높이, 홈 주요 카드 우선 표시, 최근 매수 서버 범위 조회, 과거 연도 집계와 정확한 무효화, 설정/복리 기본 내용 독립 표시를 적용한다. 기존 계산·조회 기준·계좌 분리와 더보기 의미를 유지한다. API 수보다 카드 표시시간/전체 완료시간과 정확성을 함께 평가한다.

운영 완료 결과 및 측정/미확인은 [최종 QA](../qa/phase18-results.md) 참조. 운영 복구 #184와 기본 화면 코드 분리 #185 포함.
