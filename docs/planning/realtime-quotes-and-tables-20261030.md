# 실시간 주가 화면과 테이블 고도화 · 2026.10.30

상태: **실시간 기획 확정·Figma 작성 / 코드 전환 대기**. 60초 크롤링의 현재 구현과 아래 전환 목표를 구분한다. 테이블 분리는 논의 예정이다.

## 확정된 실시간 주가

- 한투 웹소켓으로 체결 정보를 지속 수신한다. 일정 주기로 요청하는 방식이 아니다.
- 최신 수신값을 **1초마다 화면에 묶어 반영**한다. 앞서 논의한 3초는 대체한다.
- 전체 카드/목록 로딩·깜박임·스켈레톤 없이 변경 숫자만 갱신한다. 자릿수 변경으로 열이나 카드가 흔들리지 않게 한다.
- 증권통 참고 2열 시세 카드. 종목명·현재가·전일 대비 등락률·등락액을 표시하고 주문 버튼·체결량은 제외한다.
- 알림 아이콘은 표시하되 기능은 후속 논의한다. 구현하지 않은 알림 기능을 동작하는 것으로 표시하지 않는다.
- 상단 시장 선택은 **통합 / NXT / KRX**, 기본 **통합**이다. 서로 다른 시장 시세를 섞지 않는다.
- 상승 빨강·하락 파랑·보합 중립색. 새 체결이 없으면 기존 값 유지.
- C3400(370×465) / T3400(725×396), v0.1 · 2026.10.30. 헤더/하단 고정·본문 스크롤.

## 구현 시 검토할 설계

API 키는 서버에서 관리하고 단일 수신 경로의 최신값을 기존 API/SSE와 연결하는 방향으로 검토한다. 외부 한투 웹소켓과 내부 서버→브라우저 SSE는 구분한다. 최초 진입·재연결의 REST 보완, 중복 연결 방지, 시장별 캐시, 지연/끊김 표시, 구독 전환과 순서 역전 방어가 필요하다. DB 저장 주기와 체결 원본 보관 여부는 확정하지 않았다. 1초 표시가 1초마다 모든 종목을 DB에 쓰라는 뜻은 아니다.

기존 API 최대 100종목을 한투 구독 가능 수로 그대로 간주하지 않는다. 앞서 확인한 한투 공개 안내의 앱키당 1세션·합산 41구독과 계정별 최신 정책을 구현 전에 재확인한다. 호가 등 다른 구독도 합산한다. 초과 시 표시/구독 우선순위 정책은 후속 확정한다. REST TPS와 실시간 메시지 수신 횟수는 별개다.

검증 대상: 최초 값·1초 반영·변경 없는 종목, 통합/NXT/KRX 전환 중 응답 혼합, 재연결·역전 시각·휴장/거래정지·미지원 시장, 긴 숫자·두 뷰포트·배경 복귀·사용자 권한. 실제 증권통과 비교할 때 동일 시장·기준시각으로 대조한다.

## 미확정 사항

상단 보유·관심 선택, 직접설정순, 종목추가는 현재 시안의 배치 예시이며 상세 동작은 별도 확정한다. 우측 미니 가격표시의 데이터 정의도 추가 논의한다. 실시간 화면의 메뉴 진입 위치와 알림 기능은 미확정이다.

DB 테이블 분리는 다음 논의 대상이다. 현재 스키마를 보존하며 분리 대상·키·관계·이관·복구·물리 DB 분리 여부를 임의로 정하지 않는다.
