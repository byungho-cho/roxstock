# 실시간 주가 화면과 테이블 고도화 · 현행 2026.11.01

실시간 화면은 v1.2.49~1.2.53으로 구현·운영 반영됐다. [현행 정본의 최종 동작과 저장 정책](../current-state-20261101.md)을 기획·개발 공통 기준으로 사용한다. 초기 개발 대기 기획은 대체한다.

C3400/T3400 V1.0, 기존 화면 크기·공통 메뉴를 사용한다. 화면 진입은 홈 다음 두 번째 메뉴, 상단 +는 실제 보유 등록이 아닌 표시종목 관리다. 목록·필터·정렬·일괄 추가/제거·롱프레스 임시 순서 편집·취소/일괄 저장은 현행 정본대로 구현돼 있다.

한투 웹소켓 수신과 약 1초 화면 갱신은 별개다. 화면 전체 리프레시 없이 숫자를 갱신하고 가격 영역만 약 1초 강조한다. 강조색은 현재 전일 대비 방향이다. 초기값은 시장별 메모리 및 기존 KRX 저장값의 명시적 참고 표시로 보완한다.

실시간 전용 새 테이블과 체결 이력 저장은 추가하지 않았다. 사용자 설정에 표시종목 ID·순서·버전만 저장한다. 표시 한도 50과 공유 구독 한도 41을 구분한다. 기존 네이버 평가·스냅샷 수집은 유지한다.

**테이블 고도화**는 별도 후속 논의이며 분리 대상·키·관계·이관·복구·물리 DB 분리를 임의 확정하지 않는다. 이번 소식 읽음 테이블은 사용자별 읽음 기능에 필요한 별도 변경으로, 실시간 저장 확대나 테이블 분리 완료를 뜻하지 않는다.
