# 13.1차 상세 상단·검색 · 2026.10.08

13차 PR #142 병합 main 3d9c1cb10a3feb6f80671338a8df90179ff6883d 기준. 상단 구성은 본 문서가 13차보다 우선한다.

| 진입 | 가치분석·재무지표 상세 상단 |
|---|---|
| 보유·관심 목록 | 뒤로가기, 중앙 종목명, 아래 코드, 좌우 이전·다음. 이웃이 없어도 구성 유지 |
| 가치분석 검색·선택 | 뒤로가기·종목 내비게이션 없이 종목명 (코드) 한 줄 왼쪽 정렬 |

목록의 분류·검색·정렬 결과 ID 순서와 반환 위치를 종목 이동 및 상세 전환에서 보존한다. 태블릿 목록 진입 상세는 해당 종목 전체 너비로 표시한다. 가치분석 태블릿 검색/상세 분할은 유지하고 선택 종목 상단은 한 줄로 표시한다. 차트 전체화면 뒤로가기는 유지한다.

검색은 이름/코드 API를 그대로 사용한다. 확인 버튼·Enter는 동일 확정 처리를 사용하고 확정 후 입력 blur. enterKeyHint=done. 한글 조합 중 및 native isComposing/keyCode 229 Enter는 차단하고 같은 검색어 반복 확정은 조회를 중복 실행하지 않는다. 결과 없음은 기존 빈 상태를 표시한다.
