# 17차 미완료 UI 보완 · 2026-10-10

기존 17차의 후속 작업이며 새로운 차수가 아니다. 동일 항목의 이전 기준보다 이 문서를 우선한다. PR #173 브랜드 아이콘과 PR #137 임시 소통은 범위 밖이다.

- 하단 메뉴·더보기는 같은 공통 아이콘 정의/파일을 사용한다. 투자금은 예수금과도 구분하며 투자손익·가치분석·재무제표·복리계획·모니터링·설정을 의미별로 구분한다. 하단 높이44px·아이콘18px·선택 노랑·양 끝 홈/더보기 고정·중간 가로 스크롤은 유지한다.
- 계좌 카드는 첫 줄 계좌명/번호와 오른쪽 연필, 둘째 줄 한국 시간 `YYYY.MM.DD HH:mm`과 오른쪽 금액이다. 최근 수정·오전/오후 문구는 제거한다. 기본 높이는약60px로 기존 약97px 대비 약38% 축소한다. 긴 내용은 잘림을 피하도록 줄바꿈하여 높이가 늘 수 있다. 카드 선택·독립 연필 편집·선택 제목/테두리 노랑을 유지한다.
- 복리 진행 폭은 기존 서버의 현재 자산/최종 목표 비율을 사용하며 새 계산식으로 대체하지 않는다. 그 아래 올해 목표/최종 목표의 배경을 겹치고 목표 위치에는 별도 최상위 노란 기준선을 표시한다. 표시 폭/선 위치는0~100%로 제한하되 원래 진행률 값과 초과 금액은 보존한다. 올해 목표가 최종 목표를 넘으면 오른쪽 끝에 기준선을 표시한다.
- 올해 목표 대비 부족/초과 금액 또는 목표 달성을 표시한다. 금액 비교·차액은 소수 문자열 BigInt로 표시 반올림 전에 판정한다. 현재 자산과 진행 막대는 올해 목표 달성률90% 미만 파랑,90~110% 양 끝 포함 노랑,110% 초과 빨강이다. 목표 자산은 흰색이며 올해 노란 기준선은 상태색과 별개다.
- 올해 목표 누락/0 이하 또는 현재 자산 미수집은 상태색/차액 중립이다. 최종 목표 누락/0 이하에서는 폭/기준선을 표시하지 않는다. 자산분석 요약·목표 상세·계획 목록/비교에 같은 공통 컴포넌트를 사용한다.

복리 계산·목표 금액·최종 목표 대비 진행률·수집·계좌 데이터 기준과 관리 기능은 유지한다. 화면 검증은 모의 API, 운영 확인은 읽기 전용으로 구분한다.
