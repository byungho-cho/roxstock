# Collector

수집기 전용 최상위 디렉터리입니다. API 서버(`backend/`), 프론트엔드(`frontend/`)와 구분해 수집기 개발을 관리합니다.

## 현재 상태

이 커밋은 디렉터리와 역할 안내만 추가합니다. 수집기 실행 코드는 아직 기존 위치에 있으며, 실행 명령·이미지·배포 동작은 변경하지 않습니다.

## 후속 분리 작업 기준

- 일반·실시간 주가·DART 수집기의 진입점, 스케줄러, 수집·파싱·재시도 로직 및 전용 테스트를 이 디렉터리로 이동합니다.
- 수집기 전용 패키지·TypeScript 빌드 설정과 Dockerfile을 이 디렉터리에서 관리합니다.
- API와 수집기가 공유하는 DB 접근·타입·유틸리티는 별도 공통 모듈로 관리합니다. 코드를 복제하거나 서로의 내부 소스에 직접 의존하지 않습니다.
- 수집 상태 조회·관리 API는 `backend/`에 유지하며, 수동 수집 요청 전달 경로를 보존합니다.
- 동일 저장소·동일 서버·동일 DB를 유지하고, 코드·이미지·빌드·배포를 독립화합니다.
- 실제 이동 시 import, 실행 명령, CI 경로 필터, 이미지 빌드 컨텍스트, 배포 및 롤백 문서를 함께 수정합니다.

분리 전 소스 복구 기준은 [`v0.2`](https://github.com/byungho-cho/roxstock/releases/tag/v0.2)입니다. DB 복구는 별도 백업과 스키마 호환성 확인이 필요합니다.
